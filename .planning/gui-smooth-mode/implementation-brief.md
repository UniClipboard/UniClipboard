# Go GUI 流畅模式完整实装梳理

日期：2026-10-21。当前阶段：已实施、完成本机验收并提交当前分支；当前事实见 docs/specs/2026-10-21-gui-smooth-mode.md。

## 1. 目标与依据

将设置页的「自动／效果优先／流畅优先」落实为可持久化、跨窗口一致的 Go/Wails GUI 功能。用户明确限定：仅覆盖 GUI 界面，不适用于 macOS/Windows 的独立原生快捷面板。

产品语义依据 VISION.md「跨平台视觉适配」及 docs/specs/2026-09-08-adaptive-smooth-mode-spec.md。旧规格中的 Tauri 模块、Rust DTO 生成和测试入口已不适用；不恢复旧宿主，也不修改 Engine。

## 2. 用户应得到的行为

| 用户选择 | 系统允许动效 | 系统要求减少动效或无法读取 |
| --- | --- | --- |
| 自动 | Linux 固定流畅；macOS/Windows 使用本次 GUI 启动冻结的自动判断 | 减少动效与视觉效果 |
| 效果优先 | 完整效果 | 关闭非必要动画，保留静态视觉效果 |
| 流畅优先 | 关闭非必要动画、模糊与重阴影，使用不透明表面 | 同左 |

必须分别输出 reduceMotion 与 lowEffects：流畅为 true/true；效果优先遇到系统减少动效为 true/false；完整效果为 false/false。

- 用户选择与有效结果分开。Linux 保存 auto 时，界面仍选中「自动」。
- 手动切换立即应用，不重挂载页面，不丢输入、焦点、滚动或选择。
- 主窗口、WebView 快捷面板、更新窗口共享同一 GUI 会话的权威结果。独立原生快捷面板不接入该设置。
- GUI 窗口隐藏、重载、重新显示后恢复当前状态，不重新初判。
- GUI 进程重启后恢复用户选择；daemon 重启不重置视觉策略。
- 自动采样只影响下次 GUI 启动，不在操作中突然降级；切回自动仍使用本次冻结结果。

## 3. 当前缺口与证据

| 环节 | 当前实现 | 必须补齐 |
| --- | --- | --- |
| 宿主状态 | apps/gui-go/host_commands_native.go 内进程状态，启动固定 auto | 独立状态服务、启动恢复与纯决策规则 |
| 自动结果 | AutoForSession 固定 effects | Linux 固定 smooth；macOS/Windows 原生初判 |
| 流畅模式 | 只设置 lowEffects，reduceMotion 只跟随系统 reduce | 正确的双布尔值决策 |
| 系统偏好 | 最后一次上报覆盖；不校验 sessionID；改变后不广播 | 窗口身份、会话校验、保守汇总、销毁清理、全窗口广播；unknown 保守处理 |
| 持久化 | 明确标注 session-only，没有文件读取 | profile/便携路径隔离、有界读写、原子替换与失败状态 |
| 自动评估 | BeginVisualEffectsSample 返回 nil，报告丢弃 | 统一许可、校验、限频、会话上限与下次启动降级 |
| 前端公共控制 | store、Provider、CSS 与采样器仍在 | 复用并修正边界，不另建决策源 |
| 三平台皮肤 | 存在独立 CSS、系统媒体查询和 Windows Fluent 组件 | 按实际渲染路径核对动画、阴影、玻璃和 portal；不能只检查旧公共控件 |
| macOS 原生材质 | 主窗口创建时固定原生材质，前端按启动参数识别 | 流畅时保证不透明；核查当前 Wails 是否支持关闭原生材质，不能以关闭 CSS 模糊代替原生控制 |
| 独立原生快捷面板 | macOS/Windows 默认独立 helper | 用户明确排除，不增加状态通道或修改面板行为 |
| 验收 | 旧浏览器脚本使用模拟连接；历史原生记录属于退役宿主 | 新 Go/Wails 真实宿主、磁盘与 GUI 多窗口证据 |

profile=a 旧 visual-effects.json 的 mode=auto、policyVersion=2、nextAuto=null、evidenceClass=unknown；Go GUI 目前不读取它。迁移需保留用户模式，不将该粗分类当作当前设备探测结果。

## 4. 所有权与模块安排

建议在 apps/gui-go/internal/visualeffects/ 集中实现状态服务、纯策略、配置存储和平台探测。命名可在实施时按实际大小调整，但职责与唯一所有权固定：

- Go GUI 服务唯一决定模式、冻结自动结果、汇总系统偏好、授予采样许可并写配置。
- apps/gui-go/host_commands_native.go 的相关方法退为薄转发；删除现有占位策略。
- apps/gui-go/host_types.go 保持公开合同唯一来源；需要变更时运行 bun run gen:host-contract，不手改生成文件。
- React store 仅维护权威快照、订阅与显示重读；皮肤消费有效状态，不判断硬件或自行保存模式。
- 不修改 apps/quick-panel/ 或 packages/desktop-host-go/quickpanelhelper/，不向独立原生快捷面板推送状态、收集偏好或采样。
- 所有原生图形查询优先核查固定 Wails 版本源码；未覆盖能力才加平台适配。已确认 beta.28 提供 application.WindowKey，可从受信任调用上下文取得窗口身份。
- 不加入 daemon 设置、导入导出或设备同步；不为视觉偏好连接 Engine 密钥内部实现。

## 5. 持久化与迁移

- 沿用 profile 数据根中的 visual-effects.json，保持既有 schemaVersion=1 的读取兼容；版本变化保留手动选择，只清除失效自动证据。
- 保存模式、schemaVersion、policyVersion、nextAuto、evidenceClass；不保存原始硬件、逐帧数据或会话样本计数。
- 缺文件正常创建；损坏、超过 4 KiB 或未知未来版本保留原文件，当前会话仍可操作并明确不能保存。
- 串行执行内存更新、保存、返回与广播；失败保留本次有效结果，标记 session_only，后续明确保存成功才能清除失败提示。
- 使用同目录唯一临时文件、刷新和跨平台原子替换；Windows 必须实际验证覆盖已有文件，不能假定 os.Rename 与 Unix 行为一致。
- 现有规格提出的有限明文例外并非自动授权：实现与沙箱测试可以先完成；若沿用明文格式，合入前仍须逐字段论证非敏感性并完成仓库要求的审批。不得额外保存任何用户内容。

## 6. 自动策略与采样

- Linux：自动固定流畅，不执行硬件探测或运行采样，手动效果优先仍有效。
- macOS/Windows：后台初判，最长等待 2 秒；期间静态低效果，超时按 unknown 冻结，迟到结果不改变本次判断。
- 沿用旧规格的初始门槛：至少 4 个物理核心、8 GiB 物理内存，并具备规定的现代原生图形能力；任一已知不达标为 constrained，信息不足为 unknown，全部满足才为 capable。
- Metal/Direct3D 是候选原生能力路径，具体适配须以固定依赖和官方 API 核查为准；原生能力不代表 WebView 实测帧率，不用型号白名单或命令行硬件探测。
- 优先采用有效的历史降级结果；策略或粗能力分类变化使旧自动证据失效。系统偏好只是即时覆盖，不写入冻结结果。
- 自动且实际完整效果时才允许采样。启动至少 10 秒、业务就绪、窗口前台可见且未最小化、可信交互后启动；隐藏、休眠、重载或模式变化取消。
- 全 GUI 会话一次仅一个许可，每次最多 2 秒，间隔至少 30 秒，最多 10 次。拒绝许可不得创建 rAF。
- 至少 30 个有效间隔；大于 50 ms 算长帧，长帧至少 6 个且占比达到 20% 算差样本；出现超过 500 ms 的间隔丢弃整段。
- 验证 session、revision、窗口、许可、重复报告、有效数值及许可期限；不允许一个窗口消耗另一个窗口许可。
- 同会话 3 次独立差样本后保存 nextAuto=smooth；本次有效结果保持不变，下次 GUI 启动采用并持续保留。
- 流畅状态不做自动恢复试探，不因低效果下表现正常恢复完整效果。
- 运行采样仅覆盖受该设置控制的 GUI WebView，不采样或评估独立原生快捷面板。

## 7. 效果覆盖与验证

重新审计真实入口的 CSS、Motion、命令式动画、Windows Fluent 组件与原生材质；旧效果来源清单仅作起点。

- 动画关闭后仍应用正确终态，退出、关闭、焦点返回和 inert 清理正常。
- 流畅时去除重阴影、模糊和装饰效果，半透明表面使用语义不透明背景；不全局清除 transform、opacity 或定位样式。
- 加载、进度、错误和选中反馈保持可理解，不能只留下冻结的旋转图标。
- 保留用户内容自身的动图/视频语义，不把内容播放与装饰动效混为一谈。
- 系统偏好冲突按存活 GUI 窗口 reduce > unknown > allow 汇总；窗口销毁后清除对应状态。
- 验收所有三档、系统 allow/reduce/unknown、浅深色、三种皮肤；GUI 多窗口隐藏重显、重载、GUI 重启与 daemon 重启。
- 覆盖正常/缺失/损坏/超大/未来版本配置、已有配置迁移、写失败与两个 profile 隔离。
- 自动路径覆盖强/弱/未知能力、探测超时、三次差样本、重复与失效许可、30/60/120 Hz、后台取消和会话限额。
- 浏览器检查验证真实组件外观与交互；带 e2e 标签的真实 Wails WebView 验证宿主与磁盘，生产构建不得暴露控制面。
- 自动化使用唯一 gui-go-* profile 与隔离环境、禁用系统剪贴板；不修改 profile=a。测试以 apps/gui-go/AGENTS.md 的端到端要求为准，不新增宿主单元测试。
- macOS/Windows/Linux 分别保存运行证据；交叉编译不等于真机通过，历史 Tauri 证据不计为 Go 实装验收。

## 8. 实施顺序与完成条件

1. 完成手动选择闭环：纯策略、旧配置读取与保存、系统偏好汇总、全窗口通知、正确双布尔值和保存反馈。
2. 补齐 GUI 三平台公共效果控制，包含 GUI 原生窗口材质和进行中动画收尾。
3. 实现 macOS/Windows 原生初判、全进程采样许可与下一启动降级；Linux 明确跳过。
4. 执行真实宿主验收，生成效果覆盖、能力与性能边界记录；更新旧规格和失真的用户提示。

完整完成必须同时满足：三档确实改变有效行为、选择可恢复、各窗口一致、平台自动规则真实执行、运行降级生效、保存失败可见、三套 GUI 皮肤与受控窗口有证据。仅按钮可点、模拟浏览器通过或目标可编译，都不足以称为完整实装。
