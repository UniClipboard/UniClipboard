    ## Planner behavior (planner.rs)
    - Test 1: plan() with RemotePush origin -> clipboard: None, files: []
    - Test 2: plan() with LocalRestore origin -> clipboard: Some (text snapshot), files: []
    - Test 3: plan() with LocalCapture + file_sync_disabled -> clipboard: Some, files: []
    - Test 4: plan() with LocalCapture + file_sync_enabled + no file representations -> clipboard: Some, files: []
    - Test 5: plan() with LocalCapture + file_sync_enabled + file URIs + all within size -> clipboard: Some (with file_transfers), files: vec of FileSyncIntent
    - Test 6: plan() with LocalCapture + file_sync_enabled + all files exceed max_file_size -> clipboard: None (all_files_excluded guard), files: []
    - Test 7: plan() with LocalCapture + mixed file sizes (some exceed, some not) -> clipboard: Some (only valid file_transfers), files: only valid FileSyncIntents
    - Test 8: plan() when settings load fails -> clipboard: Some (safe default), files: [] (safe default)
    - Test 9: plan() with file metadata read failure -> that file excluded, others proceed

    ## File path extraction (pure URI parsing, NO APFS)
    - Extracts file:// URIs from text/uri-list and file/uri-list MIME representations
    - Also checks format_id "files" and "public.file-url"
    - Skips comment lines (# prefix) and empty lines
    - Deduplicates and sorts paths
    - Does NOT call resolve_apfs_file_reference (that stays in uc-tauri)
