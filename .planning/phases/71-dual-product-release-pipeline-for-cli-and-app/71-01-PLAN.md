<objective>
Align CLI version to workspace inheritance and fix Cargo.lock refresh during version bumps.

Purpose: The CLI crate has a hardcoded `version = "0.1.0"` that drifts from the workspace version. After switching to `version.workspace = true`, the existing `updateCargoLock()` function only patches the root `uniclipboard` package entry. A new function must also patch the `uc-cli` entry (and any other workspace member) in Cargo.lock, or the lock file becomes inconsistent after version bumps. CI workflows must also run `cargo update -p uc-cli` after the bump script to ensure Cargo.lock is correct.

Output: uc-cli/Cargo.toml using workspace version, bump-version.js refreshing all workspace members in Cargo.lock, updated CI workflows, extended tests.
</objective>
