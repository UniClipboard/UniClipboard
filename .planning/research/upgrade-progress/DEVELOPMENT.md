# 升级界面开发预览

2026-09-10：最初提供本地 Engine 临时引用与界面模拟；后续已接入真实启动状态和自动连接。
最新实现说明见 `docs/architecture/startup-upgrade-progress.md`。

## 使用

从仓库根目录运行 `bun run dev --host 127.0.0.1 --port 1437`，打开
`http://127.0.0.1:1437/?upgrade-preview`。

开发工具栏可以切换升级、恢复、未知总量、磁盘空间不足、保护材料不可用、中断、准备应用和完成。
播放按钮推进模拟任务，重试创建新尝试，导出仅生成带 `simulated: true` 的模拟快照。
深浅色和中英文可切换；模拟入口绕过正常应用启动，不读取真实 profile。

可用查询参数：`scenario=failed`、`scenario=protection`、`theme=dark`。
正常地址继续运行原应用；生产构建删除开发入口与模拟数据。

## 已完成与边界

- `StartupProgressScreen` 只消费 Engine 公共 StartupSnapshot 的序列化形状和操作回调；无需升级的冷启动不显示升级步骤或升级完成文案。
- 已知总量显示当前步骤百分比；未知总量不显示假百分比。警告未知与零分开。
- 只有失败或中断且允许重试时显示重试；保护信息不可用不提供密码输入。
- 当前类型使用共享 Rust DTO 经 Tauri 生成的定义；真实进度来自认证后的后台启动状态服务。
- 正常应用已移除独立的 12 秒失败计时，原生和前端等待会识别活跃升级并继续等待。
  业务就绪后完成健康检查和连接；模拟预览仍独立运行，不能替代真实资料验收。
