## Почему UniClipboard

- **Кроссплатформенность**: синхронизация между Windows, macOS и Linux — в одной сети Wi-Fi или в разных сетях.
- **Без облака**: устройства соединяются напрямую по зашифрованному каналу. Регистрация не нужна. История хранится только на ваших устройствах.
- **Лёгкость**: фоновая служба синхронизации занимает около 14 МБ памяти в простое<sup>[1](#benchmarks)</sup>. В Windows главное окно занимает около 34–49 МБ<sup>[2](#benchmarks)</sup>. После закрытия окна его процесс завершается.
- **Синхронизируется всё**: текст, изображения, файлы и целые папки.

## Возможности

| | |
|---|---|
| ⚡ **Быстрая панель** | Нажмите `⌘ ⌃ V` (`Ctrl Alt V` в Windows / Linux) в любом приложении, выберите запись и нажмите Enter, чтобы вставить. |
| 🔍 **Быстрый поиск** | Введите слово или отфильтруйте по `#метке`, `@устройству` или `/типу`. Найдите то, что копировали месяцы назад. |
| 🏷️ **Автоматические метки** | Ссылки, адреса e-mail, цвета, номера версий, UUID и IP-адреса получают метки автоматически. Можно добавить свои правила. |
| 📁 **Файлы и папки** | Отправляйте папку целиком с сохранением структуры — на все устройства или на одно. |
| 📮 **Отправка без сопряжения** | `unic send "текст"` выводит 6-значный код. Получатель вводит его и получает данные. Запись об устройстве не сохраняется. |
| 🧩 **Плагины** | Устанавливайте плагины в один клик из настроек, например чтобы превратить изображение или файл в ссылку. |
| ⌨️ **Командная строка** | `unic` отправляет, принимает и ищет по истории из терминала, по SSH и в скриптах. |
| 🌍 **Языки** | English, 简体中文, 日本語, Português, Русский. Светлая и тёмная темы. |

## Начните за 3 шага

**1. Запустите**

> Установщики скоро появятся. Пока можно запустить из исходного кода — нужен только [Go](https://go.dev/dl/).

```sh
git clone https://github.com/UniClipboard/UniClipboard.git
cd UniClipboard
make run-desktop
```

**2. Подключите второе устройство**

На первом устройстве откройте **Устройства → Добавить устройство** и запомните 6-значный код. Введите его на втором устройстве. Когда оба покажут одинаковый отпечаток, нажмите **Принять** на каждом.

**3. Копируйте**

Нажмите `Ctrl+C` на одном устройстве и `Ctrl+V` на другом.

## Командная строка

```sh
unic send --to all "Hello"        # отправить на все устройства
unic send --to all -f ./photos    # отправить файлы или папку
unic send "временно"              # без сопряжения: получить код
unic recv 482913                  # принять по коду
unic history list                 # история
```

Все команды — в [руководстве по CLI](app/service/README.md).

## Измерения

| | Память | Условия |
|---|---:|---|
| Служба `unicd` | **14 МБ** | macOS (Apple Silicon), пустая история, замер после 20 с простоя; та же метрика, что в столбце «Память» Мониторинга системы<sup>1</sup> |
| Главное окно | **34 МБ** / 49 МБ | Windows 11, нативная сборка ARM64 / x64, 60 текстовых записей; метрика Диспетчера задач<sup>2</sup> |
| Главное окно с изображениями | 119 МБ / 133 МБ | То же плюс 12 изображений 2048×1536<sup>2</sup> |

<sup>1</sup> Замер на коммите `e2cb68d` командой `footprint <pid>`. <sup>2</sup> Медиана трёх запусков. Подробнее — в [отчёте о памяти в Windows](docs/exec/windows-desktop-memory.md).

## Конфиденциальность

- Данные шифруются сквозным шифрованием между устройствами. У UniClipboard нет серверов, которые хранят ваш буфер обмена.
- Каждое новое устройство вы одобряете сами, сверив отпечаток. Удалённое устройство сразу теряет доступ.
- Содержимое буфера, пути к файлам и адреса устройств не попадают в журналы.
- Анонимная диагностика не содержит данных буфера и идентификаторов устройств. Её можно отключить в **Настройки → Диагностика и конфиденциальность**.

О проблемах безопасности сообщайте конфиденциально, как описано в [SECURITY.md](SECURITY.md).

## Переход с UniClipboard v1

v2 импортирует всю историю v1: текст, изображения, файлы и метки. Следуйте подсказкам при первом запуске v2 или импортируйте позже через **Настройки › Хранилище › Перенести из v1**.

Устройства v2 не синхронизируются с устройствами v1. Обновите все устройства до v2 и выполните сопряжение заново. Код v1 находится в [ветке `v1`](https://github.com/UniClipboard/UniClipboard/tree/v1).
