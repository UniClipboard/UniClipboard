# Color token catalogue

The current native presentation exposes the following code-defined color tokens. Values use sRGB `#RRGGBBAA`. The first 111 semantic/accent tokens per scheme come from the pinned BoardUI source. Gradient endpoints, shadow layers, existing native paints and native primitive colors complete the vocabulary.

`boardui.ColorTokenNames()` returns these names in sorted order. `(*boardui.ColorTheme).Tokens(dark)` returns an independent snapshot. A nil theme returns the current default values. Use these APIs to regenerate or export this catalogue. See [theme usage](README.md#code-defined-color-themes).
