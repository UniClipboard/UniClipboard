---
title: Install
description: Install UniClipboard on macOS, Windows, or Linux.
---

Pick the build for your platform.

## macOS

Download the latest `.dmg` from the Releases page, drag the app into
`/Applications`, and grant Accessibility + Input Monitoring permissions on
first launch.

## Windows

Download the `.msi` installer or the portable `.zip`. Both are signed.

## Linux

Snap (recommended) or AppImage:

```bash
snap install uniclipboard
```

Once installed, continue to [Quick start](./quick-start).
