---
title: Quick start
description: Pair two devices and sync your first clip.
---

After installing on two machines on the same LAN:

1. Open UniClipboard on **device A** → **Settings → Pairing → New code**.
2. On **device B**, enter the code. The peers exchange a key and store each
   other in their trusted-peer list.
3. Copy something on A. Paste on B. Done.

The pairing handshake is one-time; subsequent sessions reconnect automatically
when both peers are online.

See [Pairing & sync](../guides/pairing) for protocol details.
