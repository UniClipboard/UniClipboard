This page walks through the mobile app settings one by one, explaining what each option controls. iOS and Android are laid out differently: Android is a settings hub split into several sub-pages, while iOS is a single paged list. The two platforms are covered separately below.

For options that mean the same thing on both platforms, the full explanation is given on one side and only referenced on the other, without repeating it.

<Tabs items={['iOS', 'Android']}>

<Tab value="iOS">

### Servers

- **Server list** — the desktops you've connected to. You can add, remove, and switch the default server, or add a new one by scanning a QR code. You can also tap the current server name in the top bar of the main screen to switch quickly. Credentials are stored only on this phone. For the full steps to add a connection, see [Connect to a desktop](./connect).

### Sync

Three independent toggles control the flow of data between this phone and the desktop:

| Toggle                                | What it does                                                                                                                                                                                               | Default |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| Auto-write to this device's clipboard | Automatically writes the latest remote content into the iOS system clipboard. **When off**, remote content is only highlighted on the main screen and won't overwrite the clipboard already on your phone. | On      |
| Auto-push this device's clipboard     | While the app is in the foreground, automatically pushes whatever you copy on your phone to the desktop.                                                                                                   | Off     |
| Real-time push (SSE)                  | Receives new content instantly via server push instead of periodic polling. Requires desktop support; when unsupported it does **not** fall back to polling automatically.                                 | On      |

<Callout type="info">
  If remote content never makes it into your system clipboard, first check that "Auto-write to this
  device's clipboard" is on. On iOS you also need to grant "Paste from Other Apps" once under
  "Clipboard access" before the app can read what you copy and push it up.
</Callout>

### Extensions and permissions

- **Keyboard** — setup guide and status for the custom keyboard extension.
- **Share** — the share extension in the system share sheet.
- **Clipboard access** — triggers the iOS "Paste from Other Apps" prompt once, so the app can read the system clipboard and push it up.

For detailed setup of the keyboard and share extensions, see [iOS extensions](./ios-extensions).

### Other

- **Storage** — view how much space cache / logs / history use.
- **Appearance** — appearance mode: follow system / light / dark.
- **Language** — Simplified Chinese / English.
- **Check for updates on launch** — checks for a new version when you open the app.
- **About** — version number and other information.

</Tab>

<Tab value="Android">

Android settings are a hub; you tap into each sub-page.

### Sync

- **Server management** — the server list; add, remove, and switch. You can also tap the current server name in the top bar of the main screen to switch quickly. To add a connection, see [Connect to a desktop](./connect).
- **Auto sync** — a single toggle that enables both "auto-apply remote" and "auto-push this device" (while the app is in the foreground).

Advanced options:

| Option                      | What it does                                                                                                                                                      |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sync toast notifications    | Shows a toast when a sync happens.                                                                                                                                |
| Max data size for auto sync | Content larger than this size is not synced automatically, to avoid large images or files consuming the network.                                                  |
| Real-time push (SSE)        | Receives new content instantly via server push instead of polling. Requires desktop support; when unsupported it does not fall back automatically. On by default. |
| Remote polling interval     | How often to pull from the remote when real-time push isn't available.                                                                                            |
| Local polling interval      | How often to check this device's clipboard for changes.                                                                                                           |

### History

- **Maximum entries kept** — the cap on retained clipboard history, 1000 by default; older entries are cleaned up automatically once the cap is exceeded.

### Background operation

Controls background clipboard read/write and keep-alive when the app isn't in the foreground. The master "Background auto sync" toggle walks you through ignoring battery optimization, granting notification permission, and granting whatever the current background reading method requires, in turn. Advanced options include the persistent notification, ignore battery optimization, background download from remote, background upload of this device, and the background reading method (Timed polling / ADB events / Shizuku).

Background operation is all off by default. For the full explanation, see [Background clipboard access](./android-access).

### SMS forwarding

- **Auto-upload SMS verification codes** — automatically pushes an SMS verification code to the desktop when it arrives. Requires SMS permission.

### Appearance

- **Appearance mode** — follow system / light / dark.
- **Hide from recent tasks** — keeps the app out of the system's recent tasks (multitasking) list.

### Other

- **Language** — Simplified Chinese / English.
- **Storage** — view how much space cache / logs / history use.
- **About** — version number and homepage link.
- **Developer options** — logs, debugging, adding a desktop shortcut, and more. Not needed by typical users.

</Tab>

## Defaults at a glance

| Option                     | iOS            | Android                                           |
| -------------------------- | -------------- | ------------------------------------------------- |
| Auto-write remote → device | On             | Follows the "Auto sync" master toggle             |
| Auto-push device → remote  | Off            | Follows the "Auto sync" master toggle             |
| Real-time push (SSE)       | On             | On                                                |
| Background clipboard tasks | Not applicable | Off by default; reading method defaults to Timed polling |
| History retention cap      | —              | 1000 entries                                      |
