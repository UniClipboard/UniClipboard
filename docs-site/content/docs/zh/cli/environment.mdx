---
title: 高级配置
description: 用于隔离 profile、无头节点、网络部署和诊断的环境变量。
---

大多数用户应优先使用命令参数和应用设置，而不是环境变量。下面只保留部署和排障时
确实需要的公开选项。请在启动 `uniclip` 或桌面应用之前设置它们。

## 隔离 profile

| 变量         | 作用 |
| ------------ | ---- |
| `UC_PROFILE` | 选择一个命名且相互隔离的 profile。它等价于 `--profile <NAME>`，会分开数据、安全存储条目、日志和网络身份。 |

例如：

```bash
UC_PROFILE=test uniclip space status
```

桌面应用和 CLI 通常可以共用默认 profile。只有确实需要独立实例时才使用另一个
profile。

## 无头节点

不应访问系统剪贴板的服务器，请使用公开命令：

```bash
uniclip start --server
```

Linux 环境中没有 `DISPLAY` 和 `WAYLAND_DISPLAY` 时，也会自动关闭剪贴板访问。
如果要在图形会话中强制使用相同行为，可以设置：

```bash
UC_DISABLE_SYSTEM_CLIPBOARD=1 uniclip start
```

## 直连网络

| 变量                  | 作用 |
| --------------------- | ---- |
| `UC_IROH_BIND_PORT`   | 把本机 iroh UDP 端口固定为指定值，而不是使用临时端口。 |
| `UC_IROH_PUBLIC_ADDR` | 把已知的公网 `IP:端口` 作为直连候选地址发布，通常与 `UC_IROH_BIND_PORT` 一起使用。 |

这些选项用于固定 NAT 或防火墙部署，普通配对不需要设置。完整的端口与公网地址配置见
[自建服务器节点](../guides/self-host-server-node)。

## 诊断日志

普通排障优先使用公开命令：

```bash
uniclip debug on
uniclip debug status
uniclip debug export-logs
uniclip debug off
```

只有支持人员或开发者要求指定过滤条件时，才应短时间使用 `RUST_LOG`：

```bash
RUST_LOG=debug uniclip start --foreground
```

详细日志仍会受到强制隐私限制。不要长时间保留范围很宽的日志设置。

内部进程角色、后台服务启动和开发专用变量不会列在这里。它们是程序内部约定，
不是用户配置。
