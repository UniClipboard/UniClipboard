title: 设备管理
description: 设备列表与详情、设备组选项、添加与解除配对，以及按设备的同步规则。
---

设备页是空间成员的实时视图：哪台机器在线、走的是直连还是中继、哪些内容类型被允许从这边发过去。所有动作都对 **当前空间** 生效；切换空间后视图会随空间更新。

## 页面结构

左侧列表分为本机、已配对设备和手机同步设备；选择一台设备，右侧显示它的详情。
列表底部提供添加设备、添加手机、手机同步设置和切换空间入口。没有已配对设备时，列表内也会显示添加入口。

本机详情提供设备名称、同步开关、连接信息和重建空间操作。已配对设备详情提供同步规则、连接信息和取消配对操作。
手机详情提供连接地址、凭据管理和最近活动时间。

## 设备信任变化

需要决定设备组变化时，UniClipboard 打开必须处理的选择窗口，并发送系统通知。
每个选项会说明继续与哪些设备同步、停止与哪些设备同步，以及是否需要重新配对或成员资料尚不完整。
移除变化可能显示「应用变化」和「保留当前空间」；其他问题按当前可用设备组显示选项。

涉及移除本机时必须再次确认。提交后可能已经完成、仍在等待，或需要重新配对；按窗口中的结果继续操作。
如果设备状态在选择期间改变，页面会刷新选项，请重新选择。
不同设备组是长期结果，不代表离线或失败，UniClipboard 不会自动合并两边。

设备列表只展示当前空间成员。已经移除或属于不同空间的设备不会因为保留了历史关系而重新出现。
只有后台确认设备版本过旧时，才显示「需要更新」；单纯离线不代表需要更新或已经被移除。

## 卡片能告诉你什么

设备现在以列表行展示。桌面设备显示名称和在线、离线或需要处理的状态；点击后在右侧查看完整连接信息与操作。
手机显示最近活动时间，这不是持续在线状态。

### 传输通道徽标

<Feature since="0.7.0">
  按对端展示 `LAN` / `Direct` / `Relay` 的可达性徽标。底层由 `ConnectionChannelPort`
  单一真相源贯穿到 DTO，GUI、托盘图标与 `uniclip status --json` 三处看到的状态一致。
</Feature>

`Online` 旁的小标签告诉你这次连接走的是哪条路：

| 标签     | 含义                              |
| -------- | --------------------------------- |
| `LAN`    | 通过局域网 mDNS 发现并直连。      |
| `Direct` | NAT 穿透成功，跨网络的 P2P 直连。 |
| `Relay`  | P2P 打洞失败，走加密中继转发。    |

中继看到的永远是密文，参见 [配对与同步 — 中继看到的](../guides/pairing#中继看到的-vs-对端看到的)。**这个标签只反映可达性 / 性能层面**，不影响机密性。

## 添加新设备

从列表底部的添加菜单选择添加设备；已配对设备列表为空时，也可点击列表内的添加入口。弹窗会：

1. 调用 sponsor 守护进程生成一段一次性邀请码。
2. 显示邀请码 + 倒计时（默认有效期 5 分钟）。
3. 提供一键复制按钮。

把邀请码送到新设备（同物理位置直接念 / 私聊都行 —— 邀请码不带口令），让对方在新设备上点 **我已经在另一台设备上使用** → 输入邀请码与空间口令。详见 [快速开始 — 添加第二台设备](../getting-started/quick-start#添加第二台设备)。

<Callout type="warn">
  邀请码过期或已被消费就 **无法再用**。这是配对协议的"一次性"性质决定的，不是 bug ——
  重新生成一张即可。
</Callout>

## 单台设备的设置

选择已配对设备后，设置直接显示在右侧详情中。

### 基本信息

详情顶部显示设备名称、状态和取消配对操作。展开「连接信息」可查看并复制设备标识，查看连接通道和地址。

### 发送与接收开关

「与此设备同步」控制本机与该设备的同步。关闭后停止两个方向的同步；全局同步关闭时，此处不能重新开启。

### 内容类型白名单

文本、图片、链接、文件和富文本分别提供四种方向：双向同步、仅发送、仅接收、关闭。
「恢复默认」恢复默认同步规则。关闭发送的类型不会从本机发给该设备；关闭接收的类型会在进入本机历史或系统剪贴板前被拒绝。
这些规则只属于本机对这台设备的设置，不会改写对端的偏好；重新开启只影响之后的内容。

## 解除配对

在设备详情顶部点击 `取消配对` 并确认。解除后：

- 这台对端从「空间成员」列表里消失。
- 移除完成后，受保护空间会拒绝来自该 node ID 的后续传输。
- **本机历史不动** —— 之前同步过来的内容仍在。

成员移除由空间本身完成，并会跨应用或后台服务重启继续处理。若需要另一台设备上线才能完成，
只会在那台设备上显示「等待资料更新」图标；没有独立的刷新流程，也没有“永久丢失确认”操作。

若显示需要恢复，请通过仍受信任的设备恢复或重新加入空间。普通离线不代表设备已经被移除。

移除操作无法抹掉丢失或失窃设备上已经保存的历史，应当视为这些本地副本仍可被访问。

**重新配对被移除设备：** 在一台仍受信任的设备上生成新的 `invite`，再在被移除设备上完成 `join`。

## 重建空间

在本机详情的「危险区」点击「重建空间」，输入 `RESET` 后确认。
重建会创建仅包含本机的新空间，保留本地历史和设置，清空旧空间的成员关系、安全状态及未完成邀请；其他设备需要重新配对。

## 移动端同步设备

已注册手机在左侧单独分组，显示名称和最近活动时间。它们不属于桌面设备的信任组，也不显示桌面的传输通道徽标。
选择手机后，右侧显示连接地址、用户名、最近活动和凭据管理。

列表底部的菜单提供手机同步设置和添加手机入口。未启用手机同步时，添加流程先引导开启；监听失败时会显示原因。
有手机设备时，也可使用手机分组旁的设置按钮。

已有设备的原始密码无法重新读取。需要再次配对时，可重设密码；刚创建或更新凭据后，详情提供新的二维码和凭据备份。
编辑可修改名称、用户名或密码；密码留空表示保持不变。更改用户名会重新生成凭据，手机需要重新配对。
撤销设备后，旧凭据不能再访问服务。

完整配置流程见 [移动端同步](./mobile-sync)。

## 在线状态多久刷新一次

设备页是 **推送驱动** 的。守护进程内部跑一个 keepalive worker 监测对端
上下线，并通过 `peers.changed` WebSocket 事件广播变化；页面只负责订阅
并重渲染。

- **对端重新上线**：~1 秒内反映出来。对端自己的 keepalive 拨回本机时
  事件立即触发。
- **对端断网**：~25–60 秒被检测到。来自守护进程自身的 keepalive tick
  与底层 QUIC idle 超时。

页面还会在以下两种情况主动拉一次（兜底，防止某次推送被漏掉）：

1. 本次会话第一次打开设备页时。
2. 切换标签后重新回到设备页时。

**不再有周期性轮询** —— 关掉设备页后这个页面的网络流量会归零。如果某个
状态明显不对（例如远端明明在跑但你看到 `Offline`），切换标签再回来强制
刷新一次；仍不对参见 [故障排查 — 对端不上线](../help/troubleshooting#对端不上线)。

## 与 CLI 的对应

| GUI 操作                | CLI 等价                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------- |
| 「空间成员」列表        | `uniclip members`（本机 + 已配对对端；加 `--probe` 获取实时在线状态）。`uniclip devices` 是其别名。 |
| 添加设备 → 邀请码       | `uniclip invite`                                                                                    |
| 加入已有空间            | `uniclip join <code>`                                                                               |
| 复制 Peer ID            | `uniclip status --json` 中的 `network.endpoint`                                                     |
| 解除配对                | `uniclip member remove <PEER-ID>`                                              |
| 按对端的内容类型白名单  | `uniclip member sync show <DEVICE>` / `uniclip member sync set <DEVICE>`                                                  |
| 移动端同步 — 状态       | `uniclip mobile status`                                                                             |
| 移动端同步 — 列出已配对 | `uniclip mobile status`                                                                             |
| 移动端同步 — 注册设备   | `uniclip mobile setup`（向导） 或 `uniclip mobile add --label …`                                    |
| 移动端同步 — 吊销设备   | `uniclip mobile revoke <device-id>`                                                                 |
