所有复制、接收和 Action 产生的内容都保存在**本机历史**中。历史只存在于当前设备，标签、收藏和过期时间都不会同步到其他设备。

## 浏览与恢复

桌面端主窗口按时间倒序显示历史，支持列表和网格视图，滚动到底部时自动加载更多。选中条目可预览文本、图片、文件和文件夹，并恢复到系统剪贴板。

命令行：

```bash
unic history list                 # 最近 20 条（不含正文）
unic history list --type image -n 50
unic history list --tag work --json
unic history show @1              # 打印最新一条的文本
unic history use @2               # 恢复到本机剪贴板
unic history delete @3            # 在终端中会先确认；-y 跳过
unic history export @1 --output ./out   # 导出文件或文件夹快照副本
```

`@N` 表示第 N 新的条目（`@1` 为最新），也可以使用条目 ID。`unic h` 是 `unic history` 的别名。

- 恢复不会产生新的历史条目。设置 `sync.on_restore = true` 后，恢复的内容会再次发送给其他设备。
- 已保存的正文不可修改，标签和过期时间可以修改。
- `export` 不会覆盖已有文件；文件夹快照导出为 `rN/原文件夹名` 结构，并逐个校验文件哈希。

## 搜索

桌面端主窗口和[快捷面板](./quick-panel)都由服务端直接在本机历史中搜索，无需加载全部内容。

可搜索的内容：

- 文本正文；富文本仅有 HTML 时，搜索其中的可见文字。
- 文件和文件夹的**文件名**（不读取文件内容）。

搜索规则：

- 不区分大小写的**子串匹配**，中文单字、双字也能命中。
- 主窗口输入多个词时，所有词都需出现在同一条目中；快捷面板把整段输入作为一个短语。
- `%`、`_`、引号和标点都按字面匹配，没有通配符或布尔运算符。
- 不做拼音、OCR、去重音或网页抓取。

可按类型（文本、富文本、图片、文件、文件夹）、标签、来源（本机、某台设备、外部、迁移）、文件扩展名和时间范围筛选。具体输入语法见[搜索语法](../reference/search-syntax)。

<Callout>
命令行目前没有全文搜索命令，`unic history list` 只支持按类型、标签和来源筛选。
</Callout>

## 收藏

在历史或快捷面板中可以把条目设为收藏。收藏是一个保留标签 `favorite`，在侧栏「收藏」中集中显示，也可以在主窗口搜索 `#favorite`。收藏不改变排序，但默认**不会**阻止自动清理；如需长期保留，请把它加入清理排除标签（见下文）。

## 自动清理

| 配置键 | 默认值 | 说明 |
|---|---|---|
| `history.auto_cleanup` | `true` | 自动清理总开关 |
| `history.retention_days` | `180` | 保留天数，`0` 表示不按时间清理 |
| `history.max_items` | `0` | 最多保留条数，`0` 表示不限 |
| `history.excluded_tags` | `[]` | 带有这些标签的条目永不被自动清理 |
| `history.max_bytes` | `4GiB` | 历史存储总预算（重启后生效） |
| `file_cache.max_bytes` | `500MiB` | 接收文件默认缓存的配额 |

```bash
unic config set history.retention_days 30
unic config set history.excluded_tags '["favorite", "work"]'
```

- 清理从最旧的条目开始，在启动、修改设置后、每次提交后以及运行期间每 30 秒执行一次。
- 修改策略会立即作用于已有历史；读取或恢复条目不会重置其"年龄"。
- 被排除的条目不计入 `max_items`。
- 删除历史会一并释放 unic 自己缓存的文件，但**不会删除**你的源文件，也不会删除你指定的自定义接收目录中的文件。
- 手动设置的过期时间独立于自动清理：

```bash
unic history expire @1 24h
unic history expire @1 never
```

若清理关闭或受保护的条目占满空间，新内容会因存储不足被拒绝，而不会强行删除受保护条目。
