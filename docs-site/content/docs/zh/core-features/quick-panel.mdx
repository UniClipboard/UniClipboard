快捷面板是 UniClipboard 的键盘流主入口：一个独立的浮窗，列出当前空间的剪贴历史，按方向键定位、回车直接粘贴回原应用。整个流程不需要把焦点切到主窗口。

## 唤出与隐藏

| 平台            | 默认快捷键       |
| --------------- | ---------------- |
| macOS           | `Cmd + Ctrl + V` |
| Windows / Linux | `Ctrl + Alt + V` |

按一次唤出，再按一次隐藏。`Esc` 也可以直接收起面板。面板失焦后会自动隐藏（设计上不抢长焦点）。

<Callout type="info">
  快捷键被其它应用占用了？面板"按了没反应"通常是热键冲突，不是 bug。到 [设置 —
  快捷键](../guides/settings#快捷键)改成空闲组合即可。如果根本不想要这个面板，也可以在
  [设置 — 快捷面板](../guides/settings#快捷面板) 里整体关掉它 ——
  关闭即时反注册全局快捷键。
</Callout>

<Callout type="info">
  macOS 与 Windows 上的快捷面板是随应用安装的原生面板，详见下方「macOS 与 Windows
  原生面板」一节。**下文的键位、右键菜单、筛选前缀和缩略图墙描述的是 Linux
  的面板**，与原生面板不完全相同。
</Callout>

原生 Wayland 桌面环境如果无法提供全局快捷键，可以在窗口管理器中绑定下面的命令。程序尚未运行时会启动并打开面板；程序已运行时会切换面板的显示状态：

```bash
uniclipboard --quick-panel
```

### Omarchy

UniClipboard 支持在 Omarchy 的 Hyprland 会话中显示快捷面板、跟随桌面主题，以及把选中内容粘贴回原窗口。按以下步骤将 Omarchy 自带剪贴板管理器的快捷键改为打开 UniClipboard。

编辑 `~/.config/hypr/bindings.lua`，取消 Omarchy 默认的 `Super+Ctrl+V` 绑定，再把它交给 UniClipboard：

```lua
hl.unbind("SUPER + CTRL + V") -- was: Clipboard manager
o.bind("SUPER + CTRL + V", "UniClipboard quick panel", "uniclipboard --quick-panel")
```

保存后 Hyprland 通常会自动重新加载。可以用下面的命令主动验证配置：

```bash
hyprctl reload
hyprctl configerrors
```

第二条命令没有输出即表示配置有效。GUI 正在运行时，按 `Super+Ctrl+V` 可打开或关闭快捷面板；GUI 未运行时，该命令会报错退出，而不会启动 UniClipboard。快捷面板必须在 UniClipboard 设置中保持启用。

## macOS 与 Windows 原生面板

macOS 和 Windows 安装包自带一个独立的原生面板进程，默认使用，主窗口关闭后仍随应用驻留在托盘、占用很低。想改回旧面板，可在启动应用前设置环境变量 `UC_GPUI_QUICK_PANEL=0`。内容处于锁定状态时（在主窗口输入口令之前）面板显示「应用界面已锁定」，读不到任何历史：后台会拒绝它的请求，锁定的一瞬间面板也会立刻丢弃已显示的条目、缩略图和预览。按 `Enter` 打开主窗口解锁，解锁后面板自动刷新。

Windows 上下表的 `Cmd` 换成 `Ctrl`，默认快捷键是 `Ctrl + Alt + V`。面板用系统的模拟按键把条目粘贴回原窗口；如果原窗口是以管理员身份运行的，而 UniClipboard 不是，Windows 会丢弃模拟的按键，面板会提示没有权限。第一次启动后台时，Windows 防火墙可能弹出“允许访问网络”，回答后才继续。

这把锁只管应用界面（主窗口和快捷面板）：命令行工具 `uniclip` 与其他客户端不受影响。它也不是针对本机恶意进程的防线，因为客户端类型由调用方自己声明，而后台信任持有本机连接令牌的同一系统用户；密文落盘保护不受这把锁影响。

| 按键                      | 作用                                                       |
| ------------------------- | ---------------------------------------------------------- |
| `↑` / `↓`                 | 上下移动选中项                                             |
| `Enter`                   | 粘贴选中项                                                 |
| `Shift + Enter`           | 以纯文本粘贴                                               |
| `Cmd + Enter`             | 粘贴并保持面板打开                                         |
| `Cmd + K`                 | 打开操作列表（粘贴、复制、打开、发送到设备、收藏、删除等） |
| `Cmd + 1`–`9`             | 粘贴列表中前几项；图片九宫格中粘贴当前可见的第 1–9 格      |
| `Cmd + O`                 | 打开链接或文件（图片不支持）                               |
| `Cmd + Backspace`         | 清空搜索文字和所有筛选                                     |
| `Cmd + Shift + Backspace` | 删除选中项                                                 |
| `Cmd + Shift + O`         | 打开主窗口                                                 |
| `Cmd + ,`                 | 打开设置                                                   |
| `Esc`                     | 关闭面板                                                   |

右键菜单已由 `Cmd + K` 操作列表取代。`Alt + Backspace` 不再删除条目，仍用于删除搜索框里的上一个词。

搜索框里直接输入文字检索历史，并用简写添加条件：`#标签`、`@设备`、`/类型`，`Tab` 确认。输入日期或范围（如 `9.1-9.15`、`上周`、`3d`）会建议时间条件；中文界面下也可以用拼音首字母（如 `tp` 图片、`zt` 昨天）。同一维度的多个值取「或」，不同维度取「且」；时间只有一个值，新的会替换旧的。标签之间取「且」暂不支持。

类型只选「图片」时，列表换成 3×3 九宫格：方向键在格子间移动，`Cmd + 1`–`9` 直接粘贴对应格，超过 9 张时按行滚动。历史为空、已锁定、无结果、后台未连接时，列表区会显示对应的提示页。

## 键盘操作

面板设计为完全用键盘驱动。下面这套键位可在打开后立即用：

| 按键                                    | 作用                                     |
| --------------------------------------- | ---------------------------------------- |
| `↑` / `↓`                               | 上下移动选中项                           |
| `Enter`                                 | 把选中项粘贴回上一个应用                 |
| 按住 `Option` / `Alt`                   | 请求纯文本粘贴                           |
| `Esc`                                   | 关闭面板，不粘贴                         |
| `Alt + Backspace`                       | 从历史中删除选中项                       |
| `Cmd` / `Ctrl` + `C`                    | 把选中项复制到系统剪贴板并关闭面板       |
| `Cmd` / `Ctrl` + `V`                    | 把选中项粘贴回上一个应用（等同 `Enter`） |
| `Cmd` / `Ctrl` + `1`–`9`                | 直接选第 1–9 项                          |
| `Cmd` / `Ctrl` + `0`                    | 直接选第 10 项                           |
| 直接输入                                | 即时按子串过滤（substring，大小写无关）  |
| 输入 `type:` `#` `from:` `ext:` `time:` | 行内添加筛选筹码（见下文「筛选」）       |

`Cmd` / `Ctrl` + `C` 与 `Cmd` / `Ctrl` + `V` 作用于当前 hover 或键盘选中的条目；但如果你正在编辑搜索框（选中了一段文字，或粘贴时查询词非空），会让位给搜索框原生的文本选中复制/粘贴行为。

`Enter` 的粘贴是通过模拟系统粘贴完成的，所以接收方应用感知到的是"用户刚按了 Cmd/Ctrl+V"，富文本与文件类型也会按目标应用支持的最高保真表示落地。

如果想粘贴纯文本，确认条目时按住 `Option` / `Alt`：可以按 `Enter`、点击条目，或继续使用
`Cmd` / `Ctrl` + 数字快捷键。UniClipboard 会先只把 `text/plain` 表示写回系统剪贴板；如果条目没有纯文本表示，则静默回退到普通多格式粘贴。

## 右键操作

右键任意条目——列表行或图片墙的 tile——可打开上下文菜单。右键会同时选中该条目，所以高亮的那条始终就是菜单作用的对象。

| 操作            | 说明                                                                         |
| --------------- | ---------------------------------------------------------------------------- |
| 复制            | 把该项放回系统剪贴板（不粘贴），随后关闭面板。已失效条目（负载丢失）会灰显。 |
| 收藏 / 取消收藏 | 切换收藏标记。已收藏的条目会在列表里显示 ★。                                 |
| 发送到设备      | 把该项派发给某个已配对设备——或全部设备——**不**动本机剪贴板。离线对端不可点。 |
| 打开文件位置    | 仅文件条目：在系统文件管理器中定位收到的文件。                               |
| 粘贴文件路径    | 仅文件条目：把本地路径直接输入到上一个应用，不改变系统剪贴板。               |
| 删除            | 立即从历史中移除该项——等同 `Alt + Backspace`，无确认。                       |

这些与主窗口历史卡片上的逐项操作一致，所以临时复制、收藏或重发一条时不必再打开主窗口。

## 内嵌预览

选中一项后，右侧预览面板会按内容类型自动选择渲染方式：

| 表示类型    | 预览形态                                          |
| ----------- | ------------------------------------------------- |
| 纯文本      | 等宽字体；超大文本（>50KB）走虚拟化滚动           |
| 链接        | 提取域名 + 完整 URL                               |
| 图片        | 内嵌缩略，按比例适配预览区，附带尺寸              |
| 代码 / HTML | 与文本一致的渲染（不做语法高亮）                  |
| 文件        | 文件名 + 图标；图片文件显示缩略图；多文件按行排列 |

超过 8 MB 的图片不会自动拉取——预览面会改为显示 **加载图片** 按钮，避免大原图阻塞预览；点击后再按需拉取完整图片。

预览 **只读**。要把项目放回系统剪贴板或粘贴出去，回到列表按 `Enter`。

## 筛选

搜索框是一个复合筛选栏。直接输入即按子串匹配，再叠加以筹码（chip）形式呈现的**结构化筛选**。共有五个维度：

- **类型**：文本 / 富文本 / 图片 / 文件（旧的 `链接` / `代码` 筹码仍可解析）。
- **标签**：语义标签，如 `link`、`code`。
- **来源**：条目被捕获的设备。
- **扩展名**：文件扩展名，仅对文件类负载有意义。
- **时间**：今天、昨天、近 7 天、近 30 天、本周、本月。

添加筹码有两种方式：点搜索框末尾的**筛选按钮**选值，或输入前缀再从建议里选：

```text
type:image
#link
from:<设备>
ext:pdf
time:last_7d
```

筹码可叠加（多个筛选之间是 AND），每个都带 ✕ 可清除。筹码之外的普通词按子串匹配；不支持引号短语、布尔操作符、正则 —— 详见 [全文搜索 — 查询语法](./search#查询语法)。

### 图片筛选 — 缩略图墙

列表里的图片条目通常在类型图标位置展示一枚小缩略图，让你不用打开预览也能一眼认出是哪张截图。当**图片**类型筹码固定时，列表切换为**三列瀑布流缩略图墙**，每个 tile 按图片自身比例排布——方便一次扫过多张最近截图。方向键仍按时间顺序导航，`↑` / `↓` 与 `Cmd`/`Ctrl` + `1`–`9` 的行为跟列表视图一致。

筛选写在内存里，关闭面板后 **不持久** —— 下次打开是无筛选状态。这是刻意的：面板是即用即抛的入口，不当工作台用。

<Callout type="info">
  CLI 端的等价能力是 `uniclip search`，参数与上面对应：`--type` / `--ext` /
  `--from-ms` / `--to-ms`。详见 [CLI 参考 — 搜索](../cli/reference#搜索)。
</Callout>

## 自定义快捷键

已录制的按键组合仍是主要触发方式。在 **设置 → 快捷面板 → 双击修饰键** 中，还可以选择 Option/Alt、Control 或 Command/Windows/Super，连续轻按两次该修饰键即可打开面板。关闭此选项不会影响已录制的快捷键。

macOS 上的双击修饰键需要单独授予 **辅助功能（Accessibility）** 权限。UniClipboard 只会静默检查权限状态，不会在后台弹系统授权框；请主动点击 **打开辅助功能设置** 完成授权。原生 Wayland 会话暂不支持该触发方式，即使会话同时提供 XWayland 的 `DISPLAY` 也会明确显示为不支持，此时继续使用已录制的快捷键。

<Tabs items={['路径', '常见可用组合']}>

<Tab value="路径">

**设置 → 快捷键 → 全局 → 唤起快捷面板**

记录器直接接受按键组合：按下你想用的组合即可，冲突会即时提示。也可以录制**两段式**快捷键：再按一个组合让第一段成为 leader 键，或连按两次同一组合作为"双击"。`重置`回默认，`清空` 让该项不绑定（此时只能从托盘菜单或 GUI 主窗口打开）。

- Windows：`Win+V`（与系统剪贴板历史冲突，关掉 Windows 那个再用）、`Ctrl+Shift+V`

## 何时用面板，何时回主窗口

| 你想做的事                         | 推荐入口                                                 |
| ---------------------------------- | -------------------------------------------------------- |
| 立刻粘贴最近的某一项               | 快捷面板                                                 |
| 跨多设备查找几天前的内容           | 快捷面板筛选（类型 / 来源 / 时间）/ CLI `uniclip search` |
| 长时间整理、批量删除、导出         | 主窗口仪表盘                                             |
| 配置筛选规则、按设备的内容类型限制 | [设备页](./devices) / [设置](../guides/settings)         |

## 排查

- 已录制的快捷键没反应：先看 [故障排查 — 剪贴板权限](../help/troubleshooting#剪贴板权限)，macOS 还要确认 **输入监控** 已授权并彻底重启过应用。
- macOS 上双击修饰键被禁用：点击设置旁的按钮授予 **辅助功能** 权限，然后返回 UniClipboard。Linux 原生 Wayland 会话会明确显示此触发方式不受支持，已录制的快捷键仍可使用。
- 面板里看不到刚复制的内容：守护进程没起或剪贴板监听被系统隔离。`uniclip space status` 看 `daemon.running` 与剪贴板监听日志。
- 同步过来的项目从未出现在面板：可能在发送端被设备规则挡掉了，到对端的 [设备 → 内容类型白名单](./devices#内容类型白名单) 检查。
