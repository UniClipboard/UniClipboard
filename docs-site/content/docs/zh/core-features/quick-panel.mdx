---
title: 快捷面板
description: 在任意应用中用全局快捷键呼出历史，选中后回车直接粘贴。
---

快捷面板是桌面端的一个轻量历史窗口：在任意应用里按下快捷键，搜索或挑选一条历史，按回车即可粘贴到原来的应用。它只在桌面端（`unic-desktop`）提供，纯 CLI / 无头部署没有快捷面板。

## 呼出面板

| 平台 | 默认快捷键 |
|---|---|
| macOS | `⌘ ⌃ V`（Command+Control+V） |
| Windows / Linux | `Ctrl Alt V` |

也可以从托盘菜单或「设置 > 快捷面板」中的按钮打开。面板可见时再次按下同一快捷键会关闭面板。

<Callout>
快捷键由托盘进程注册。普通模式下关闭主窗口后快捷键仍然可用；轻量模式关闭后只剩后台服务 `unicd`，所有桌面快捷键都会释放，需重新打开桌面端。
</Callout>

## 面板内操作

| 按键 | 作用 |
|---|---|
| `Enter` | 把选中条目写入剪贴板，回到原应用并粘贴 |
| `Shift+Enter` | 以纯文本粘贴（去掉富文本格式）；图片、文件及仅有 HTML 的条目不支持 |
| `Cmd+Enter` / `Ctrl+Enter` | 粘贴后重新打开面板，方便连续粘贴多条 |
| 复制 | 只写入剪贴板，不模拟按键 |
| `Esc` | 关闭面板，并在 unic 仍处于前台时把焦点还给原应用 |

面板的搜索与主窗口使用相同的服务端搜索，语法见[搜索语法](../reference/search-syntax)。

面板粘贴前会确认目标应用仍在前台、剪贴板内容未被替换；任何一步失败（目标退出、焦点被抢、权限缺失、你切换了窗口等）都不会自动重试粘贴，此时内容可能已写入剪贴板，可手动粘贴。从 unic 自己的窗口打开面板时没有可粘贴的目标，只能复制。

## 自定义快捷键

在「设置 > 快捷键」中可为每个操作录制一到两组组合键（两步序列在第一步后 1 秒内有效）。除打开面板外，还可绑定「显示主窗口」「在快捷面板中打开收藏」，二者默认未绑定。设置会拒绝互相冲突或互为前缀的绑定。

如果系统拒绝注册新快捷键，unic 会保留之前生效的绑定，并在「设置 > 快捷面板」显示注册结果，可点击重试。

对应的配置项（`config.toml`）：

```toml
[desktop]
quick_panel_shortcut = "Ctrl+Alt+V"   # macOS 默认 "Cmd+Ctrl+V"
quick_panel_double_tap = ""           # off、alt、control 或 meta

[desktop.shortcuts]
"clipboard.search" = ["mod+f"]        # 空数组 [] 表示禁用该绑定
```

`quick_panel_double_tap` 可开启“连按两次修饰键”打开面板，默认关闭；macOS 需要辅助功能权限，Wayland 不支持。完整配置说明见[配置文件](../reference/configuration)。

## 平台差异与权限

<Tabs items={['macOS', 'Windows', 'Linux']}>
<Tab value="macOS">
自动粘贴需要授予 unic「辅助功能」权限。「设置 > 快捷面板」会显示当前权限状态，并提供刷新和打开系统设置的按钮；查看状态不会触发授权请求。
</Tab>
<Tab value="Windows">
无需额外权限。
</Tab>
<Tab value="Linux">
X11 支持自动粘贴。Wayland 下快捷键通过系统门户注册，但无法捕获目标窗口或模拟按键，**只能复制**，自动粘贴不可用。
</Tab>
</Tabs>

<Callout type="warn">
快捷面板的进程集成已实现，但在各平台真实应用中的实际粘贴、权限流程和不同键盘布局尚未全部完成原生验收。
</Callout>

## 隐私

目标应用的名称、窗口标识和剪贴板指纹只保存在内存中，不写入日志，也不进入统计数据；不统计粘贴是否成功。
