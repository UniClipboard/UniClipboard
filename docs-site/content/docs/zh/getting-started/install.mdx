---
title: 安装
description: 在 macOS、Windows 或 Linux 上安装 UniClipboard。
---

按你的平台选择构建版本。

## macOS

从 Releases 页面下载最新 `.dmg`，把应用拖入 `/Applications`，并在首次启动时
授予「辅助功能」与「输入监控」权限。

## Windows

下载 `.msi` 安装包或便携版 `.zip`，两者均已签名。

## Linux

推荐使用 Snap，也可使用 AppImage：

```bash
snap install uniclipboard
```

安装完成后，前往[快速开始](./quick-start)。
