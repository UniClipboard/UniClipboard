<Steps>
<Step>
### 运行 UniClipboard

在两台设备上分别按[安装](./install)运行桌面端。首次启动会显示初始设置，如检测到 v1 数据可选择离线导入历史。
</Step>
<Step>
### 连接第二台设备

在第一台设备上打开 **设备 → 添加设备**，记下 6 位配对码，在第二台设备上输入。两边显示相同的指纹后，分别点击 **接受**。

<Callout>
通过配对码加入的设备始终需要你手动批准。
</Callout>
</Step>
<Step>
### 复制

在一台设备上按 `Ctrl+C`（macOS 为 `⌘C`），在另一台设备上按 `Ctrl+V`（`⌘V`）即可。
</Step>
</Steps>

## 常用操作

- **快捷面板**：在任意应用中按 `⌘ ⌃ V`（Windows / Linux 为 `Ctrl Alt V`），选中条目回车即可粘贴。见[快捷面板](../core-features/quick-panel)。
- **搜索历史**：输入关键词，或用 `#标签`、`@设备`、`/类型` 过滤。见[历史与搜索](../core-features/history-and-search)。

## 用命令行

```sh
unic send --to all "Hello"        # 发送到所有已配对设备
unic send --to all -f ./photos    # 发送文件或文件夹
unic send "temporary"             # 免配对：打印 6 位取件码
unic recv 482913                  # 用取件码接收
unic history list                 # 浏览历史
```

`unic` 在需要时会自动启动同目录下的临时 `unicd`，用完后自动停止。首次在新数据目录使用命令行前，请先运行 `unic init` 完成初始化（若检测到 v1 数据会引导选择导入或全新开始；也可直接运行 `unic migrate` 导入 v1 历史）。详见[命令行入门](../cli/getting-started)。
