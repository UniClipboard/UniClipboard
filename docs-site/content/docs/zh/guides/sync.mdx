---
title: 同步内容
description: 剪贴管线支持的负载类型。
---

UniClipboard 把剪贴板内容标准化成一组表示，并把每种表示作为独立负载同步，
让粘贴目标拿到它能理解的最丰富格式。

| 类型      | 说明                                          |
| --------- | --------------------------------------------- |
| 纯文本    | UTF-8，作为通用兜底始终可用。                 |
| RTF / HTML| 一同传输，让富格式粘贴跨设备保留格式。        |
| 文件      | 支持多文件选择；接收端按序重建。              |
| 图片      | PNG / JPEG / WebP，按内容哈希传输。           |

大负载会分块传输，并在重连后续传。
