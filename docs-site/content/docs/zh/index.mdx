UniClipboard 让文本、文件和富格式剪贴内容在你的多台设备之间保持同步——
完全不依赖第三方服务器。

## 为什么选择 UniClipboard

- **本地优先。** 所有同步走局域网，剪贴内容不出网。
- **跨平台。** macOS、Windows、Linux 共享同一条剪贴流。
- **富内容。** 文件、图片、RTF、HTML——不止于纯文本。
- **键盘优先。** 为键盘流打造的快速面板。
