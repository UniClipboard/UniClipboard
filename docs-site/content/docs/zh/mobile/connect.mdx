---

UniClipboard 移动 App 是一个纯局域网 / 自建服务器的同步客户端。它不加入桌面的
加密空间，也不跑 P2P 节点——它连接的是一台运行 UniClipboard **桌面端并开启了
「手机同步」** 的电脑，之后所有内容都经这台电脑中转。两部手机之间不会互相同步，
各自跟桌面通信。

首次连接大致就是：在桌面拿到一份一次性凭据，再让手机通过扫码或手动填写把它录进来。

<Steps>

<Step>

### 在桌面端拿到凭据

先在电脑上打开 UniClipboard 桌面端，进入 **设备 → 手机同步 → 添加设备**。
桌面会弹出一次性凭据（服务器地址 + 用户名 + 密码）和一个二维码，用于这一台手机接入。

- 桌面侧如何开启手机同步、这份凭据里各字段是什么意思，见
  [移动端同步](../core-features/mobile-sync) 与 [配对与同步](../guides/pairing)。
- 手机与电脑需要在**同一个 Wi-Fi** 下，或都接入同一个 Tailscale / VPN。跨网络访问
  见 [用 Tailscale 打通手机与桌面](../guides/tailscale) 或 [自建 server 节点](../guides/self-host-server-node)。

弹窗里的**明文密码通常只显示一次**。如果没扫成或没填成，可以在桌面重新添加设备 /
轮换密码再拿一份新的。

</Step>

<Step>

### 方式一：App 内扫码（推荐）

装好 App 后，在连接界面选**扫码**，把镜头对准桌面弹出的二维码。

- 首次扫码需要授予**相机权限**。光线暗时可以打开界面上的**手电筒**。
- 扫码成功后，**服务器地址、用户名、密码会自动填好**，确认保存即可。
- 扫不动、镜头不方便，或二维码显示不全时，选**改为手动填写**转到方式二。

</Step>

<Step>

### 方式二：手动填写表单

如果不方便扫码，就手动录入桌面弹窗里的那几项。表单字段：

| 字段           | 说明                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 名称           | 给这个桌面起个好认的名字（如「家里的 Mac」），只用于你自己区分。                                                               |
| 服务器地址     | 桌面弹窗里的地址，形如 `http://192.168.1.5:42720`。**可以添加多条备用地址**（如局域网、Tailscale、公网各一条），第一条为默认。 |
| 允许不安全证书 | **仅当**桌面走的是自签名 HTTPS 才需要打开；纯 HTTP 地址不用管它。                                                              |
| 用户名         | 桌面弹窗里的用户名。                                                                                                           |
| 密码           | 桌面弹窗里的一次性密码（HTTP Basic Auth）。                                                                                    |

多条备用地址用于你在不同网络下都能连上同一台桌面：在家走局域网、在外走 Tailscale
或公网网关。填几条无妨，App 会自动选路。

</Step>

<Step>

### 测试连接与多地址自动择优

保存前可以点**测试连接**，确认地址、账号密码都对。

如果你填了多条备用地址，App 会**按当前所在网络自动挑选能拨通的那一条**，界面上会标注
**「将使用」** 哪个地址，你不用手动切换。换了网络后它会重新选路。

连不上时，先确认手机和电脑在同一 Wi-Fi、桌面端已开启手机同步、地址和端口没填错；
提示鉴权失败一般是用户名或密码不对（可在桌面轮换密码后重填）。

</Step>

<Step>

### 连接多台桌面 / 切换服务器

你可以同时保存多台桌面的凭据。要再加一台，重复上面的扫码或手动流程即可。

在主界面**顶栏点当前服务器名**，会弹出切换面板，可以在多台桌面之间**切换**、**删除**
某台，或**扫码新增**。所有凭据都保存在手机本地。

</Step>

</Steps>

<Callout type="info">
  桌面弹出的二维码用的是 `uniclipboard://connect` 深链接格式。它的完整规范只对「想自己
  写一个兼容客户端」的人有意义，普通使用不用关心——详见
  [移动端扫码接入协议](../reference/mobile-connect-uri)。
</Callout>

连上之后，就可以开始收发剪贴内容了。下一步看 [日常使用](./daily-use)。
