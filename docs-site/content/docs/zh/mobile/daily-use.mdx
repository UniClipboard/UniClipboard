连接好桌面之后（还没连的话先看 [连接桌面](./connect)），你几乎所有操作都在
主界面完成：看历史、上传内容、控制同步。

## 主界面

打开 App 就是剪贴历史，以卡片网格呈现，每张卡片是一条剪贴内容（文本、图片
或单个文件），新的在前。顶栏有三样东西：

- **搜索** —— 按内容过滤历史。
- **当前服务器名** —— 点它弹出切换面板，在多台桌面之间切换（详见
  [连接桌面](./connect)）。
- **连接状态点** —— 指示当前与桌面的连接是否正常。

历史可以按类型筛选（文本 / 图片 / 文件），只看你关心的那一类。

## 添加内容

右下角的 **添加** 悬浮按钮（FAB）展开后有 5 项：

| 操作         | 作用                               |
| ------------ | ---------------------------------- |
| 拍照         | 现拍一张照片并上传                 |
| 从相册选图片 | 从系统相册挑一张已有图片上传       |
| 选择文件     | 挑一个文件上传                     |
| 上传剪贴板   | 把手机当前的系统剪贴板内容上传     |
| 立即同步     | 立刻和桌面做一次收发，不等自动同步 |

选完之后内容会立刻出现在历史里（见下方 [落库即完成](#落库即完成与时钟角标)），
再由后台推送到桌面。

## 通过系统分享上传

不必先打开 UniClipboard。在**任何** App 里点系统分享按钮，从分享面板里选
**UniClipboard**，就能把当下这条内容（文本、链接、图片、文件）发过来。

<Steps>

<Step>

### 在来源 App 里分享

在浏览器、相册、文件等 App 里点系统分享，选择 UniClipboard。

</Step>

<Step>

### 内容立刻落到本地历史

分享的内容瞬时写入 UniClipboard 的历史，无需等待网络。

</Step>

<Step>

### 随即回到来源 App

分享面板关闭、你回到刚才那个 App 继续做事。推送到桌面这一步交给后台，
不占用你的时间。（截图、系统分享等场景下界面可能会停留在 App 内。）

</Step>

</Steps>

<Callout type="info">
  iOS 上分享扩展装好 App 后自动出现在系统分享面板，无需在设置里开启。如果它
  排得靠后，可以在分享面板里手动把它「设为常用」拖到前面。详见 [iOS 扩展](./ios-extensions)。
</Callout>

## 落库即完成与时钟角标

无论是 FAB 上传还是系统分享，UniClipboard 都是**先落本地、后台再推**：内容
一进历史就算完成，你能马上看到它。

推送尚未成功的卡片，右下角会有一个**时钟图标**，表示「待上传 / 待同步」。
后台会自动重试，一旦推送到桌面成功，这个角标就消失。所以看到时钟不用管，
它自己会清掉；持续不消失才说明连接有问题（见 [故障排查](./troubleshooting)）。

## 前台自动同步

主界面有一个自动同步开关。打开后，只要 App 在前台，它会同时做两件事：

- **自动应用远端** —— 桌面上的新剪贴内容自动进入手机。
- **自动推送本机** —— 手机上新复制的内容自动发往桌面。

<Callout type="info">
  这个前台开关只在 App 打开着的时候生效。要在 App 不在前台、甚至锁屏时也能收发， iOS 靠键盘 /
  分享扩展与后台配置，Android 靠后台剪贴板访问 —— 分别见 [iOS 扩展](./ios-extensions) 与 [Android
  后台访问](./android-access)。
</Callout>

## 卡片详情操作

点开任意一张卡片进入详情，可以：

- **复制** —— 把这条内容写回手机系统剪贴板。
- **保存图片到相册** —— 图片类内容。
- **保存文件** —— 文件类内容。
- **删除** —— 从历史里移除这条记录。

## 支持的内容类型

UniClipboard 移动 App 同步三类内容：

- **文本**（含链接）
- **图片**
- **单个文件**
