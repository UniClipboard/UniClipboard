这一页逐条列出移动 App 的设置项，说明每一项管什么。iOS 与 Android 的设置结构不同：Android 是一个设置 Hub 分成若干子页，iOS 是一张分页列表。下面按端分列。

跨端含义相同的项，在其中一端展开解释，另一端只做引用，不重复。

<Tabs items={['iOS', 'Android']}>

<Tab value="iOS">

### 服务器

- **服务器列表** —— 你连接过的桌面端。可增删、切换默认服务器、扫码新增。也可以从主界面顶栏点当前服务器名快速切换。凭据只保存在这台手机上。新增连接的完整步骤见 [连接桌面](./connect)。

### 同步

三个独立开关，控制这台手机与桌面之间的数据流向：

| 开关 | 作用 | 默认 |
| --- | --- | --- |
| 自动写入本机剪贴板 | 把远端最新内容自动写进 iOS 系统剪贴板。**关掉后**，远端内容只在主界面里高亮显示，不会覆盖你手机上现有的剪贴板。 | 开 |
| 自动推送本机剪贴板 | App 在前台时，把你手机上复制的内容自动推给桌面。 | 关 |
| 实时推送（SSE） | 通过服务端推送即时收到新内容，而不是定时轮询。需要桌面端支持；不支持时**不会**自动回退到轮询。 | 开 |

<Callout type="info">
  如果远端内容始终不进你的系统剪贴板，先确认「自动写入本机剪贴板」是开着的。iOS 还需要在「剪贴板访问」里授权一次「从其他 App 粘贴」，App 才能读你复制的内容往上推。
</Callout>

### 扩展与权限

- **键盘** —— 自定义键盘扩展的启用引导与状态显示。
- **分享** —— 系统分享面板里的分享扩展。
- **剪贴板访问** —— 触发一次 iOS 的「从其他 App 粘贴」授权，App 才能读取系统剪贴板往上推送。

键盘和分享扩展的详细配置见 [iOS 扩展](./ios-extensions)。

### 其他

- **存储** —— 查看缓存 / 日志 / 历史的占用。
- **外观** —— 外观模式：跟随系统 / 浅色 / 深色。
- **语言** —— 简体中文 / English。
- **启动时检查更新** —— 打开 App 时检查有没有新版本。
- **关于** —— 版本号等信息。

</Tab>

<Tab value="Android">

Android 的设置是一个 Hub，点进各个子页。

### 同步

- **服务器管理** —— 服务器列表，增删 / 切换。也可从主界面顶栏点当前服务器名快速切换。新增连接见 [连接桌面](./connect)。
- **自动同步** —— 一个开关同时开启「自动应用远端」+「自动推送本机」（App 在前台时）。

高级项：

| 项 | 作用 |
| --- | --- |
| 同步 Toast 通知 | 同步发生时弹 Toast 提示。 |
| 允许自动同步的数据大小上限 | 超过这个大小的内容不自动同步，避免大图大文件占用网络。 |
| 实时推送（SSE） | 通过服务端推送即时收到新内容，而不是轮询。需要桌面端支持；不支持时不会自动回退。默认开。 |
| 远程轮询间隔 | 没有实时推送时，多久拉一次远端。 |
| 本地轮询间隔 | 多久检查一次本机剪贴板变化。 |

### 历史记录

- **最多保留条数** —— 剪贴历史保留的上限，默认 1000 条，超出后自动清理最旧的。

### 后台运行

控制 App 不在前台时的后台剪贴板读写与保活。总开关「后台自动同步」会依次引导你忽略电池优化、开通知权限、开悬浮窗权限。高级项包括常驻通知、忽略电池优化、后台下载远程、后台上传本机、以及后台剪贴板访问方式（悬浮窗 / Shizuku）。

后台默认全部关闭。完整说明见 [后台剪贴板访问](./android-access)。

### 短信转发

- **自动上传短信验证码** —— 收到短信验证码时自动推给桌面。需要短信权限。

### 外观

- **外观模式** —— 跟随系统 / 浅色 / 深色。
- **在最近任务列表中隐藏** —— 让 App 不出现在系统的最近任务（多任务）列表里。

### 其他

- **语言** —— 简体中文 / English。
- **存储** —— 查看缓存 / 日志 / 历史的占用。
- **关于** —— 版本号、主页链接。
- **开发者选项** —— 日志、调试、添加桌面快捷方式等。一般用户用不到。

</Tab>

</Tabs>

## 默认值速查

| 项 | iOS | Android |
| --- | --- | --- |
| 自动写入远端 → 本机 | 开 | 随「自动同步」总开关 |
| 自动推送本机 → 远端 | 关 | 随「自动同步」总开关 |
| 实时推送（SSE） | 开 | 开 |
| 后台剪贴板任务 | 无此概念 | 默认关；访问方式默认悬浮窗 |
| 历史保留上限 | —— | 1000 条 |
