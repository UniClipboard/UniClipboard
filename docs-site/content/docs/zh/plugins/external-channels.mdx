---
title: 外部渠道
description: 通过同步后端插件与没有 unic 身份的第三方服务互相同步剪贴板。
---

**外部渠道**是一类特殊的同步对象：对方不是运行 unic 的设备，而是第三方服务或应用（例如某个输入法的剪贴板同步组）。它们没有 unic 的设备密钥，也无法核对指纹，所以 unic 不把它们当作设备，而是单独作为“渠道”管理。

你可以在[插件市场](./marketplace)安装 SyncClipboard 或微信输入法剪贴板插件。配好插件后，可在桌面端的 **设备** 中查看和管理外部渠道。

## 与设备有什么不同

| | unic 设备 | 外部渠道 |
|---|---|---|
| 身份 | 设备密钥与指纹 | 无，不核对指纹 |
| 授权方式 | 配对码 + 你的批准 | 在对方服务里完成配对，再在 unic 里启用 |
| 发送目标 | 单台设备 | 一个组；组内成员只作展示，不能单独授权 |
| 移除 | 撤销信任，对方也断开 | 只在本机生效（取决于后端能力） |

在对端列表中，渠道和设备混排显示，详情会标明所属后端和目标类型。

## 配对与启用

按插件详情中的步骤配置渠道。SyncClipboard 使用插件配置的客户端凭据。微信输入法共享空间使用微信输入法提供的配对码。打开桌面端的 **设置 → 插件 → 微信输入法剪贴板**，按提示加入共享空间。也可以从命令行对支持配对码的后端执行：

```sh
unic channel pair <后端实例 ID>            # 按提示输入对方服务的配对码
unic channel pair <后端实例 ID> --resume   # 继续一次尚未完成的配对
```

启用渠道即表示你允许本机与它同步。如果后端要求对方批准，请在对方服务中完成该步骤。

<Callout type="info">
发往外部渠道的内容会进入第三方服务。内容类型取决于插件能力和同步设置。SyncClipboard 和微信输入法剪贴板支持文本和图片。能否把单个图片文件作为图片发送，取决于插件是否声明该能力以及图片同步是否开启。
</Callout>

## 收到的内容

- 渠道有“自动写入剪贴板”开关，默认开启。关闭后，收到的内容只进入历史，不写入剪贴板。
- 收到的内容照常经过处理插件并进入历史，来源标为 `external:<后端实例>`，不归属任何设备。
- 同一份内容经 tailcat 和外部渠道各到达一次时，只保存一次。
- 回执的含义由后端决定。例如某些服务的回执只表示“已送达服务端”，并不代表对方已经写入剪贴板。

## 停用与移除

- **停用**：立即停止该渠道的发送和接收，丢弃进行中的任务。
- **移除**：停止同步并移除本机的渠道记录。插件管理服务端凭据。

后端插件会声明是否支持远端退出（`remote_revocation`）。不支持时，移除**只在本机生效**，本设备仍留在对方的组里，需要你到对方的官方应用中移除本设备。已经发出的内容无法撤回。

凭据和服务端地址保存在该后端实例的私有目录，不会出现在日志、事件或错误信息中。

## 开发渠道后端

渠道后端是声明了 `external_channels` 的 Go 同步后端插件，通过插件 RPC 与 unic 通信。插件基础见 [Go 插件开发](./develop-go)；同步后端的接口仍在演进，开发前请阅读仓库中的 `docs/contracts/sync-backend-contract.md` 与 `docs/contracts/plugin-contract.md`。
