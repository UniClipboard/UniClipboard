---
title: 命令行（uc-cli）
description: 通过命令行控制 UniClipboard 守护进程。
---

`uc-cli` 通过本地 IPC socket 与守护进程通信，适合脚本、无界面服务器
以及不带 GUI 的 CI 流程。

## 常用命令

```bash
uc-cli status              # 守护进程健康状态与对端列表
uc-cli copy "hello"        # 把内容写入本机剪贴板
uc-cli paste --latest      # 把最新一条剪贴内容打到 stdout
uc-cli peers ls            # 查看已配对设备
uc-cli send <peer> --file PATH
```

执行 `uc-cli --help` 查看完整命令面。
