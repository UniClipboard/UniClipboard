---
title: 搜索语法
description: 桌面端历史搜索框的关键词、筛选前缀与匹配规则。
---

搜索在本机历史上进行，由服务端维护索引；不会上传任何内容。

## 关键词

- 用空格分隔多个关键词，**所有关键词都必须出现在同一条历史中**。
- 匹配为不区分大小写的子串匹配，中文一两个字也能命中。
- 用引号把含空格的短语作为一个关键词：`"meeting notes"`。用 `\` 转义单个字符。
- `%`、`_`、引号、标点以及 `AND`/`OR` 等都按字面匹配，不是通配符或运算符。
- 不做重音或 Unicode 形式归一化，也不支持拼音匹配。

搜索的内容：

| 类型 | 被搜索的部分 |
|---|---|
| 纯文本 | 全文 |
| 仅 HTML | 去除标签、脚本、样式后的可见文本 |
| 文件 | 每个文件的**文件名**（不读取文件内容） |
| 图片 | 不搜索像素内容（无 OCR） |

## 筛选前缀

在搜索框中输入以下前缀会弹出候选列表，选中后变为筛选条件：

| 前缀 | 维度 | 示例 |
|---|---|---|
| `/` | 类型：文本、富文本、图片、文件、文件夹 | `/image` |
| `#` | 标签 | `#Issue` |
| `@` | 来源设备（本机、其它设备、外部渠道、迁移导入） | `@laptop` |
| `on:` | 时间：今天、昨天、最近 7 天、最近 30 天、本周、本月 | `on:today` |
| `ext:` | 文件扩展名（小写，不带点） | `ext:pdf` |

规则：

- 不同维度之间是“且”的关系。
- 主窗口中多个标签要求**同时具备**；快捷面板中的标签为“任一”。
- 时间按本地日历计算，每周从周一开始。
- 输入未加引号的 `#favorite` 等同于只看收藏。

也可以通过搜索框旁的筛选菜单选择这些条件，菜单会显示每个选项的匹配数量。

## 快捷面板

快捷面板把整个输入当作一个字面短语匹配，不拆分关键词。

## 限制

- 最多 16 个关键词；单个关键词不超过 4096 字节，合计不超过 8192 字节。
- 每个筛选维度最多 64 个值。
- 单次搜索超时 2 秒。
- 若部分历史未能建立索引，文本与扩展名搜索会提示不可用，而不是返回不完整的结果；按类型、标签、时间等浏览仍可使用。

<Callout>
命令行目前没有全文搜索命令；`unic history list` 支持 `--type`、`--tag`、`--origin` 筛选，见 [CLI 参考](../cli/reference)。
</Callout>
