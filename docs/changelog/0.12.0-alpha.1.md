## 0.12.0-alpha.1 - 2026-05-28

### Features

- Add a dedicated update window that shows release notes and download progress instead of relying on system notifications (#854)
- Add a macOS receive panel for incoming file transfers with progress, speed, remaining time, and a cancel button (#848)
- Make mobile sync setup scan-first, with client download options, selectable connection addresses, hidden manual credentials, and one dialog for mobile device details and actions (#883)

### Fixes

- Prevent secure storage failures on some Linux desktops from interrupting unlock or space switching (#882)
- Restore pending space migration after manual or silent unlock so history and pairing state can recover after an interrupted migration (#857)
- Improve local network file transfers by keeping them on the local route when one is available (#852)
- Stop empty placeholder files from third-party clipboard tools from triggering repeated remote file transfers (#849)
- Avoid repeated waits when copying while a paired device is offline (#863)
- Make repeated copies to an offline device return faster by sharing the same reachability check and shortening the retry window (#889)
- Fix rich text and non-ASCII link syncing across platforms so Windows HTML no longer grows nested wrappers and Linux or macOS links keep readable characters (#862)
- Show the update window when the main window is reopened after an update check, and make the update window follow the user's theme (#865)
