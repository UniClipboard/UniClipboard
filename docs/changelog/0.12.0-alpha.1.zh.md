## 0.12.0-alpha.1 - 2026-05-28

### Features

- 新增独立更新窗口，可查看更新内容和下载进度，不再只依赖系统通知 (#854)
- 在 macOS 上新增接收文件浮窗，可查看进度、速度、剩余时间，并可直接取消接收 (#848)
- 移动端同步设置改为优先扫码，并提供客户端下载入口、连接地址选择、折叠的手动凭据，以及统一的移动设备详情与操作窗口 (#883)

### Fixes

- 修复部分 Linux 桌面上的安全存储故障，避免解锁或切换空间被中断 (#882)
- 修复手动或静默解锁后未继续恢复空间迁移的问题，让中断迁移后的历史记录和配对状态可以恢复 (#857)
- 改进局域网文件传输，在可用时优先保持本地网络路径 (#852)
- 忽略第三方剪贴板工具产生的空占位文件，避免反复触发远端文件传输 (#849)
- 修复已配对设备离线时，每次复制都可能反复等待的问题 (#863)
- 多次复制到离线设备时会更快返回，并减少重复的可达性检查 (#889)
- 修复跨平台同步富文本和非 ASCII 链接时的问题，避免 Windows HTML 反复嵌套，并保留 Linux 或 macOS 链接中的可读字符 (#862)
- 主窗口重新打开并触发更新检查后会显示更新窗口，且更新窗口会跟随用户选择的主题 (#865)
