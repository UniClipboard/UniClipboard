## 0.14.0-alpha.5 - 2026-06-05

### Features

- Add a tray Lightweight Mode that closes the window while keeping background sync running, with a one-time notification explaining how to reopen the app.
- Large image previews now show their size first and only load the full image after you choose to load it.

### Fixes

- Quit now fully stops UniClipboard from the tray, Cmd-Q, the app menu, or terminal shutdown, while closing the window, restarting, or using Lightweight Mode keeps background sync running.
- Keep the clipboard list accurate after the background sync connection reconnects, including items copied while the connection was down.
- Prevent rapid clipboard activity from causing local connection limit errors in the desktop app.
- Fix creating spaces, saving settings, and other actions that send data from the desktop app.
- Fix member sync preference changes so the device page keeps showing the updated settings after saving.
- Fix clipboard capture crashes on X11-based Linux desktops when copying plain text from some apps.
