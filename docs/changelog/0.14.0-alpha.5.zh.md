## 0.14.0-alpha.5 - 2026-06-05

### Features

- 托盘菜单新增“轻量模式”，可关闭窗口但保持后台同步运行，并通过一次性通知说明如何重新打开应用。
- 大图片预览现在会先显示图片大小，并只在你选择加载后才加载完整图片。

### Fixes

- 通过托盘、Cmd-Q、应用菜单或终端关闭时，现在会完整退出 UniClipboard；关窗、重启或使用轻量模式时仍会保持后台同步运行。
- 后台同步连接重新连上后，剪贴板列表会重新同步，包含断开期间复制的内容。
- 修复桌面应用中快速连续复制时可能触发本机连接限制错误的问题。
- 修复桌面应用中创建空间、保存设置等需要发送数据的操作可能失败的问题。
- 修复成员同步偏好保存后，设备页面没有继续显示最新设置的问题。
- 修复基于 X11 的 Linux 桌面在从部分应用复制纯文本时可能崩溃的问题。
