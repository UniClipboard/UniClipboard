## 0.16.0-alpha.1 - 2026-06-23

### Breaking Changes

- CLI 用法已调整：切换空间请使用 `uniclip join --switch`，搜索请使用 `uniclip search <query>`，不再使用 `uniclip switch-space` 和 `uniclip search query <query>` (#1095)

### Features

- 新增 Debug 模式和一键导出日志，可从设置或命令行收集排障所需信息 (#1087)
- 新增官方 Homebrew cask 支持，macOS 用户可通过 Homebrew 安装和更新 UniClipboard (#1086)
- 新增 Chocolatey、winget、Scoop、Flathub 和 Nix 的包管理器打包支持 (#1088)
- 简化 CLI 命令，搜索写法更短，成员列表可按需刷新可达状态，升级状态也会默认显示 (#1095)
- 将移动端同步 CLI 命令重命名为 `uniclip mobile`，并在设置时自动把检测到的网络地址写入二维码 (#1099)
- 新增配置备份和导入，可在设置或首次启动流程中把现有 UniClipboard 配置迁移到另一台设备 (#1118)
- 新增跨设备活动剪贴板同步，并提供“恢复时同步”选项，让从历史恢复的内容也能成为其他设备上的当前剪贴板 (#1117)
- 新增网络传输行为设置，可按本地网络或远距离连接选择更合适的传输方式 (#1121)

### Fixes

- 修复 Snap 打包，使安装后的应用包含所需的二进制文件 (#1075)
- 明确 Homebrew 6.0+ 的 tap 信任步骤，避免 macOS Homebrew 安装卡在未信任 tap 报错上 (#1078)
- 减少 Linux/X11 复制图片后可能刷满剪贴板历史的重复捕获循环 (#1083)
- 通用设置保存失败时会显示错误，并避免 Windows 安装器更新在 UniClipboard 仍在运行时卡住 (#1087)
- 修复命令行文本输出，让 `uniclip get` 在终端中能正常换行结束 (#1091)
- 修复 Linux 剪贴板图片处理，优先选择可用图片数据，避免选到不支持的图片目标 (#1089)
- 修复 Linux/X11 剪贴板读取过早放弃，导致内容尚未准备好就被漏掉的问题 (#1096)
- Debug 模式生效期间保持重启对话框打开，让用户能看到重启仍在进行 (#1102)
- 修复共享剪贴板图片仅透明通道差异导致的 Linux 重复图片捕获 (#1105)
- 修复 macOS 剪贴板历史中再次复制同一段文本时，该条目不会回到顶部的问题 (#1112)
- 通过默认使用更快的本地网络模式提升局域网传输速度 (#1121)
- 修复文件剪贴板同步中同一个文件在不同设备间无法识别、反复拉取的问题 (#1126)
- 当对端离线导致剪贴板条目无法投递时，显示为不可达而不是失败 (#1131)
- 防止并发文件传输在 macOS 和 Windows 上把缓存文件变成空文件 (#1132)
- 防止同一复制文件通过重叠同步路径到达时产生重复文件条目和重复下载 (#1133)
