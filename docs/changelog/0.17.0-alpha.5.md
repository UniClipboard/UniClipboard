## 0.17.0-alpha.5 - 2026-06-29

### Features

- Redesign the History page with searchable browsing, combined filters (type, source, tag, time range, file extension), and an inline preview of the selected item (#1165, #1180)
- Unify History browsing and search into a single entry point, and persist favorites across restarts (#1171)
- Add a right-click context menu (copy, favorite, send to device, delete, open file location), image thumbnail previews, and composite quick-panel search to History (#1185)
- Add a favorite action and keyboard shortcut to the clipboard preview (#1182)

### Fixes

- Automatically resume an interrupted search-index rebuild on startup instead of leaving History stuck in a "rebuilding" state (#1179)
- Stop a single copied file from being saved as two separate History entries on Windows (#1173)
- Fix copied files sometimes not being captured into History at all on Windows (#1168)
