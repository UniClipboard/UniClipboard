## 0.17.0-alpha.5 - 2026-06-29

- 重新设计历史页面，改为可搜索的卡片网格视图，支持标签筛选、三栏布局，并统一浏览与搜索体验 (#1165, #1171, #1180)

- Windows 端将历史搜索框移入窗口标题栏 (#1187)

- 修复历史搜索重建过程崩溃后卡在重建状态的问题，现在会自动恢复重建 (#1179)
- 修复同一个复制文件被保存为两条历史记录的问题 (#1173)
- 修复 Windows 上复制文件后偶尔不会出现在历史记录中的问题 (#1168)
