## 0.17.0-alpha.5 - 2026-06-29

### Features

- 重新设计历史页面：支持搜索浏览、按类型/来源/标签/时间/扩展名组合筛选，并即时预览选中的条目 (#1165, #1180)
- 将历史记录的浏览与搜索统一为同一入口，并持久化保存收藏状态 (#1171)
- 历史条目新增右键菜单（复制、收藏、发送到设备、删除、打开文件位置）、图片缩略图预览，以及快速面板的组合搜索 (#1185)
- 剪贴板预览新增收藏操作和快捷键 (#1182)

### Fixes

- 历史搜索索引重建中断后，现在会在下次启动时自动恢复，不再卡在「重建中」状态 (#1179)
- 修复 Windows 上同一个复制文件被保存为两条历史记录的问题 (#1173)
- 修复 Windows 上复制文件有时完全不会被记录到历史的问题 (#1168)
