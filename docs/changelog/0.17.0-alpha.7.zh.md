## 0.17.0-alpha.7 - 2026-06-30

### Features

- 在历史记录、快捷面板和搜索中加入富文本类型筛选，并让链接和代码标签更准确 (#1197)
- `uniclip search` 现在可以用设备名或设备 id 按来源设备筛选结果 (#1208)

### Fixes

- 避免移动端同步时因同一内容被重新编码而产生重复剪贴板记录 (#1159)
- 文件剪贴板记录会继续按文件显示，而不是显示为原始的 `file://` 文本 (#1205)
- 当新记录出现在历史列表顶部时，最新的第一张卡片会保持选中状态 (#1204)
- 代码预览的滚动条现在更容易看见和操作 (#1196)
