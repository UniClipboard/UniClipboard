## 0.17.0 - 2026-07-01

### Features

- The History page now uses a searchable card grid with richer previews and easier browsing (#1165)
- Browse and search now share one live result view, so filters, favorites, and new clipboard items stay in sync across history surfaces (#1171)
- The History page now has a three-pane layout with tag search and clearer entry details (#1180)
- Clipboard previews now include a favorite action and shortcut (#1182)
- History cards now have a context menu, and the quick panel search can combine multiple filters (#1185)
- The Windows History page now places search in the title bar for quicker access (#1187)
- History and quick panel filters now recognize Rich Text as its own content type and show link or code tags separately (#1197)
- Shortcut settings now support two-step shortcuts and double-tap shortcuts (#1148)
- Storage settings now include an Unlimited max history items option, and automatic cleanup follows the configured retention rules while protecting favorites (#1225)
- The `uniclip search` command can now filter results by source device (#1208)
- Scrollbars now follow the app theme (#1212)
- The About settings page now has a clearer update area and sponsor section (#1214)
- Sponsor information now shows a placeholder while it loads (#1232)

### Fixes

- Mobile clients now receive readable file previews instead of raw HTML when syncing clipboard files (#1220)
- File previews in clipboard history now use the actual file list instead of showing the copied file path text (#1217)
- File clipboard entries now render as files instead of `file://` text (#1205)
- New clipboard items no longer steal focus from the first active history card (#1204)
- Code previews now scroll more smoothly and consistently (#1196)
- Clipboard image previews now load reliably instead of failing with authorization errors (#1192)
- Chinese, Japanese, and Korean text now uses a more consistent system font across the app and code cards (#1190)
- Search index rebuilds now resume after an interrupted startup instead of leaving search stuck (#1179)
- Copying the same files through multiple clipboard formats no longer creates duplicate history entries (#1173)
- The Open File Location action now opens the folder for received files (#1158)
- Restart from the tray now restarts both the window and background service (#1157)
- Linux image clipboard bursts, especially from shared clipboard tools, are now less likely to create repeated image entries (#1154)
- Lightweight Mode now makes it clearer that UniClipboard is still running in the background, and weak-GPU Windows devices should see smoother clipboard and device pages (#1149)
