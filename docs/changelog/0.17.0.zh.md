## 0.17.0 - 2026-07-01

### Features

- 历史记录页改为可搜索的卡片网格，预览更丰富，浏览更方便 (#1165)
- 浏览和搜索现在共用同一个实时结果视图，筛选、收藏和新剪贴板内容会在历史记录相关界面中保持同步 (#1171)
- 历史记录页新增三栏布局、标签搜索和更清晰的条目详情 (#1180)
- 剪贴板预览现在可以直接收藏条目，并支持对应快捷键 (#1182)
- 历史记录卡片新增右键菜单，快捷面板搜索现在可以组合多个筛选条件 (#1185)
- Windows 上的历史记录页现在把搜索放到标题栏，访问更快 (#1187)
- 历史记录和快捷面板筛选现在会把富文本识别为独立内容类型，并单独显示链接或代码标签 (#1197)
- 快捷键设置现在支持两段式快捷键和双击式快捷键 (#1148)
- 存储设置新增“不限制”最大历史条数选项，自动清理会按已配置的保留规则执行并保护收藏条目 (#1225)
- `uniclip search` 命令现在可以按来源设备筛选结果 (#1208)
- 滚动条现在会跟随应用主题 (#1212)
- “关于”设置页现在有更清晰的更新区域和赞助者区域 (#1214)
- 赞助者信息加载时现在会显示占位状态 (#1232)

### Fixes

- 移动端同步剪贴板文件时，现在会收到可读的文件预览，而不是原始 HTML (#1220)
- 剪贴板历史中的文件预览现在会使用实际文件列表，而不是显示复制的文件路径文本 (#1217)
- 文件类剪贴板条目现在会按文件渲染，而不是显示为 `file://` 文本 (#1205)
- 新剪贴板条目加入列表时，不会再抢走第一个历史卡片的当前焦点 (#1204)
- 代码预览的滚动现在更顺畅、更一致 (#1196)
- 剪贴板图片预览现在能更可靠地加载，不再因为授权错误而失败 (#1192)
- 中日韩文字现在会在应用界面和代码卡片中使用更一致的系统字体 (#1190)
- 搜索索引重建如果在启动时被中断，现在会继续恢复，不会让搜索卡住 (#1179)
- 通过多种剪贴板格式复制同一批文件时，不会再生成重复历史记录 (#1173)
- “打开文件位置”现在可以打开已接收文件所在的文件夹 (#1158)
- 托盘中的重启现在会同时重启窗口和后台服务 (#1157)
- Linux 上短时间内连续出现的图片剪贴板事件，尤其是共享剪贴板工具产生的事件，现在不易生成重复图片条目 (#1154)
- 轻量模式现在会更清楚地提示 UniClipboard 仍在后台运行，弱显卡 Windows 设备上的剪贴板和设备页面也应更流畅 (#1149)
