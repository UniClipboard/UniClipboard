## 0.18.0 - 2026-07-04

### Features

- Show image thumbnails in the Quick Panel list and switch the Image filter to a three-column thumbnail wall for faster visual browsing (#1266)
- Add Startup mode controls, including Lightweight mode and an option to restore the last clipboard entry when the app starts (#1275)
- Let you choose a folder where received files are saved directly instead of keeping them only in app-managed storage (#1271)
- Reduce automatic update pop-ups during busy release periods while keeping manual update checks available anytime (#1287)
- Move device and mobile-sync details into inline panels so pairing credentials, device facts, and sync controls are easier to use from the Devices page (#1291)

### Fixes

- Show release notes in the update window, honor your selected update channel, and check for a newer release again before installing (#1280)
- Prevent search and history content from being returned while the app is locked, so locked sessions no longer expose searchable previews (#1292)
