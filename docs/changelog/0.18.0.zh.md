## 0.18.0 - 2026-07-04

### Features

- 快捷面板列表现在会显示图片缩略图，选择图片筛选后会切换为三列缩略图墙，方便快速浏览图片记录 (#1266)
- 新增启动方式设置，包含轻量模式，以及应用启动时恢复最近一条剪贴板记录的选项 (#1275)
- 现在可以选择接收文件的保存文件夹，让收到的文件直接保存到指定位置，而不是只放在应用托管存储中 (#1271)
- 在版本发布密集时减少自动更新弹窗打扰，同时手动检查更新仍可随时使用 (#1287)
- 设备页改为内嵌面板展示设备与移动端同步详情，让配对凭据、设备信息和同步开关更容易操作 (#1291)

### Fixes

- 更新窗口现在会显示版本说明，遵循你选择的更新频道，并在安装前再次检查是否已有更新版本 (#1280)
- 应用锁定时不再返回搜索和历史内容，避免锁定会话暴露可搜索的预览信息 (#1292)
