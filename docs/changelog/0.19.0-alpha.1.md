## 0.19.0-alpha.1 - 2026-07-08

### Features

- Mobile companion sync can now receive desktop clipboard changes immediately instead of waiting for periodic refreshes (#1295)
- Add a right-click menu in the Quick Panel for copying, favoriting, sending, revealing files, and deleting entries (#1305)
- Add Cmd/Ctrl+C and Cmd/Ctrl+V shortcuts in the Quick Panel for copying or pasting the hovered or selected entry (#1306)

### Fixes

- Prevent mobile companion sync from missing back-to-back image or file copies and from re-applying an item it just sent (#1301)
