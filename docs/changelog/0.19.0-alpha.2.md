## 0.19.0-alpha.2 - 2026-07-16

### Features

- Sync copied folders between desktop devices while preserving their directory structure (#1323)
- Restore copied files and folders as native file paths from clipboard history and the quick panel (#1314)
- Filter clipboard history to show copied folders only (#1341)
- Use UniClipboard in Russian, including the desktop interface and tray menu (#1348)
- Find the add-device action more easily at the top of the device list and in empty device sections (#1353)
- Hear sound feedback for key actions throughout the app (#1352)
- Turn interaction sounds on or off in settings (#1322)
- Follow separate download and installation steps when applying an update (#1312)
- See smoother animations when switching themes and changing settings (#1324)

### Fixes

- Update the receiving device immediately when a peer copies previously synced content again (#1355)
- Keep the mobile clipboard available when a copied folder becomes active on desktop (#1335)
- Allow requested clipboard folders to sync reliably to another desktop device (#1344)
- Prevent an unpainted window from flashing when the main window opens (#1340)
- Prevent stale search results from flashing when the quick panel is reopened (#1311)
- Prevent settings from briefly reverting or flashing while changes are being saved (#1322)
