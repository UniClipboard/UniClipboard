## 0.19.0-alpha.2 - 2026-07-16

### Features

- 在桌面设备之间同步复制的文件夹，并保留其目录结构 (#1323)
- 从剪贴板历史记录和快捷面板恢复复制的文件或文件夹时，写入原生文件路径 (#1314)
- 筛选剪贴板历史记录，只查看复制的文件夹 (#1341)
- 使用完整的俄语桌面界面和托盘菜单 (#1348)
- 在设备列表顶部和空设备分区中更方便地找到添加设备入口 (#1353)
- 在应用中的关键操作完成时获得声音反馈 (#1352)
- 在设置中开启或关闭交互声音 (#1322)
- 安装更新时分别完成下载和安装步骤 (#1312)
- 切换主题和更改设置时获得更流畅的动画效果 (#1324)

### Fixes

- 当另一台设备再次复制已同步过的内容时，接收设备会立即更新剪贴板 (#1355)
- 在桌面端激活复制的文件夹时，保持移动端剪贴板内容可用 (#1335)
- 修复另一台桌面设备请求当前剪贴板时，文件夹可能无法可靠同步的问题 (#1344)
- 修复打开主窗口时可能短暂显示未绘制画面的问题 (#1340)
- 修复重新打开快捷面板时可能短暂闪现旧搜索结果的问题 (#1311)
- 修复保存设置期间，设置项可能短暂回退或闪烁的问题 (#1322)
