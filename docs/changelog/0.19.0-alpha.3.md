## 0.19.0-alpha.3 - 2026-07-16

### Features

- Sync copied folders between desktop devices while preserving their directory structure (#1323) (#1344)
- Filter clipboard history to show copied folders (#1341)
- Copy file paths from history or paste them as text from the quick panel (#1314)
- Download updates in the background and choose when to install them (#1312)
- Use UniClipboard in Russian (#1348)
- Find the add-device action more easily at the top of the device list and in empty device sections (#1353)
- Play optional sound feedback for common interactions such as toggles, menus, copying, and pasting (#1322) (#1352)

### Fixes

- Keep a newly added mobile device selected so its details remain visible (#1359)
- Update the receiving device immediately when another device copies older clipboard content again (#1355)
- Keep the mobile clipboard available when a synced folder is active on the desktop (#1335)
- Prevent the main window from appearing before its content has loaded (#1340)
- Prevent stale search results from flashing when the quick panel is reopened (#1311)
- Apply settings changes immediately without dimming or flashing the entire settings page (#1322)
