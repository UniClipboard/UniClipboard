## 0.19.0-alpha.3 - 2026-07-16

### Features

- 在桌面设备之间同步复制的文件夹，并保留原有目录结构 (#1323) (#1344)
- 在剪贴板历史中筛选已复制的文件夹 (#1341)
- 从历史记录复制文件路径，或通过快速面板将文件路径作为文本粘贴 (#1314)
- 在后台下载更新，并自行选择安装时机 (#1312)
- 使用俄语界面的 UniClipboard (#1348)
- 在设备列表顶部和空设备分区中更容易找到添加设备入口 (#1353)
- 为开关、菜单、复制和粘贴等常用操作提供可关闭的声音反馈 (#1322) (#1352)

### Fixes

- 添加移动设备后保持选中该设备，以便继续查看其详情 (#1359)
- 当其他设备再次复制较早的剪贴板内容时，立即更新接收设备 (#1355)
- 桌面端激活同步文件夹时，仍可在移动端访问剪贴板内容 (#1335)
- 避免主窗口在内容加载完成前提前显示 (#1340)
- 避免重新打开快速面板时短暂显示过期的搜索结果 (#1311)
- 立即应用设置更改，避免整个设置页面变暗或闪烁 (#1322)
