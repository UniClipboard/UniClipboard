## 0.19.0 - 2026-07-18

### Features

- Add full Russian and Brazilian Portuguese translations, including tray menus (#1348) (#1381)
- Make setup and empty states clearer about connecting another device, with a direct option to create a new invitation after pairing (#1387)
- Add a clearly visible Add Device button and dedicated actions for empty device lists (#1353)
- Allow opening the quick panel by double-tapping a chosen modifier key (#1364)
- Add right-click actions for quick-panel items, including copy, favorite, send to device, open file location, and delete (#1305)
- Add Ctrl/Cmd+C and Ctrl/Cmd+V shortcuts for copying or pasting the highlighted quick-panel item (#1306)
- Add interaction sounds for common actions, with a setting to turn sound feedback off (#1322) (#1352)
- Add local folder capture, cross-device folder sync, and a folder filter in clipboard search (#1321) (#1323) (#1341) (#1344)
- Add actions to copy or paste file entries as native file paths (#1314)
- Let updates download in the background and install later without downloading again (#1312)
- Refresh theme changes, switches, and network setting controls with smoother interactions (#1324)

### Fixes

- Keep a newly added mobile device selected so its pairing QR code appears immediately (#1359)
- Ensure copying previously synced content again immediately updates the receiving device's clipboard (#1355)
- Prevent the main window from briefly appearing blank while the interface is still loading (#1340)
- Prevent activating a synced folder from replacing clipboard content that mobile devices can use (#1335)
- Prevent previous search results and filters from flashing when the quick panel is reopened (#1311)
- Prevent received folders from exposing incomplete staging folders or overwriting an existing same-named folder (#1382)
- Prevent the entire settings page from dimming or flashing while an individual setting is saved (#1322)
