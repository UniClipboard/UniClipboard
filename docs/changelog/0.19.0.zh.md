## 0.19.0 - 2026-07-18

### Features

- 新增完整的俄语和巴西葡萄牙语翻译，包括托盘菜单 (#1348) (#1381)
- 优化初始设置和空状态中的设备连接引导，并可在配对完成后直接创建新邀请 (#1387)
- 新增醒目的“添加设备”按钮，并在设备列表为空时提供专门的添加入口 (#1353)
- 支持连按两次指定修饰键打开快速面板 (#1364)
- 为快速面板条目新增右键操作，包括复制、收藏、发送到设备、打开文件位置和删除 (#1305)
- 支持用 Ctrl/Cmd+C 和 Ctrl/Cmd+V 复制或粘贴快速面板中高亮的条目 (#1306)
- 为常用操作新增交互音效，并可在设置中关闭声音反馈 (#1322) (#1352)
- 新增本地文件夹捕获、跨设备文件夹同步和剪贴板搜索中的文件夹筛选 (#1321) (#1323) (#1341) (#1344)
- 支持将文件条目以本机文件路径的形式复制或粘贴 (#1314)
- 支持在后台下载更新，稍后安装时无需重新下载 (#1312)
- 优化主题切换、开关和网络设置控件的交互动画 (#1324)

### Fixes

- 添加移动设备后保持选中该设备，使配对二维码立即显示 (#1359)
- 修复再次复制之前同步过的内容时，接收设备的剪贴板未立即更新的问题 (#1355)
- 修复界面仍在加载时主窗口短暂显示空白的问题 (#1340)
- 修复激活已同步文件夹时会替换移动设备可用剪贴板内容的问题 (#1335)
- 修复重新打开快速面板时短暂显示上次搜索结果和筛选条件的问题 (#1311)
- 修复接收文件夹时可能显示未完成的暂存目录或覆盖同名文件夹的问题 (#1382)
- 修复保存单项设置时整个设置页面变暗或闪烁的问题 (#1322)
