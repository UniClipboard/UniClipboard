## 0.19.3 - 2026-08-30

### Features

- Add Japanese language support throughout the desktop app and tray menu
- Add an option on Windows and Linux to use the system title bar and window controls

### Fixes

- Make long links easier to read and open in clipboard previews (#1411)
- Prevent visual artifacts when switching pages or toggling settings (#1414)
- Restore support for macOS Monterey 12.5 and later (#1431)
- Prevent temporary port conflicts from stopping the app during startup (#1474)
- Show a clear fallback instead of failing when a text preview is unavailable (#1556)
- Keep the history list at a readable width on wide screens (#1582)
- Keep the app connected to its local background service when a system proxy is configured
- Improve Linux window rendering and prevent AppImage startup failures on affected systems
