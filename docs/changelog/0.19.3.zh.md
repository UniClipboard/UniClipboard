## 0.19.3 - 2026-08-30

### Features

- 桌面应用和托盘菜单现已支持日语
- Windows 和 Linux 现可选择使用系统标题栏和窗口控件

### Fixes

- 优化剪贴板链接预览，使较长链接更易阅读和打开 (#1411)
- 修复切换页面或开关设置时出现的画面残影 (#1414)
- 恢复对 macOS Monterey 12.5 及更高版本的支持 (#1431)
- 修复临时端口冲突导致应用启动失败的问题 (#1474)
- 修复文本预览不可用时无法正常显示的问题，并提供明确提示 (#1556)
- 限制宽屏下的历史记录列表宽度，使内容更易阅读 (#1582)
- 修复配置系统代理后应用无法连接本地后台服务的问题
- 改善 Linux 窗口显示，并修复部分环境下 AppImage 无法启动的问题
