## 0.20.0-alpha.1 - 2026-07-19

### Features

- Incoming clipboard transfers now keep their receive status across restarts, show combined progress for multi-item entries, and can be canceled from the receiving entry (#1399)

### Fixes

- Allow folders copied on Windows to be captured and synced correctly (#1399)
- Show a clear transfer status for directory sends instead of a misleading percentage that resets for each file (#1408)
- Show full URLs in a simple wrapping link view instead of truncating them in preview cards (#1411)
