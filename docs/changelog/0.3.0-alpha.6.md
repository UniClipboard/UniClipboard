## 0.3.0-alpha.6 - 2026-03-16

### Features

- Add event-driven device discovery with scanning states and animated setup UX.
- Add a draggable setup header with a persistent back button and improved onboarding visuals.
- Add per-file size metadata in clipboard file entries and show file count/total size in previews.

### Fixes

- Fix device discovery to preserve and display real device names during re-discovery.
- Fix setup flow step indicators and related i18n key mismatches.
- Fix quick panel shortcut handling across platforms, including Windows default shortcut conflicts.
- Fix sponsor re-authorization so multiple joiners can complete space access in sequence.
- Fix clipboard entry deletion to avoid removing user-owned local files outside the managed cache.
- Fix outbound sync behavior for disabled file sync and oversized files to prevent invalid transfers.
- Fix Windows preview panel focus stealing by restoring quick panel focus after show.
- Fix cross-platform dev startup by replacing Unix-only cargo sweep command syntax.
- Fix TypeScript `itemRef` naming conflict and stabilize integration tests by using in-memory DB.

### Refactor

- Refactor device settings UI into sheet/dialog patterns and extract reusable device utilities.
- Refactor clipboard shared data hooks to unify shared clipboard state handling.
