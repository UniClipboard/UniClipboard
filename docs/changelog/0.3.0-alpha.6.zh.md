## 0.3.0-alpha.6 - 2026-03-16

### Features

- 新增事件驱动的设备发现流程，包含扫描状态与动画化设置体验。
- 新增可拖拽的设置页顶部栏与固定返回按钮，并优化引导页视觉效果。
- 新增剪贴板文件条目的单文件大小元数据，并在预览中展示文件数量与总大小。

### Fixes

- 修复设备重复发现时名称被覆盖的问题，确保显示真实设备名。
- 修复设置流程步骤指示顺序与相关 i18n 键不匹配问题。
- 修复跨平台快捷面板快捷键处理问题，包括 Windows 默认快捷键冲突。
- 修复空间访问授权流程，支持赞助方连续为多个加入者重新授权。
- 修复删除剪贴板条目时误删本地用户文件的问题，仅清理受管缓存目录。
- 修复文件同步关闭或文件超限时的出站同步行为，避免无效传输。
- 修复 Windows 预览面板抢焦点问题，在显示后恢复快捷面板焦点。
- 修复开发启动流程的跨平台兼容性，移除仅适用于 Unix 的 cargo sweep 语法。
- 修复 TypeScript `itemRef` 命名冲突，并通过内存数据库提升集成测试稳定性。

### Refactor

- 重构设备设置界面为 sheet/dialog 模式，并提取可复用设备工具函数。
- 重构剪贴板共享数据 hooks，统一共享状态处理逻辑。
