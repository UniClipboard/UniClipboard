## 0.4.0-alpha.2 - 2026-04-01

### Breaking Changes

- Remove CLI clipboard subcommands (`clipboard list`, `clipboard get`, `clipboard clear`) from this prerelease.

### Features

- Add a full CLI workflow with interactive setup plus `start`, `stop`, and status commands.
- Bundle background service management into the CLI package so startup and lifecycle handling are built in.
- Improve setup and pairing flow consistency across app and CLI, including clearer progress and recovery paths.
- Improve real-time sync resilience with automatic reconnect handling and stale-connection detection.
- Expand settings and device management capabilities across app and CLI, including encryption state and lifecycle controls.
- Improve attachment and image preview loading paths.
- Redesign the Devices page with clearer card-based status presentation.

### Fixes

- Fix unlock flow regressions that could leave users on a black screen after successful unlock.
- Fix pairing reliability issues, including accept/verify race conditions and missing failure propagation.
- Fix setup state handling so verification and completion status stay aligned across app and CLI.
- Fix startup and runtime stability issues that could cause missed clipboard capture or service handoff problems.
- Fix standalone desktop mode clipboard monitoring regressions.
- Fix macOS panel transparency regression.
- Fix device online status reporting to better match actual discoverability.
- Fix CLI path and startup checks to avoid incorrect background service launch behavior and stale setup hints.
