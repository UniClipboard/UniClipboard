## 0.4.0-alpha.2 - 2026-04-01

### Breaking Changes

- 本次预发布移除了 CLI 的剪贴板子命令（`clipboard list`、`clipboard get`、`clipboard clear`）。

### Features

- 新增完整的 CLI 使用流程，包含交互式设置向导以及 `start`、`stop`、状态查询命令。
- CLI 打包内置后台服务，启动与生命周期管理可直接在 CLI 内完成。
- 改进 App 与 CLI 之间的设置与配对流程一致性，进度反馈和恢复路径更清晰。
- 提升实时同步稳定性，增强自动重连与失活连接检测能力。
- 补齐设备与设置相关能力，支持应用侧设置、加密状态与生命周期控制。
- 改进附件与图片预览加载体验。
- 重新设计设备页面，使用更清晰的卡片式状态展示。

### Fixes

- 修复了解锁成功后仍可能出现黑屏的问题。
- 修复了配对流程稳定性问题，包括确认/校验竞争条件与失败状态未正确透传。
- 修复设置状态处理问题，确保 App 与 CLI 间的校验与完成状态保持一致。
- 修复启动与运行稳定性问题，降低剪贴板采集遗漏和服务切换异常的概率。
- 修复独立桌面模式下的剪贴板监听回归问题。
- 修复 macOS 面板透明背景回归问题。
- 修复设备在线状态显示，使其更符合实际可发现性。
- 修复 CLI 路径与启动检查问题，避免错误启动行为和过期提示。
