## 0.4.0-alpha.6 - 2026-04-07

### Features

- Add file list preview in the quick panel so copied files are shown with readable file names and file icons.
- Improve peer connection behavior by prioritizing local network paths first, with fallback to wider network paths when needed.

### Fixes

- Fix file copies being incorrectly recognized as web links when the clipboard only contains local file paths.
- Prevent the UI from freezing or becoming sluggish when previewing very large text clipboard entries.
- Improve connection upgrade and retry behavior to reduce timeout failures during device communication.
