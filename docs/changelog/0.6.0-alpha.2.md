## 0.6.0-alpha.2 - 2026-05-01

### Breaking Changes

- Existing device pairings from earlier versions must be recreated before devices can sync again.

### Features

- The first-run setup flow now lets you create a secure space or join an existing one with an invitation code and passphrase.
- Devices can now be invited from the Devices page with a short-lived code, copy and regenerate actions, and live success or failure feedback.
- You can now join another space from the Devices page while preserving and migrating local clipboard history.
- File and large image clipboard items now sync between devices with filenames, incoming placeholders, and send or receive progress shown in the history list.

### Fixes

- Fixed paired-device lists and counts so the current device is no longer shown as a paired device.
- Fixed invitation-code entry so pasted codes are accepted even when separators are missing.
- Fixed duplicate clipboard-history entries that could appear after receiving content from another device.
- Fixed cases where file lists, PNG images, and rich clipboard content could lose formats when written to the system clipboard on Windows or macOS.
- Made device and file syncing more reliable after cold starts, offline devices, and network changes.
