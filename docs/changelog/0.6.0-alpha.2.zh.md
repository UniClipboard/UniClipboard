## 0.6.0-alpha.2 - 2026-05-01

### Breaking Changes

- 从旧版本升级后，原有设备配对需要重新建立，设备之间才能继续同步。

### Features

- 首次设置流程现在支持创建新的安全空间，或通过邀请码和口令加入已有空间。
- 现在可以在「设备」页用短期邀请码邀请新设备，并支持复制、重新生成以及实时显示成功或失败结果。
- 现在可以从「设备」页加入其他空间，同时保留并迁移本地剪贴板历史。
- 文件和大图片剪贴板内容现在可以在设备间同步，并会在历史列表中显示文件名、接收占位卡片以及发送或接收进度。

### Fixes

- 修复已配对设备列表和数量会把本机也算作配对设备的问题。
- 修复粘贴不带分隔符的邀请码时可能无法识别的问题。
- 修复从其他设备接收剪贴板内容后，剪贴板历史可能出现重复记录的问题。
- 修复 Windows 或 macOS 上写入系统剪贴板时，文件列表、PNG 图片和富文本内容可能丢失部分格式的问题。
- 提升了冷启动、设备离线后恢复以及网络变化时的设备和文件同步可靠性。
