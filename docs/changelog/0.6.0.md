## 0.6.0 - 2026-05-02

### Features

- Add local clipboard history search with advanced filters, result counts, clearer empty and loading states, and a manual rebuild control in Settings.
- Add interface zoom shortcuts that stay in sync between the main window, Settings, and the quick panel.
- Refresh the Windows main window, clipboard preview area, and quick panel with clearer spacing, metadata, and file, image, text, code, and link previews.
- Improve file transfer progress so active transfers show clearer status, speed, and remaining time.

### Fixes

- Fix restoring file items from clipboard history so files are placed back on the system clipboard reliably.
- Improve quick panel reliability so it opens on the screen with your cursor and avoids stale previews, focus jumps, and resize flashes.
- Fix pairing and connection flows that could stay busy after a previous session or concurrent connection attempt.
- Fix cases where new local clipboard changes could be skipped after a recent remote update or when macOS apps provide clipboard data with a short delay.
- Fix update checks and downloads so Settings shows progress and failed downloads can be retried.
