## 0.6.0 - 2026-05-02

### Features

- 新增本地剪贴板历史搜索，支持高级筛选、结果数量、更清晰的空状态和加载状态，并可在设置中手动重建搜索数据。
- 新增界面缩放快捷键，主窗口、设置页和快速面板中的缩放状态会保持一致。
- 优化 Windows 主窗口、剪贴板预览区和快速面板的视觉效果，文件、图片、文本、代码和链接预览的信息展示更清晰。
- 优化文件传输进度展示，可更清楚看到传输状态、速度和预计剩余时间。

### Fixes

- 修复从剪贴板历史恢复文件条目时可能失败的问题，文件现在能更可靠地放回系统剪贴板。
- 提升快速面板可靠性，使其在鼠标所在屏幕打开，并减少旧预览残留、焦点跳动和尺寸变化闪烁。
- 修复配对与连接流程在上一次会话结束后或并发连接时仍可能显示忙碌的问题。
- 修复最近接收远端更新后，或 macOS 应用延迟提供剪贴板数据时，新的本地剪贴板变化可能被跳过的问题。
- 修复更新检查和下载体验，设置页会显示检查进度，下载失败后也可以重试。
