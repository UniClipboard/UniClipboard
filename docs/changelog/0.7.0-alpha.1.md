## 0.7.0-alpha.1 - 2026-05-05

### Features

- Add LAN-only Mode in Network settings so devices can sync only on the same local network after restart.
- Add an option for shared VPN or overlay-network setups, with guidance on when to enable it.
- Show each paired device's connection status in the device list, including whether it is direct, relayed, disconnected, or outside the local network.
- Show LAN-only Mode status from the system tray when it is active.

### Fixes

- Reduce repeated macOS Keychain permission prompts during startup and unlock.
- Restore the main window when clicking the Dock icon on macOS after the window was hidden.
