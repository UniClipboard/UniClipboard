## 0.7.0-alpha.1 - 2026-05-05

### Features

- 在网络设置中新增 LAN-only Mode，重启后可让设备只在同一本地网络内同步。
- 新增适用于共享 VPN 或虚拟网络环境的开关，并说明何时应该开启。
- 在设备列表中显示每台已配对设备的连接状态，包括直连、中转、未连接或不在本地网络。
- 当 LAN-only Mode 已启用时，可在系统托盘中查看其状态。

### Fixes

- 减少 macOS 在启动和解锁过程中重复弹出 Keychain 权限提示的问题。
- 修复 macOS 上主窗口隐藏后点击 Dock 图标无法恢复窗口的问题。
