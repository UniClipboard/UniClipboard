## 0.9.0 - 2026-05-12

### Features

- Customize light and dark themes separately, including preset choices and individual accent, background, text, and border colors.
- Switch light or dark appearance from the new preview controls while still keeping the option to follow the system theme.
- Paste clipboard history as plain text from the quick panel by holding Option or Alt when pressing Enter, clicking an item, or using number shortcuts.
