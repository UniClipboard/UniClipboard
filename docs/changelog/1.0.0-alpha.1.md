## 1.0.0-alpha.1 - 2026-08-05

### Breaking Changes

- Encrypt more locally stored content with updated protection that cannot safely be downgraded after upgrading (#1424)
- Require macOS 12.5 or later (#1431)

### Features

- Keep incoming transfers resumable after restart, show combined progress for multi-item entries, and allow canceling them from the receiving entry (#1399)
- Add Japanese and Traditional Chinese interface languages, including localized tray menus (#1413)
- Use the same peer-to-peer sync foundation across the desktop and mobile apps (#1424)
- Clarify the choices between pairing another device and connecting a phone over the local network (#1439)
- Add, replace, or remove access tokens for custom relay nodes directly from Network settings (#1447)
- Make removing devices from older spaces secure, with protection and rejoin status shown on the Devices page (#1457)
- Choose which content types this computer can send to and receive from each paired device (#1461)
- Show connection progress and upgrade requirements for devices in a space (#1484)
- Keep content type and tag filters visible in the quick panel for faster filtering (#1496)
- Show device removal progress and offer recovery when another device is permanently unavailable (#1504)

### Fixes

- Sync folders copied on Windows correctly (#1399)
- Show a clear transfer status when sending folders instead of a misleading percentage that resets for each file (#1408)
- Show full URLs in a simple wrapping link view instead of truncating them in preview cards (#1411)
- Prevent visual jumps during page transitions and when toggling switches (#1414)
- Load the complete text when opening a search result whose preview was truncated (#1415)
- Let `uniclip get --type` find image and file entries (#1436)
- Restore automatic update checks after the initial setup is complete (#1437)
- Show the success result in the Add Device dialog when pairing completes (#1441)
- Keep clipboard updates working after receiving very large clipboard content (#1445)
- Restore live progress updates for file transfers (#1453)
- Recover from a temporary startup port conflict instead of leaving the background service unavailable (#1474)
- Preserve the original names of received files stored in the managed cache (#1475)
- Paste file paths from Quick Panel without changing the system clipboard (#1476)
- Explain when another device must be updated before it can rejoin the space (#1483)
- Allow space switching to continue while preserving local history that cannot be read (#1497)
- Remove an unwanted blurred decoration from the unlock screen (#1503)
- Make invitation codes and passphrases clearer and easier to enter during setup (#1506)
