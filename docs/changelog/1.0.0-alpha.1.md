## 1.0.0-alpha.1 - 2026-09-29

### Features

- Keep content type and tag filters visible in Quick Panel for faster filtering (#1496)
- Show device removal progress and offer recovery when another device is permanently unavailable (#1504)
- Control all syncing separately from automatic sending, so manual sends remain available when automatic sync is off (#1546)
- Choose whether to confirm before deleting clipboard history (#1564)
- Make history and device navigation easier with a sidebar and dedicated history search panel (#1587)
- Redesign the floating transfer indicator on macOS (#1603)
- Show explicit choices when devices belong to different groups, with the affected devices explained before confirmation (#1628)
- Add Smooth Mode to choose between richer visual effects and reduced animation, with an automatic option (#1636)
- Turn syncing on or off for all devices or individual devices from the tray menu (#1638)
- Refresh a device connection manually from its details page (#1641)
- Improve Quick Panel on Linux with desktop theme matching, expandable tag filters, and separate window and text scaling (#1664)
- Choose between regular mobile pairing and the older local-network connection in one dialog (#1666)
- Create local backups before data upgrades and let you review or delete them in Storage settings (#1671)
- Reset the space passphrase without losing local history when this device is unlocked and is the only device in the space (#1672)
- Show whether pairing is awaiting confirmation, has expired, or was replaced by a newer attempt (#1675)
- Copy retrieved text or saved file paths to the computer running your terminal with `uniclip get --copy` (#1696)
- Wait for the next synced item and retrieve it with `uniclip get --wait` (#1711)
- Send multiple files by piping a list of file paths into `uniclip send --file` (#1720)
- Show incoming transfer progress while `uniclip get --wait` waits for content (#1725)
- Simplify setup and unlocking with an inline passphrase form and password visibility controls (#1731)

### Fixes

- Explain when another device must be updated before it can rejoin the space (#1483)
- Make invitation codes and passphrases clearer and easier to enter during setup (#1506)
- Allow stalled device removals to recover (#1524)
- Finish the invitation dialog correctly when pairing succeeds (#1555)
- Keep keyboard navigation working in Quick Panel after changing filters (#1561)
- Keep the re-pairing notice visible when an upgrade requires devices to be paired again (#1586)
- Allow dragging the app window while a dialog is open (#1631)
- Recover older local data during upgrades and show progress while the upgrade runs (#1647)
- Restore the main window controls (#1648)
- Allow dragging the window from the history toolbar again (#1650)
- Allow the main window to be resized smaller (#1657)
- Prevent a device trust dialog from briefly appearing during normal startup (#1683)
- Keep command results free of extra status text when piping or redirecting CLI output (#1695)
- Send existing files correctly when their paths are passed to `uniclip send` (#1701)
- Recover local data with the original passphrase when the saved system key is missing (#1710)
- Prevent idle interface sounds from keeping audio hardware busy and disrupting other audio on macOS (#1716)
- Update device status when pending device-group changes finish reaching other devices (#1732)
- Show recovery guidance instead of failing to open when saved local data is damaged, without deleting or replacing it (#1734)
- Restore startup for older Linux installations whose saved keys are unavailable from the system keyring (#1753)
