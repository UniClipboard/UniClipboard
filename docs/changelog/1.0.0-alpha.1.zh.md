## 1.0.0-alpha.1 - 2026-08-05

### 破坏性变更

- 更多本地存储的内容会采用更新后的保护方式；升级后无法安全降级回旧版 (#1424)
- 现要求 macOS 12.5 或更高版本 (#1431)

### 新功能

- 接收中的传输在应用重启后仍可继续，多个项目会显示汇总进度，并可直接从接收条目取消 (#1399)
- 新增日语和繁体中文界面，并提供本地化托盘菜单 (#1413)
- 桌面端与移动端现共用同一套点对点同步基础 (#1424)
- 明确区分配对其他设备与通过局域网连接手机的入口 (#1439)
- 可直接在网络设置中添加、更换或移除自定义中继节点的访问令牌 (#1447)
- 支持从旧版空间中安全移除设备，并在设备页面显示保护和重新加入状态 (#1457)
- 可分别设置本机向每台已配对设备发送和接收哪些内容类型 (#1461)
- 显示空间内设备的连接进度和升级要求 (#1484)
- 在快捷面板中始终显示内容类型和标签筛选项，以便更快筛选 (#1496)
- 显示设备移除进度，并在其他设备永久不可用时提供恢复选项 (#1504)

### 修复

- 修复 Windows 上复制的文件夹无法被正确同步的问题 (#1399)
- 发送文件夹时改为显示明确的传输状态，不再显示随每个文件重置的误导性百分比 (#1408)
- 链接预览现在以简洁的自动换行链接显示完整网址，不再使用会截断网址的卡片 (#1411)
- 修复页面切换和开关操作时的画面跳动 (#1414)
- 修复打开预览被截断的搜索结果时无法加载完整文本的问题 (#1415)
- 修复 `uniclip get --type` 无法找到图片和文件条目的问题 (#1436)
- 修复初始设置完成后自动更新检查未能运行的问题 (#1437)
- 修复配对完成后“添加设备”对话框不显示成功结果的问题 (#1441)
- 修复接收超大剪贴板内容后无法继续收到剪贴板更新的问题 (#1445)
- 修复文件传输的实时进度不再更新的问题 (#1453)
- 修复临时端口冲突会导致后台服务无法启动的问题 (#1474)
- 修复接收至受管缓存的文件未保留原始名称的问题 (#1475)
- 修复从快捷面板粘贴文件路径时会改变系统剪贴板的问题 (#1476)
- 明确提示另一台设备需要升级后才能重新加入空间 (#1483)
- 支持在保留无法读取的本地历史记录后继续切换空间 (#1497)
- 移除解锁界面上不应出现的模糊装饰 (#1503)
- 优化邀请码和口令的布局，使设置时输入更清晰便捷 (#1506)
