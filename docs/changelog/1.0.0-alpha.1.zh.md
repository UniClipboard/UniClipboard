## 1.0.0-alpha.1 - 2026-09-29

### Features

- 快捷面板中始终显示内容类型和标签筛选项，方便快速筛选 (#1496)
- 显示设备移除进度，并在其他设备永久不可用时提供恢复选项 (#1504)
- 可分别控制全部同步和自动发送，关闭自动同步后仍可手动发送 (#1546)
- 可设置删除剪贴板历史记录前是否需要确认 (#1564)
- 通过侧边栏和独立的历史搜索面板，更方便地浏览历史记录和设备 (#1587)
- 重新设计 macOS 上的悬浮传输状态提示 (#1603)
- 设备属于不同组时显示明确的处理选项，并在确认前说明受影响的设备 (#1628)
- 新增流畅模式，可选择丰富视觉效果、减少动画，或由应用自动选择 (#1636)
- 可从托盘菜单开启或关闭全部设备或单台设备的同步 (#1638)
- 可在设备详情页手动刷新连接 (#1641)
- 改进 Linux 快捷面板，支持跟随桌面主题、展开标签筛选，以及分别调整窗口和文字大小 (#1664)
- 可在同一对话框中选择常规手机配对或旧版局域网连接方式 (#1666)
- 数据升级前自动创建本地备份，并可在存储设置中查看或删除 (#1671)
- 当本机已解锁且是空间中唯一的设备时，可重设空间口令而不丢失本地历史记录 (#1672)
- 显示配对是否正在等待确认、已过期或已被新的配对尝试替代 (#1675)
- 可使用 `uniclip get --copy` 将读取的文本或已保存文件的路径复制到终端所在电脑 (#1696)
- 可使用 `uniclip get --wait` 等待并读取下一条同步内容 (#1711)
- 可将文件路径列表通过管道传给 `uniclip send --file`，一次发送多个文件 (#1720)
- 使用 `uniclip get --wait` 等待内容时显示接收进度 (#1725)
- 简化初始设置和解锁界面，直接在页面中输入口令，并可切换口令是否可见 (#1731)

### Fixes

- 明确提示另一台设备需要升级后才能重新加入空间 (#1483)
- 优化邀请码和口令的布局，使初始设置中的输入更清晰便捷 (#1506)
- 修复设备移除停滞后无法恢复的问题 (#1524)
- 修复配对成功后邀请对话框未能正确完成的问题 (#1555)
- 修复更改筛选条件后快捷面板键盘导航异常的问题 (#1561)
- 升级后需要重新配对设备时，持续显示重新配对提示 (#1586)
- 修复打开对话框后无法拖动应用窗口的问题 (#1631)
- 修复旧版本地数据的升级恢复问题，并在升级过程中显示进度 (#1647)
- 修复主窗口控制按钮失效的问题 (#1648)
- 修复无法通过历史记录工具栏拖动窗口的问题 (#1650)
- 允许将主窗口缩小到更小尺寸 (#1657)
- 修复正常启动时设备信任对话框短暂闪现的问题 (#1683)
- 修复命令行输出经管道传递或重定向时混入额外状态文字的问题 (#1695)
- 修复将已有文件路径传给 `uniclip send` 时无法正确发送文件的问题 (#1701)
- 系统保存的密钥丢失时，可使用原口令恢复本地数据 (#1710)
- 修复 macOS 上界面提示音在空闲时仍占用音频设备、干扰其他声音的问题 (#1716)
- 待处理的设备组变更送达其他设备后，正确更新设备状态 (#1732)
- 本地数据损坏时显示恢复指引，不再直接启动失败，也不会删除或替换原有数据 (#1734)
- 修复旧版 Linux 安装的密钥无法从系统密钥环读取时不能启动的问题 (#1753)
