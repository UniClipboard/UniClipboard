## 1.0.0-alpha.11 - 2026-09-13

### Features

- Choose regular phone sync or experimental invitation-code pairing from a single Connect phone dialog on the Devices page (#1666)
- Improve the Linux quick panel with side-by-side history and previews, separate window and text scaling, and automatic Omarchy theme matching (#1664)

### Fixes

- Allow upgrades to continue when individual old history items cannot be decoded, while preserving their original content (#1668)
- Keep manual theme settings available and hide Omarchy controls on unsupported desktops (#1665)
- Improve history scrolling responsiveness on Linux (#1663)
- Remove the send button from quick-panel previews while keeping it available in the main history window (#1662)
- Prevent the device check dialog from briefly appearing at startup when no issues are found (#1661)
