## 1.0.0-alpha.17 - 2026-09-19

### Breaking Changes

- The quick-panel command now requires UniClipboard to be running and reports an error instead of launching the app when it is closed (#1702)

### Features

- Send existing files directly with `uniclip send <path>`, choose receiving devices with `--peer`, and have the command exit automatically once each transfer succeeds or cannot be completed (#1701)

### Fixes

- Fix installation failures for the `uniclipboard-git` AUR package on Arch Linux and Omarchy (#1699) (#1700)
- Prevent opening UniClipboard or running a command from restarting the background service when it is temporarily slow to respond (#1704)
