## 1.0.0-alpha.17 - 2026-09-19

### Breaking Changes

- The Quick Panel command now requires UniClipboard to be running and exits with an error if the app is closed (#1702)

### Features

- Send existing files directly with `uniclip send ./file`, optionally choose recipient devices, and have the command exit automatically when transfers finish or cannot proceed (#1701)

### Fixes

- Prevent opening the app or running a command from interrupting the running background service when it is temporarily slow to respond (#1704)
- Fix installation failures for the AUR source package on Arch Linux and Omarchy (#1699) (#1700)
