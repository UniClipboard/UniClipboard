## 1.0.0-alpha.17 - 2026-09-19

### Breaking Changes

- 快捷面板命令现在要求 UniClipboard 已在运行，应用关闭时会报错退出 (#1702)

### Features

- 支持通过 `uniclip send ./file` 直接发送现有文件、指定接收设备，并在传输完成或无法继续时自动退出命令 (#1701)

### Fixes

- 修复后台服务暂时响应缓慢时，打开应用或执行命令可能导致现有后台服务中断的问题 (#1704)
- 修复 Arch Linux 和 Omarchy 上 AUR 源码包安装失败的问题 (#1699) (#1700)
