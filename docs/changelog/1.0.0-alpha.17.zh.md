## 1.0.0-alpha.17 - 2026-09-19

### Breaking Changes

- 快捷面板命令现在要求 UniClipboard 已在运行，应用关闭时会报错，不再自动启动应用 (#1702)

### Features

- 使用 `uniclip send <path>` 即可直接发送已有文件，通过 `--peer` 选择接收设备，并在各项传输成功或确认无法完成后自动结束命令 (#1701)

### Fixes

- 修复 Arch Linux 和 Omarchy 上 `uniclipboard-git` AUR 软件包的安装失败问题 (#1699) (#1700)
- 修复后台服务暂时响应缓慢时，打开 UniClipboard 或运行命令会导致后台服务意外重启的问题 (#1704)
