## 1.0.0-alpha.18 - 2026-09-27

### Features

- Make startup, setup, and unlock screens more consistent, with inline passphrase entry and show/hide controls (#1731)
- Let `uniclip get --wait` wait for the next synced item and show file receive progress in the terminal (#1711) (#1725)
- Send multiple files by piping a list of file paths into `uniclip send -f` (#1720)

### Fixes

- Allow recovery with the original encryption passphrase when the saved system key is missing or unusable (#1710)
- Show recovery guidance when damaged local data prevents startup while preserving existing data (#1734)
- Clear the pending device update status once the update has reached other devices (#1732)
- Show a retry option when custom relay settings cannot be loaded (#1714)
- Stop holding audio hardware active between interface sounds, reducing audio overloads on busy Macs (#1716)
- Fix the application icon for Snap installations (#1733)
