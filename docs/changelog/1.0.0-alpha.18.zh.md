## 1.0.0-alpha.18 - 2026-09-27

### Features

- 统一启动、设置和解锁界面的布局，支持直接在页面输入加密口令并切换显示或隐藏 (#1731)
- 支持通过 `uniclip get --wait` 等待下一条同步内容，并在终端显示文件接收进度 (#1711) (#1725)
- 支持将文件路径列表通过管道传给 `uniclip send -f`，一次发送多个文件 (#1720)

### Fixes

- 系统保存的密钥丢失或不可用时，可使用原加密口令恢复数据 (#1710)
- 本地数据损坏导致无法启动时，保留现有数据并显示恢复指引 (#1734)
- 设备更新送达其他设备后，不再继续显示等待更新的状态 (#1732)
- 自定义中继设置加载失败时，提供重试入口 (#1714)
- 界面提示音播放结束后释放音频设备，减少 Mac 繁忙时的音频过载问题 (#1716)
- 修复 Snap 安装版本的应用图标 (#1733)
