## 1.0.0-alpha.2 - 2026-08-05

### Features

- 快捷面板会持续显示内容类型和标签筛选器，并保留已选筛选条件 (#1496)
- 显示空间内设备是仍在连接、需要更新，还是暂时无法完成连接 (#1484)
- 显示设备移除进度，并在其他设备永久不可用时提供恢复选项 (#1504)

### Fixes

- 切换空间时可保留无法读取的加密历史，并明确显示保留的记录数量 (#1497)
- 优化设置和切换空间时的邀请码输入框，使各字符更易区分和输入 (#1506)
- 移除解锁界面角落中多余的模糊装饰 (#1503)
- 明确提示等待重新准入的设备需要更新 UniClipboard (#1483)
