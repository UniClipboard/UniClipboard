## 1.0.0-alpha.4 - 2026-08-15

### Features

- Let users review and approve device-removal changes from another device before their sync relationships change (#1552)
- Add separate controls for all syncing and automatic sending, so manual sends remain available when auto-sync is off (#1546)
- Keep device lists and pairing results up to date automatically as devices join, leave, or reconnect (#1542)
- Move the deprecated LAN phone connection option under "Other ways to add" and clarify the device invitation guidance (#1532)

### Fixes

- Allow a device waiting to rejoin to be removed without blocking the rest of the device group (#1522)
- Automatically resume device removals that were interrupted before completion (#1524)
- Link alpha release notes to the matching Android preview download instead of the latest stable release (#1523)
- Restore images and other static resources on the documentation site (#1530)
- Make the documentation site load correctly from its main address (#1536)
