## 1.0.0-alpha.4 - 2026-08-15

### Features

- 当其他设备提出移除设备时，先让用户查看并确认，再改变本机的同步关系 (#1552)
- 将同步总开关与自动发送分开，关闭自动同步后仍可手动发送内容 (#1546)
- 设备加入、离开或重新连接后，自动更新设备列表和配对结果 (#1542)
- 将即将弃用的局域网手机连接入口移至“其他添加方式”，并让设备邀请说明更清楚 (#1532)

### Fixes

- 允许移除正在等待重新加入的设备，避免其阻塞其他设备继续使用 (#1522)
- 自动恢复尚未完成便被中断的设备移除操作 (#1524)
- 让 alpha 版本的发布说明链接到对应的 Android 预览版，而不是最新稳定版 (#1523)
- 恢复文档站点中的图片和其他静态资源 (#1530)
- 修复文档站点无法从主地址正常打开的问题 (#1536)
