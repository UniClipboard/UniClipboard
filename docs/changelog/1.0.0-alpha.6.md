## 1.0.0-alpha.6 - 2026-08-20

### Breaking Changes

- Re-pair your devices after updating because existing pairings can no longer sync (#1586)

### Features

- Add controls to skip future delete confirmations for individual history items (#1564)
- Add an option to use the system title bar and window buttons on Windows and Linux (#1566)
- Allow the quick panel to be opened from a compositor shortcut on Wayland (#1568)
- Show clear waiting and rejection states when joining or switching spaces, with an option to cancel a pending request (#1573)
- Add CLI commands for managing pending joins, device-group changes, and per-device sync preferences (#1579)
- Improve search suggestions and code previews with better result ordering, keyboard completion, line counts, and theme-aware styling (#1580)

### Fixes

- Hide the scrollbar in the quick panel's tag filter while keeping it horizontally scrollable (#1572)
- Prevent developer tools and the browser context menu from appearing in production builds (#1577)
- Keep the history list at a readable width on wide screens (#1582)
