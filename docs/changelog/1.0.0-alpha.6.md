## 1.0.0-alpha.6 - 2026-08-20

### Features

- Add an option to delete individual history items without a confirmation prompt (#1564)
- Add an option on Windows and Linux to use the system title bar and window controls (#1566)
- Allow the quick panel to be launched from desktop shortcuts on Wayland (#1568)
- Show a waiting state with a cancel option while joining or switching spaces requires confirmation from another device (#1573)
- Add command-line controls for pending joins, device trust changes, and per-device sync preferences (#1579)
- Improve history search suggestions and keyboard completion, and make code previews clearer with line counts (#1580)

### Fixes

- Hide the unnecessary scrollbar below quick panel tag filters (#1572)
- Keep the history list at a readable width on wide screens (#1582)
- Show a re-pairing notice after an upgrade when existing device connections can no longer sync (#1586)
