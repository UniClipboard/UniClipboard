## 1.0.0-alpha.6 - 2026-08-20

### Breaking Changes

- 升级后需要重新配对设备，因为现有配对将无法继续同步 (#1586)

### Features

- 支持关闭单条历史记录的后续删除确认 (#1564)
- Windows 和 Linux 新增使用系统标题栏与窗口按钮的选项 (#1566)
- Wayland 下可通过桌面合成器快捷键打开快捷面板 (#1568)
- 加入或切换空间时会清晰显示等待与拒绝状态，并可取消待处理请求 (#1573)
- 命令行新增管理待处理加入请求、设备组变更和单设备同步偏好的命令 (#1579)
- 改进搜索建议与代码预览，提供更合理的结果排序、键盘补全、行数统计和主题适配样式 (#1580)

### Fixes

- 隐藏快捷面板标签筛选栏的滚动条，同时保留横向滚动能力 (#1572)
- 防止正式版本中出现开发者工具和浏览器右键菜单 (#1577)
- 避免历史记录列表在宽屏上过度拉宽 (#1582)
