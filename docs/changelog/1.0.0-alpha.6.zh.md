## 1.0.0-alpha.6 - 2026-08-20

### Features

- 新增关闭单条历史记录删除确认的选项 (#1564)
- 新增在 Windows 和 Linux 上使用系统标题栏及窗口控件的选项 (#1566)
- 支持通过 Wayland 桌面环境的快捷键启动快捷面板 (#1568)
- 加入或切换空间需要其他设备确认时，现在会显示等待状态并提供取消选项 (#1573)
- 新增管理待处理加入请求、设备信任变更和单台设备同步偏好的命令行操作 (#1579)
- 改进历史记录搜索建议和键盘补全，并通过行数信息让代码预览更清晰 (#1580)

### Fixes

- 隐藏快捷面板标签筛选栏下方多余的滚动条 (#1572)
- 避免历史记录列表在宽屏上变得过宽 (#1582)
- 升级后原有设备连接无法继续同步时，显示重新配对提示 (#1586)
