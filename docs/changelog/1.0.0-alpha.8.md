## 1.0.0-alpha.8 - 2026-09-08

### Features

- Add Smooth Mode to automatically adjust visual effects for your device or let you choose between effects and responsiveness (#1636)
- Show which devices will keep syncing and which will pause before you confirm a device group change (#1628)
- Make history search, filters, and device navigation easier to access (#1587)
- Make code previews easier to read with theme-matched colors and a line count (#1580)
- Refresh the transfer activity display on macOS (#1603)
- Show clearer progress and failure messages when joining or switching spaces, with an option to cancel a pending join (#1573)
- Add an option to skip confirmation when deleting a single history item (#1564)
- Let Windows and Linux users switch to the system title bar and window buttons (#1566)
- Allow opening or toggling the Quick Panel through a desktop shortcut on Linux systems where global shortcuts are unavailable (#1568)
- Allow rebuilding a space from the command line while keeping local history, completed files, and settings (#1626)
- Add command-line controls for checking or cancelling join requests and changing sync preferences for individual devices (#1579)

### Fixes

- Clear completed mobile upload notifications instead of leaving them displayed as active transfers (#1633)
- Restore window dragging while a dialog is open (#1631)
- Prevent the app from clipping window corners on Linux (#1624)
- Keep the history list from stretching too wide on large screens (#1582)
- Show a persistent reminder when devices need to be paired again after an upgrade (#1586)
- Hide the unnecessary scrollbar in the Quick Panel's tag filters (#1572)
