## 1.0.0-alpha.8 - 2026-09-08

### Features

- 新增流畅模式，可根据设备自动调整视觉效果，也可手动选择效果优先或流畅优先 (#1636)
- 在确认设备组变更前，显示哪些设备将继续同步、哪些设备将暂停同步 (#1628)
- 优化历史记录搜索、筛选和设备导航，让常用入口更易找到 (#1587)
- 优化代码预览，使用与主题一致的配色并显示行数 (#1580)
- 更新 macOS 上的传输活动显示界面 (#1603)
- 加入或切换空间时显示更清晰的进度和失败原因，并支持取消等待中的加入请求 (#1573)
- 新增删除单条历史记录时跳过确认的选项 (#1564)
- 支持在 Windows 和 Linux 上切换使用系统标题栏和窗口按钮 (#1566)
- 在无法使用全局快捷键的 Linux 桌面环境中，支持通过桌面快捷键打开或切换快捷面板 (#1568)
- 支持通过命令行重建空间，同时保留本地历史记录、已完成传输的文件和设置 (#1626)
- 支持通过命令行查看或取消加入请求，以及调整单个设备的同步偏好 (#1579)

### Fixes

- 修复移动端上传完成后，通知仍显示正在传输的问题 (#1633)
- 修复打开对话框后无法拖动窗口的问题 (#1631)
- 修复 Linux 上窗口边角被应用裁切的问题 (#1624)
- 修复历史记录列表在大屏幕上拉伸过宽的问题 (#1582)
- 升级后需要重新配对设备时，持续显示提醒 (#1586)
- 隐藏快捷面板标签筛选中多余的滚动条 (#1572)
