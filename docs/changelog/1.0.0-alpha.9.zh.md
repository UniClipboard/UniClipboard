## 1.0.0-alpha.9 - 2026-09-10

### Features

- 可直接从托盘菜单开启或关闭所有设备或单个已配对设备的同步 (#1638)
- 可在设备页面手动刷新设备连接，并查看检查结果摘要 (#1641)
- 可直接在启动失败页面重试启动、检查更新或联系支持 (#1643)
- Windows 和 Linux 可选择自动、应用、系统或无标题栏，并从启动时起应用所选设置 (#1646)
- 启动时升级本地数据会显示处理进度和已用时间 (#1647)

### Fixes

- 修复单行通知中文字与图标未对齐的问题 (#1641)
- 修复升级旧版本本地数据时的启动失败，包括来自 alpha.5 的数据和此前中断的升级 (#1647)
- 恢复 Windows 和 Linux 使用应用标题栏时缺失的最小化、最大化和关闭按钮 (#1648)
