## 1.0.0 - 2026-09-28

### Breaking Changes

- Devices upgrading from 0.19 must all update to 1.0 and pair again before they can sync with each other. (#1710)

### Features

- Add Japanese and Traditional Chinese interface languages. (#1413)
- Choose which content types each device can send and receive independently. (#1461)
- Turn off automatic clipboard sending while keeping manual sending and receiving available. (#1546)
- Control sync for all devices or individual devices from the tray menu. (#1638)
- Show explicit choices and their effects when resolving device group conflicts. (#1628)
- Add a manual connection refresh action for devices. (#1641)
- Bring mobile connection options together in one dialog. (#1666)
- Back up local data before upgrading, show backup progress, and let you manage upgrade backups in Settings. (#1671)
- Reset a forgotten space passphrase without losing local history when the device is unlocked and is the only device in the space. (#1672)
- Simplify setup and unlocking with an inline passphrase form and a show-or-hide password toggle. (#1731)
- Add a collapsible sidebar and a keyboard shortcut for searching clipboard history. (#1587)
- Choose whether to confirm before deleting a single history item. (#1564)
- Add an adaptive Smooth Mode that adjusts visual effects to the device. (#1636)
- Improve the Linux quick panel with desktop theme matching, multiple tag filters, and separate panel and text scaling. (#1664)
- Show incoming transfers in history and let you cancel an individual transfer. (#1399)
- Show receive progress while the command-line tool waits for the next synced item. (#1725)
- Send files from a list of paths passed to the command-line tool through standard input. (#1720)
- Copy command-line retrieval results to the clipboard through supported terminals. (#1696)

### Fixes

- Show recovery guidance instead of failing to open when saved local data is damaged, while preserving the existing data. (#1734)
- Allow local data recovery with the original space passphrase when the saved system key is missing or unusable. (#1710)
- Show upgrade progress and avoid premature startup failures while older data is being upgraded. (#1647)
- Fix Windows upgrade backup and export failures that could prevent startup. (#1681)
- Update device group status when pending updates finish reaching other devices. (#1732)
- Close out invitation flows correctly after pairing completes. (#1555)
- Recover device removals that could remain stuck. (#1524)
- Fix copied folders being ignored on Windows. (#1399)
- Preserve recognizable original names for received files saved in the app cache. (#1475)
- Paste file paths from the quick panel without replacing the clipboard contents. (#1476)
- Keep keyboard navigation working after filtering quick panel results. (#1561)
- Load the full text when opening a truncated search preview. (#1415)
- Dismiss mobile upload notifications after transfers finish. (#1633)
- Prevent idle interaction sounds from causing audio glitches in other apps on macOS. (#1716)
- Restore compatibility with macOS Monterey. (#1431)
- Fix installation failures on Omarchy. (#1699)
- Allow the main window to be resized to a smaller size. (#1657)
- Keep command-line results usable when piped into other commands. (#1695)
