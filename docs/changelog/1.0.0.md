## 1.0.0 - 2026-09-28

> [!WARNING]
> 1.0 is a breaking upgrade: you cannot downgrade to 0.19 afterwards, and every device must be updated to 1.0 and paired again before syncing resumes. Read the [upgrade guide](https://docs.uniclipboard.app/migration/upgrade-0-19-to-v1) before upgrading.

### Breaking Changes

- Local data is upgraded to a new storage and protection format; downgrading back to 0.19 afterwards is not possible (#1424)
- All devices must be updated to 1.0 and paired again to keep syncing with each other; 1.0 cannot sync with devices still on an older version (#1483) (#1586)
- Quick panel commands now require UniClipboard to be running and exit with an error when it is not (#1702)

### Features

- Choose which content types this device sends to and receives from each paired device (#1461)
- Control all syncing and automatic clipboard syncing separately, and still send content manually while automatic sync is off (#1546)
- Turn syncing on or off for all devices or a single paired device directly from the tray menu (#1638)
- When a device comes back online, it automatically receives the latest clipboard item it missed (#1517)
- Incoming transfers continue after an app restart, show combined progress for multiple items, and can be cancelled from the receiving entry (#1399)
- Refresh the transfer activity display on macOS (#1603)
- Add, replace, or remove access tokens for custom relay servers directly in network settings (#1447)
- Device invitations are now the main way to add devices, with clearer invite code and passphrase input and status for pairings that are awaiting confirmation, expired, or replaced (#1532) (#1506) (#1675)
- Choose regular sync or experimental invite code pairing from a single Connect Phone dialog on the Devices page (#1439) (#1666)
- The Devices page shows each device's connection progress and update requirements, supports refreshing connections manually, and retries automatically when you return to the app or wake the computer (#1484) (#1518) (#1641) (#1656)
- Remove devices from a space with visible progress, plus recovery options when other devices are permanently unavailable (#1457) (#1504)
- When a device group change needs confirmation, see which devices will keep or pause syncing and choose which ones to keep (#1552) (#1628)
- Joining or switching spaces shows progress and failure reasons, and lets you wait for or cancel requests that need another device's approval (#1573)
- When this is the only device in a space, reset the space passphrase while keeping local history (#1672)
- Rebuild a space while keeping local history, received files, and settings (#1626)
- Redesigned navigation and history search, with search suggestions, keyboard completion, and animated menus, dialogs, and notifications (#1587) (#1580)
- Code previews use theme-matched colors and show line counts (#1580)
- Add Smooth Mode, which adjusts visual effects to the device automatically or lets you prefer effects or smoothness (#1636)
- The quick panel always shows content type and tag filters and keeps your selected filters (#1496)
- Add a Traditional Chinese interface (#1413)
- Add an option to skip confirmation when deleting a single history item (#1564)
- Choose an automatic, app, system, or no title bar on Windows and Linux (#1566) (#1646)
- The main window can be resized smaller, with more consistent text sizes and spacing across pages (#1657) (#1659)
- Unify the startup, setup, and unlock screens, with inline passphrase entry and a show/hide toggle (#1731)
- Open the quick panel with a desktop shortcut on Linux desktops where global shortcuts are unavailable (#1568)
- The Linux quick panel can show history and preview side by side, resize the window and text independently, and follow the Omarchy theme automatically (#1664)
- Local data is backed up automatically before upgrades, with visible progress, and backups can be viewed or deleted in storage settings (#1647) (#1671)
- Retry startup, check for updates, or contact support directly from the startup failure screen (#1643)
- Recover data with the original encryption passphrase when the system-stored key is missing or unavailable (#1710)
- When corrupted local data prevents startup, existing data is kept and recovery guidance is shown (#1734)
- Send existing files with `uniclip send ./file`, target specific devices, and pipe multiple file paths in one command (#1701) (#1720)
- Wait for the next synced item with `uniclip get --wait`, with file receive progress, and copy it to the terminal computer's clipboard with `uniclip get --copy` (#1711) (#1725) (#1696)
- View or cancel join requests, handle device trust changes, and adjust per-device sync preferences from the command line (#1579)
- Command-line output is easier to use in scripts, without extra status messages mixed into retrieved content or file paths (#1695)
