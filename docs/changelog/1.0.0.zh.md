## 1.0.0 - 2026-09-28

> [!WARNING]
> 1.0 是一次破坏性升级：升级后无法降级回 0.19，所有设备都需升级到 1.0 并重新配对后才能继续同步。升级前请先阅读[升级指南](https://docs.uniclipboard.app/migration/upgrade-0-19-to-v1)。

### Breaking Changes

- 本地数据会升级为新的存储和保护格式，升级后无法再降级回 0.19 (#1424)
- 所有设备都需升级到 1.0 并重新配对后才能继续互相同步，1.0 无法与仍在旧版本的设备同步 (#1483) (#1586)
- 快捷面板命令现在要求 UniClipboard 已在运行，应用未启动时会报错退出 (#1702)

### Features

- 可分别设置本机向每台已配对设备发送和接收哪些内容类型 (#1461)
- 可分别控制全部同步和剪贴板自动同步，关闭自动同步后仍可手动发送内容 (#1546)
- 可直接从托盘菜单开启或关闭所有设备或单台设备的同步 (#1638)
- 设备重新上线后，自动补送它错过的最新一条剪贴板内容 (#1517)
- 接收中的传输在应用重启后仍可继续，多项内容显示汇总进度，并可直接从接收条目取消 (#1399)
- 更新 macOS 上的传输活动显示界面 (#1603)
- 可直接在网络设置中添加、更换或移除自定义中继节点的访问令牌 (#1447)
- 邀请设备成为添加设备的主要方式，邀请码和口令输入更清晰，并显示配对等待确认、已过期或被新配对取代等状态 (#1532) (#1506) (#1675)
- 在设备页的“连接手机”对话框中统一选择常规同步或实验性邀请码配对 (#1439) (#1666)
- 设备页显示各设备的连接进度和更新要求，支持手动刷新连接，并在返回应用或唤醒电脑时自动重试 (#1484) (#1518) (#1641) (#1656)
- 支持从空间中移除设备并显示移除进度，其他设备永久不可用时提供恢复选项 (#1457) (#1504)
- 设备组发生需要确认的变更时，可查看哪些设备将继续或暂停同步，并选择要保留的设备 (#1552) (#1628)
- 加入或切换空间时显示进度和失败原因，需要其他设备确认时可等待或取消 (#1573)
- 当本机是空间中唯一的设备时，可重设空间口令并保留本地历史记录 (#1672)
- 支持重建空间，同时保留本地历史记录、已接收的文件和设置 (#1626)
- 重新设计导航和历史记录搜索，新增搜索建议和键盘补全，菜单、对话框和通知加入过渡动效 (#1587) (#1580)
- 代码预览使用与主题一致的配色并显示行数 (#1580)
- 新增流畅模式，可根据设备自动调整视觉效果，也可手动选择效果优先或流畅优先 (#1636)
- 快捷面板始终显示内容类型和标签筛选项，并保留已选筛选条件 (#1496)
- 新增繁体中文界面 (#1413)
- 新增删除单条历史记录时跳过确认的选项 (#1564)
- Windows 和 Linux 的标题栏可选择自动、应用、系统或无 (#1566) (#1646)
- 主窗口可以缩小到更小的尺寸，各页面的文字大小与间距更统一 (#1657) (#1659)
- 统一启动、设置和解锁界面的布局，可直接在页面输入加密口令并切换显示或隐藏 (#1731)
- 在无法使用全局快捷键的 Linux 桌面环境中，可通过桌面快捷键打开快捷面板 (#1568)
- Linux 快捷面板支持历史与预览并排显示、分别调整窗口大小和文字缩放，并可自动跟随 Omarchy 主题 (#1664)
- 升级本地数据前自动备份并显示进度，可在存储设置中查看或删除备份 (#1647) (#1671)
- 启动失败时可直接在页面上重试启动、检查更新或联系支持 (#1643)
- 系统保存的密钥丢失或不可用时，可使用原加密口令恢复数据 (#1710)
- 本地数据损坏导致无法启动时，保留现有数据并显示恢复指引 (#1734)
- 支持通过 `uniclip send ./file` 直接发送文件并指定接收设备，也可通过管道一次发送多个文件 (#1701) (#1720)
- 支持通过 `uniclip get --wait` 等待下一条同步内容并显示文件接收进度，通过 `uniclip get --copy` 复制到终端所在电脑的剪贴板 (#1711) (#1725) (#1696)
- 支持通过命令行查看或取消加入请求、处理设备信任变更，以及调整单台设备的同步偏好 (#1579)
- 命令行结果更便于在脚本中使用，取回内容和文件路径不再混入额外提示 (#1695)

### Fixes

- 修复 Windows 上复制的文件夹无法被同步的问题 (#1399)
- 发送文件夹时显示明确的传输状态，不再显示随每个文件重置的百分比 (#1408)
- 修复从快捷面板粘贴文件路径时会改变系统剪贴板的问题 (#1476)
- 改善 Linux 上历史列表的滚动响应 (#1663)
- 修复后台服务暂时响应缓慢时，打开应用或执行命令可能导致后台服务中断的问题 (#1704)
- 修复 Windows 上导出诊断日志时遗漏正在写入的日志的问题 (#1741)
