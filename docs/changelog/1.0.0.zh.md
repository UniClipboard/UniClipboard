## 1.0.0 - 2026-09-28

### Breaking Changes

- 从 0.19 升级的设备必须全部更新至 1.0 并重新配对，才能继续相互同步。 (#1710)

### Features

- 新增日语和繁体中文界面。 (#1413)
- 支持为每台设备分别设置允许发送和接收的内容类型。 (#1461)
- 支持关闭剪贴板自动发送，同时保留手动发送和接收功能。 (#1546)
- 支持通过托盘菜单控制所有设备或单台设备的同步。 (#1638)
- 处理设备组冲突时，清楚展示可选操作及其影响。 (#1628)
- 新增手动刷新设备连接的操作。 (#1641)
- 将移动设备的连接方式集中在同一个对话框中。 (#1666)
- 升级前自动备份本地数据并显示进度，支持在设置中管理升级备份。 (#1671)
- 设备已解锁且空间内仅有这一台设备时，可重设遗忘的空间口令并保留本地历史。 (#1672)
- 简化初始设置和解锁流程，支持在页面内输入口令并切换密码显示。 (#1731)
- 新增可折叠侧边栏和剪贴板历史搜索快捷键。 (#1587)
- 支持设置删除单条历史记录前是否需要确认。 (#1564)
- 新增可根据设备情况调整视觉效果的自适应流畅模式。 (#1636)
- 改进 Linux 快捷面板，支持跟随桌面主题、多标签筛选以及分别调整面板和文字大小。 (#1664)
- 在历史记录中显示正在接收的传输，并支持单独取消。 (#1399)
- 命令行工具等待下一条同步内容时，可显示接收进度。 (#1725)
- 命令行工具支持从标准输入读取路径列表并发送文件。 (#1720)
- 支持通过兼容的终端将命令行获取的内容复制到剪贴板。 (#1696)

### Fixes

- 本地数据损坏时显示恢复指引，避免应用无法打开，并保留现有数据。 (#1734)
- 系统保存的密钥丢失或不可用时，支持使用原空间口令恢复本地数据。 (#1710)
- 升级旧数据时显示进度，避免因等待时间较长而误报启动失败。 (#1647)
- 修复 Windows 上升级备份和导出失败导致无法启动的问题。 (#1681)
- 待处理的设备组更新送达其他设备后，及时刷新完成状态。 (#1732)
- 修复配对完成后邀请流程未正确结束的问题。 (#1555)
- 修复移除设备时流程可能卡住的问题。 (#1524)
- 修复 Windows 上复制的文件夹被忽略的问题。 (#1399)
- 接收的文件保存到应用缓存时保留可辨认的原文件名。 (#1475)
- 从快捷面板粘贴文件路径时，不再替换剪贴板内容。 (#1476)
- 修复快捷面板筛选结果后键盘导航失效的问题。 (#1561)
- 打开被截断的搜索预览时，正确加载完整文本。 (#1415)
- 移动设备上传完成后，及时关闭传输通知。 (#1633)
- 修复 macOS 上交互音效空闲时可能导致其他应用声音卡顿的问题。 (#1716)
- 恢复对 macOS Monterey 的兼容。 (#1431)
- 修复 Omarchy 上的安装失败问题。 (#1699)
- 支持将主窗口缩小到更小的尺寸。 (#1657)
- 修复命令行结果通过管道传给其他命令时受到额外输出干扰的问题。 (#1695)
