## 1.0.1-alpha.1 - 2026-10-01

### Features

- Introduce a redesigned native Quick Panel on macOS with filter suggestions, an image grid, and keyboard actions for clipboard items (#1786)
- Allow command-line users to change the passphrase of an unlocked, single-device space while keeping local history (#1802)
- Add a configurable connection timeout and file transfer progress display when sending from the command line (#1765)

### Fixes

- Remember the main window's size, position, and maximized state when closing it or restarting the app (#1772)
- Restore each settings category's own scroll position when switching between categories within the same window session (#1762)
- Fix an issue that prevented some Linux users from starting the app after upgrading from versions before 1.0 (#1753)
