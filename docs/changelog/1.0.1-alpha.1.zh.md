## 1.0.1-alpha.1 - 2026-10-01

### Features

- 在 macOS 上推出重新设计的原生快捷面板，支持筛选建议、图片网格和剪贴板条目的键盘操作 (#1786)
- 支持通过命令行为已解锁且仅有一台设备的空间修改口令，同时保留本地历史记录 (#1802)
- 为命令行发送新增可设置的连接等待超时和文件传输进度显示 (#1765)

### Fixes

- 关闭主窗口或重启应用后，保留主窗口的大小、位置和最大化状态 (#1772)
- 在同一次窗口会话中切换设置分类时，恢复各分类各自的滚动位置 (#1762)
- 修复部分 Linux 用户从 1.0 之前的版本升级后无法启动应用的问题 (#1753)
