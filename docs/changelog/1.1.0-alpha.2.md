## 1.1.0-alpha.2 - 2026-10-01

### Features

- Redesign the macOS Quick Panel with filter suggestions for tags, devices, content types and dates, an image grid, and a keyboard action list (#1786)
- Allow command-line users to change the passphrase of an unlocked, single-device space without losing local history (#1802)
- Add a configurable connection wait limit and file transfer progress to command-line sending (#1765)

### Fixes

- Remember the main window's size, position and maximized state when reopening it or restarting the app (#1772)
- Prevent excessive memory use when repeatedly browsing images in the macOS Quick Panel (#1806)
