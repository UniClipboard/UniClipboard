## 1.1.0 - 2026-10-03

### Features

- Redesign the macOS quick panel with search suggestions, filters for tags, devices, content types and dates, and separate content previews (#1786)
- Show built-in relay servers and whether the current relay settings have taken effect in network settings (#1813)
- Add a command to change the passphrase of an unlocked, single-device space without losing local history (#1802)
- Show file transfer progress in the command line and let users set how long sending waits for a device to connect (#1765)

### Fixes

- Remember the desktop window's size, position where supported, and maximized state across restarts (#1772)
- Reduce excessive memory use when browsing images in the macOS quick panel (#1806)
- Make the macOS quick panel close promptly when pressing Esc (#1817)
- Fix blank windows and startup crashes with AppImage on some newer Linux systems (#1815)
- Fix startup failures on Linux systems whose password storage rejects the app's key format (#1819)
- Keep the app usable after a space factory reset and automatically restart it if recovery requires a restart (#1820)
