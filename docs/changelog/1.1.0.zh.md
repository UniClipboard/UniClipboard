## 1.1.0 - 2026-10-03

### Features

- 重新设计 macOS 快捷面板，提供搜索建议、按标签、设备、内容类型和日期筛选的功能，以及独立的内容预览 (#1786)
- 在网络设置中显示内置中继服务器，以及当前中继设置是否已生效 (#1813)
- 新增命令，可为已解锁且只有一台设备的空间修改口令，同时保留本地历史记录 (#1802)
- 在命令行中显示文件传输进度，并支持设置发送时等待设备连接的时长 (#1765)

### Fixes

- 重启后保留桌面窗口的大小、最大化状态，以及系统支持时的窗口位置 (#1772)
- 减少在 macOS 快捷面板中浏览图片时的过量内存占用 (#1806)
- 按下 Esc 后，macOS 快捷面板可及时关闭 (#1817)
- 修复 AppImage 在部分较新的 Linux 系统上出现空白窗口或启动崩溃的问题 (#1815)
- 修复部分 Linux 系统因密码存储服务拒绝应用的密钥格式而无法启动的问题 (#1819)
- 修复空间恢复出厂设置后应用无法继续使用的问题，并在恢复需要重启时自动重启应用 (#1820)
