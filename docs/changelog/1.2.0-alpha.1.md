## 1.2.0-alpha.1 - 2026-10-10

### Features

- Browse clipboard history in a redesigned list with a collapsible sidebar, a detail pane, and bulk pin, send, and delete actions (#1844)
- See result counts in search suggestions and remove individual filters when a search finds nothing (#1842)
- Search with multiple tags and use #tag, /image, and @device shortcuts with suggestions as you type (#1846)
- Edit and organize tags, inspect per-device delivery status, and zoom, save, or open images from the detail pane (#1848)
- Run UniClipboard in the foreground from the command line or manage a service that starts at login on macOS and Linux (#1864)

### Fixes

- Fix Windows startup failures immediately after initial setup, quitting that could hang after pressing Alt, and stale tray menus (#1928)
- Fix window controls and quick-panel shortcut registration when launching the Linux app outside the application menu (#1929)
- Fix quick-panel sizing on Linux X11 so smaller window-scale settings take effect (#1883)
- Fix opening links, folders, and images in external applications from the Linux AppImage (#1884)
- Keep Linux tray menus up to date when devices, sync preferences, or the app language change (#1891)
- Explain why the app cannot start when a background service from a different version is already running (#1927)
