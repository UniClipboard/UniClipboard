## 1.2.0-alpha.1 - 2026-10-10

### Features

- 全新历史记录列表提供可折叠侧栏、详情面板，以及批量置顶、发送和删除操作 (#1844)
- 搜索建议显示匹配数量，搜索无结果时可逐项移除筛选条件 (#1842)
- 支持同时按多个标签搜索，并可输入 #标签、/image 和 @设备等快捷筛选，边输入边查看建议 (#1846)
- 可编辑和整理标签、查看各设备的发送状态，并在详情面板中缩放、保存或用外部应用打开图片 (#1848)
- 可通过命令行在前台运行 UniClipboard，或在 macOS 和 Linux 上管理登录时自动启动的服务 (#1864)

### Fixes

- 修复 Windows 上初始设置后立即启动失败、按下 Alt 后退出可能卡住，以及托盘菜单未及时更新的问题 (#1928)
- 修复 Linux 上窗口控制按钮失效，以及从应用菜单之外启动时快捷面板快捷键无法注册的问题 (#1929)
- 修复 Linux X11 上快捷面板无法应用较小窗口缩放设置的问题 (#1883)
- 修复 Linux AppImage 无法用外部应用打开链接、文件夹和图片的问题 (#1884)
- 修复 Linux 托盘菜单在设备、同步偏好或应用语言变更后未及时更新的问题 (#1891)
- 当其他版本的后台服务正在运行而导致应用无法启动时，明确说明原因 (#1927)
