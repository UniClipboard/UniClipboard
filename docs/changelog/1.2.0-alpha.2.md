## 1.2.0-alpha.2 - 2026-10-10

### Breaking Changes

- Use `/image` and `@Device` instead of `type:image` and `from:Device` to filter searches by content type and device (#1846)
- Use `on:` instead of `time:` for date filters in searches (#1842)

### Features

- Browse clipboard history in a list with a collapsible sidebar and a detail pane, and pin, send, or delete multiple items at once (#1844)
- See result counts beside search suggestions and remove suggested filters when a search finds nothing (#1842)
- Filter clipboard history by multiple tags at once (#1846)
- Expand clipboard details with editable colored tags, image zoom and save options, and per-device resend controls (#1848)
- Keep Linux AppImage data beside the app in a portable `.home` folder (#1879)
- Run UniClipboard in the foreground or manage it as a background service from the command line (#1864)

### Fixes

- Fix stale tray menus and startup failures after command-line setup on Windows (#1928)
- Fix duplicate window controls and quick-panel shortcut registration when launching the Linux AppImage outside the application menu (#1929)
- Make smaller quick-panel window sizes take effect on Linux X11 (#1883)
- Fix opening links, files, and images in external applications from the Linux AppImage (#1884)
- Show recovery instructions when an older version is still running and prevents the updated app from starting (#1927)
