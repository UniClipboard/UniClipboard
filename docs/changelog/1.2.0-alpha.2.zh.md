## 1.2.0-alpha.2 - 2026-10-10

### Breaking Changes

- 按内容类型和设备筛选搜索时，请使用 `/image` 和 `@设备名`，替代原来的 `type:image` 和 `from:设备名` (#1846)
- 搜索中的日期筛选前缀由 `time:` 改为 `on:` (#1842)

### Features

- 剪贴板历史采用列表、可折叠侧栏和详情栏布局，支持批量置顶、发送和删除 (#1844)
- 搜索建议显示匹配数量，搜索无结果时可按提示移除筛选条件 (#1842)
- 支持同时选择多个标签筛选剪贴板历史 (#1846)
- 详情栏新增彩色标签编辑、图片缩放与保存选项，以及按设备重新发送的操作 (#1848)
- Linux AppImage 支持将数据保存在应用旁的便携式 `.home` 文件夹中 (#1879)
- 支持通过命令行在前台运行 UniClipboard，或将其作为后台服务管理 (#1864)

### Fixes

- 修复 Windows 托盘菜单更新不及时，以及命令行初始化后应用无法启动的问题 (#1928)
- 修复窗口控制按钮重复，以及从应用菜单之外启动 Linux AppImage 时快捷面板快捷键无法注册的问题 (#1929)
- 修复 Linux X11 下快捷面板无法缩小到设定尺寸的问题 (#1883)
- 修复 Linux AppImage 无法通过外部应用打开链接、文件和图片的问题 (#1884)
- 更新后若旧版本仍在运行并阻止应用启动，现在会显示恢复操作提示 (#1927)
