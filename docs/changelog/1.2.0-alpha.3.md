## 1.2.0-alpha.3 - 2026-10-14

### Features

- Redesign History on macOS with list and grid views, adjustable card sizes, tag management, and larger image previews (#1963)
- Give History a Windows 11 look with list and grid views, tag management, and larger image previews (#1962)
- Refresh the Linux interface across History, Settings, setup, and unlocking (#1989)
- Redesign Settings to match the look of macOS (#1977)
- Redesign Settings to match the look of Windows 11 (#1987)
- Refresh setup, startup, and unlock screens on macOS and Windows (#1968)
- Select multiple history entries to pin, send, or delete them together (#1844)
- Search History with suggestions, multiple tags, and the same type and device shortcuts used in the quick panel (#1846)
- Show match counts for search filters and suggest which filters to remove when no results are found (#1842)
- Show each device’s security update progress and explain when action is needed (#1951)
- Add a native quick panel on Windows for browsing history and pasting into the previous app (#1950)
- Unlock clipboard history directly in the quick panel without opening the main window (#1975)
- Make command-line device-group choices easier with device names, numbered options, and explanations of their effects (#1954)
- Add commands to run clipboard syncing in the foreground or manage it as a service that starts at login on macOS and Linux (#1864)

### Fixes

- Prevent quick-panel text previews from briefly showing another entry’s content when switching entries (#1991)
- Keep the quick panel and its preview together on one display and within the usable screen area (#1975)
- Fix the macOS quick panel’s modifier-key double-tap trigger (#1988)
- Correctly record keyboard shortcuts that combine Option with letter or number keys (#1986)
- Allow History search filters to be entered after ordinary search text (#1974)
- Allow History to load beyond 200 entries instead of getting stuck loading older items (#1964)
- Prevent repeated loading updates when browsing History in grid view (#1973)
