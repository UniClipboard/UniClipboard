## 1.2.0-alpha.3 - 2026-10-14

### Features

- 重新设计 macOS 历史记录界面，支持列表与网格视图、卡片大小调整、标签管理和大图预览 (#1963)
- 为 Windows 历史记录提供 Windows 11 风格界面，支持列表与网格视图、标签管理和大图预览 (#1962)
- 更新 Linux 的历史记录、设置、初始配置和解锁界面 (#1989)
- 重新设计设置界面，使其更符合 macOS 的视觉风格 (#1977)
- 重新设计设置界面，使其更符合 Windows 11 的视觉风格 (#1987)
- 更新 macOS 和 Windows 的初始配置、启动和解锁界面 (#1968)
- 支持同时选中多条历史记录，批量置顶、发送或删除 (#1844)
- 历史记录搜索支持输入建议、多标签筛选，以及与快捷面板一致的内容类型和设备筛选简写 (#1846)
- 显示搜索筛选项的匹配数量，并在没有结果时建议移除哪些筛选条件 (#1842)
- 显示各设备的安全更新进度，并说明何时需要用户处理 (#1951)
- 为 Windows 提供原生快捷面板，用于浏览历史记录并粘贴到之前使用的应用 (#1950)
- 支持直接在快捷面板中解锁剪贴板历史记录，无需打开主窗口 (#1975)
- 命令行设备组操作显示设备名称、编号选项和操作影响，方便选择 (#1954)
- 新增命令，支持在前台运行剪贴板同步，或在 macOS 和 Linux 上将其设置为登录时启动的服务 (#1864)

### Fixes

- 修复切换条目时快捷面板的文本预览短暂显示其他条目内容的问题 (#1991)
- 确保快捷面板及其预览位于同一显示器，并保持在屏幕可用区域内 (#1975)
- 修复 macOS 快捷面板的修饰键双击触发功能 (#1988)
- 修复包含 Option 与字母或数字键的快捷键无法正确录入的问题 (#1986)
- 修复在普通搜索文本后输入历史记录筛选条件无法生效的问题 (#1974)
- 修复历史记录超过 200 条后无法继续加载旧条目并一直显示加载中的问题 (#1964)
- 修复以网格视图浏览历史记录时反复触发加载更新的问题 (#1973)
