## 1.2.0-alpha.4 - 2026-10-14

### Features

- Browse History in a list with a collapsible sidebar, a separate detail pane, and bulk selection. (#1844)
- Edit and organize tags, inspect image previews, and resend clipboard items to individual devices from History. (#1848)
- Search with suggestions and combine multiple tags with content-type and device filters. (#1846)
- See match counts for search filters and remove a suggested filter when a search finds nothing. (#1842)
- Give History a refreshed macOS appearance. (#1963)
- Give History a refreshed Windows 11 appearance. (#1962)
- Refresh setup, startup, and unlock screens to match macOS and Windows 11. (#1968)
- Redesign Settings with macOS-style controls and confirmation dialogs. (#1977)
- Redesign Settings with Windows 11-style cards and controls. (#1987)
- Give History, Settings, setup, startup, and unlock screens a consistent Linux appearance. (#1989)
- Unlock clipboard content directly from the Quick Panel with your passphrase. (#1975)
- Show each device’s security update status and explain when further action is needed. (#1951)
- Make command-line device-group choices easier with device names, numbered options, and explanations of their effects. (#1954)
- Add command-line options to run UniClipboard in the foreground and manage it as a background service. (#1864)

### Fixes

- Prevent Quick Panel text previews from showing another item’s content. (#1991)
- Keep the Quick Panel and its preview together on the same display. (#1975)
- Restore the modifier-key double-tap trigger for the Quick Panel on macOS. (#1988)
- Allow shortcuts containing Option and a letter or number to be recorded correctly. (#1986)
- Allow History search filters to be added after search text without losing the surrounding text. (#1974)
- Allow History to load older entries beyond the first 200 results. (#1964)
- Prevent History from repeatedly refreshing while loading more entries. (#1973)
