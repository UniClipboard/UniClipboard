## 1.2.0-alpha.4 - 2026-10-14

### Features

- 历史页面新增列表布局、可折叠侧栏、独立详情栏和批量选择。 (#1844)
- 可在历史页面编辑和整理标签、查看图片预览，并向指定设备重新发送剪贴板内容。 (#1848)
- 搜索支持输入建议，可组合多个标签以及内容类型和来源设备筛选。 (#1846)
- 搜索筛选项显示匹配数量，无结果时可按建议移除筛选条件。 (#1842)
- 历史页面采用全新的 macOS 风格界面。 (#1963)
- 历史页面采用全新的 Windows 11 风格界面。 (#1962)
- 设置向导、启动和解锁页面采用与 macOS 和 Windows 11 一致的界面风格。 (#1968)
- 设置页面采用 macOS 风格的控件和确认对话框。 (#1977)
- 设置页面采用 Windows 11 风格的卡片和控件。 (#1987)
- 历史、设置、设置向导、启动和解锁页面采用统一的 Linux 风格界面。 (#1989)
- 可直接在快捷面板中输入口令解锁剪贴板内容。 (#1975)
- 显示各设备的安全更新状态，并说明何时需要用户处理。 (#1951)
- 命令行中的设备组选择显示设备名称、编号选项及其影响说明，方便用户作出选择。 (#1954)
- 新增命令行选项，可在前台运行 UniClipboard 或将其作为后台服务管理。 (#1864)

### Fixes

- 修复快捷面板文本预览显示其他条目内容的问题。 (#1991)
- 修复快捷面板与预览窗口出现在不同显示器上的问题。 (#1975)
- 修复 macOS 上双击修饰键无法打开快捷面板的问题。 (#1988)
- 修复包含 Option 与字母或数字的快捷键无法正确录入的问题。 (#1986)
- 修复无法在历史搜索正文后添加筛选条件的问题，并保留条件前后的正文。 (#1974)
- 修复历史页面只能加载前 200 条结果、无法继续查看更早条目的问题。 (#1964)
- 修复历史页面加载更多条目时反复刷新的问题。 (#1973)
