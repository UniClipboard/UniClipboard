## 1.2.0-alpha.5 - 2026-10-14

### Features

- Give History a macOS-style layout with list and grid views and a detail pane (#1963)
- Give History a Windows 11-style layout with list and grid views (#1962)
- Refresh Settings with a macOS-style layout (#1977)
- Refresh Settings with a Windows 11-style layout (#1987)
- Give Linux a consistent desktop-style interface across History, Settings, setup and unlock screens (#1989)
- Refresh setup, startup and unlock screens to match macOS and Windows 11 (#1968)
- Select multiple history entries to pin, send or delete them together (#1844)
- Search with suggestions and multiple tags, using / for content types, @ for devices and # for tags (#1846)
- Show matching item counts for search filters and suggest filters to remove when no results are found (#1842)
- Edit and organize history tags, and zoom, save or open image previews in another app (#1848)
- Add a redesigned Windows quick panel with a separate preview that keeps search focused (#1950)
- Unlock clipboard content directly from the quick panel (#1975)
- Show each device’s security update delivery status and explain when action is needed (#1951)
- Make command-line device-group choices easier with device names, numbered options and explanations of their impact (#1954)

### Fixes

- Prevent the quick panel from briefly showing text from a different entry when switching previews (#1991)
- Keep the quick panel and its preview together on the same display without placing the preview off-screen (#1975)
- Allow History to load beyond 200 entries instead of getting stuck loading (#1964)
- Recognize search filters typed after ordinary search text (#1974)
- Correctly record macOS shortcuts that combine Option with a letter or number (#1986)
- Fix macOS modifier double-tap detection and allow choosing the trigger before granting Accessibility permission (#1988)
- Keep Windows portable builds’ interface preferences inside their own folder and separate preferences between profiles (#1965)
- Improve Windows startup, quitting and tray menu refresh reliability (#1928)
