## 1.2.0-alpha.5 - 2026-10-14

### Features

- 历史记录采用 macOS 风格布局，提供列表、网格视图和详情面板 (#1963)
- 历史记录采用 Windows 11 风格布局，提供列表和网格视图 (#1962)
- 设置页面采用全新的 macOS 风格布局 (#1977)
- 设置页面采用全新的 Windows 11 风格布局 (#1987)
- Linux 的历史记录、设置、初始设置和解锁页面采用统一的桌面风格界面 (#1989)
- 初始设置、启动和解锁页面采用与 macOS 和 Windows 11 相匹配的界面风格 (#1968)
- 支持选择多条历史记录并批量置顶、发送或删除 (#1844)
- 搜索支持输入建议和多标签筛选，可用 / 筛选内容类型、@ 筛选设备、# 筛选标签 (#1846)
- 显示搜索筛选条件的匹配数量，并在无结果时提示可移除的筛选条件 (#1842)
- 支持编辑和整理历史记录标签，并可缩放、保存图片预览或在其他应用中打开图片 (#1848)
- Windows 快捷面板采用全新设计，独立的预览窗口不会抢走搜索焦点 (#1950)
- 可直接在快捷面板中解锁剪贴板内容 (#1975)
- 显示各设备的安全更新送达状态，并说明何时需要用户处理 (#1951)
- 命令行设备组选择显示设备名称、编号选项及其影响说明，方便用户操作 (#1954)

### Fixes

- 修复快捷面板切换预览时短暂显示其他记录文本的问题 (#1991)
- 修复快捷面板与预览出现在不同显示器或预览超出屏幕边界的问题 (#1975)
- 修复历史记录超过 200 条后无法继续加载的问题 (#1964)
- 修复在普通搜索文本后输入筛选条件无法识别的问题 (#1974)
- 修复 macOS 上无法正确录入 Option 与字母或数字组合快捷键的问题 (#1986)
- 修复 macOS 修饰键双击检测，并允许在授予辅助功能权限前选择触发按键 (#1988)
- 修复 Windows 便携版界面偏好写入自身目录之外的问题，并隔离不同配置的界面偏好 (#1965)
- 修复 Windows 启动、退出和托盘菜单刷新不可靠的问题 (#1928)
