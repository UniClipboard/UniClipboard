## 1.2.0-alpha.6 - 2026-10-20

### Features

- Browse History in a redesigned macOS window with a sidebar and detail pane (#1963)
- Browse History in a redesigned Windows 11-style window (#1962)
- Use a Linux-style interface for History, Settings, setup and unlocking (#1989)
- Find settings more easily in the redesigned macOS Settings page (#1977)
- Use a redesigned Windows Settings page with Windows 11-style controls (#1987)
- Manage devices, invitations and sync preferences without leaving History (#2010)
- Organize clipboard history with editable tags, tag colors and bulk tagging (#1848)
- Narrow searches with suggestions, multiple tags and shortcuts for content types and devices (#1846)
- See result counts for search filters and suggestions for broadening searches that find nothing (#1842)
- Unlock clipboard content directly from the quick panel (#1975)
- See which devices are still waiting for a security update and whether action is needed (#1951)
- Run UniClipboard in the foreground or manage it as a background service from the command line (#1864)
- Resolve device-group choices in the command line using device names and numbered options (#1954)
- Keep Linux AppImage data alongside the app when using portable mode (#1879)
- Use system proxy settings in the Linux AppImage (#1889)

### Fixes

- Prevent the quick panel from briefly showing text from a different history entry (#1991)
- Keep the quick panel and its preview together on the same display (#1975)
- Allow shortcuts containing Option with a letter or number to be recorded correctly on macOS (#1986)
- Recognize search filters typed after ordinary search text (#1974)
- Allow History to load beyond the first 200 entries (#1964)
- Prevent History from repeatedly refreshing while loading more entries (#1973)
- Improve Windows startup, quitting and tray-menu updates (#1928)
