## 1.2.0-alpha.6 - 2026-10-20

### Features

- macOS 历史记录窗口焕新，提供侧边栏和详情面板 (#1963)
- Windows 历史记录窗口采用全新的 Windows 11 风格界面 (#1962)
- Linux 的历史记录、设置、初始化和解锁页面采用统一的系统风格界面 (#1989)
- macOS 设置页面重新设计，让各项设置更易查找 (#1977)
- Windows 设置页面焕新，采用 Windows 11 风格的控件 (#1987)
- 无需离开历史记录即可管理设备、邀请和同步偏好 (#2010)
- 通过编辑标签、设置标签颜色和批量添加标签整理剪贴板历史记录 (#1848)
- 通过搜索建议、多标签以及内容类型和设备的快捷筛选缩小搜索范围 (#1846)
- 查看搜索筛选条件的匹配数量，并在无结果时获得放宽筛选的建议 (#1842)
- 直接在快捷面板中解锁剪贴板内容 (#1975)
- 查看哪些设备仍在等待安全更新，以及是否需要手动处理 (#1951)
- 通过命令行在前台运行 UniClipboard，或将其作为后台服务管理 (#1864)
- 在命令行中根据设备名称和编号选项处理设备组中的待确认事项 (#1954)
- 使用便携模式时，将 Linux AppImage 的数据保存在应用旁 (#1879)
- Linux AppImage 支持使用系统代理设置 (#1889)

### Fixes

- 修复快捷面板短暂显示另一条历史记录正文的问题 (#1991)
- 确保快捷面板及其预览窗口显示在同一块屏幕上 (#1975)
- 修复 macOS 无法正确录入 Option 与字母或数字组合快捷键的问题 (#1986)
- 修复在普通搜索文字后输入筛选条件时无法识别的问题 (#1974)
- 修复历史记录无法继续加载前 200 条以外内容的问题 (#1964)
- 修复历史记录加载更多条目时反复刷新的问题 (#1973)
- 修复 Windows 启动、退出和托盘菜单更新不可靠的问题 (#1928)
