## 1.2.0-alpha.7 - 2026-10-20

### Features

- 为 macOS、Windows 11 和 Linux 换上符合各平台风格的历史记录界面 (#1963) (#1962) (#1989)
- 重新设计设置页面，使其更贴合 macOS 和 Windows 11 的界面风格 (#1977) (#1987)
- 支持批量置顶、发送和删除历史记录 (#1844)
- 搜索建议显示匹配数量，无结果时可直接移除筛选条件来扩大搜索范围 (#1842)
- 历史记录搜索支持多选标签，并可输入内容类型、来源设备和标签筛选条件 (#1846)
- 历史记录支持编辑标签，并改进图片查看、保存和各设备接收状态的展示 (#1848)
- 无需离开历史记录页面即可管理设备及其同步偏好 (#2010)
- 显示哪些设备仍在等待安全更新，并在发送失败时说明后续操作 (#1951)
- 为 Windows 带来重新设计的快捷面板，支持内容预览并粘贴到上一个应用 (#1950)
- 支持直接在快捷面板中解锁 (#1975)
- 新增命令行命令，可在前台运行，并在 macOS 和 Linux 上管理用户服务 (#1864)
- 命令行中的设备组交互选择支持显示设备名称、按编号选择及查看移除原因 (#1954)

### Fixes

- 修复快捷面板的文本预览可能显示其他条目内容的问题 (#1991)
- 修复快捷面板及其预览可能分散在不同显示器上的问题 (#1975)
- 修复 macOS 上双击修饰键无法打开快捷面板的问题 (#1988)
- 修复录制 Option 与字母或数字组合的快捷键时识别错误的问题 (#1986)
- 修复搜索文字后无法正常添加历史记录筛选条件的问题，并保留筛选条件前后的文字 (#1974)
- 修复历史记录只能浏览前 200 条结果的问题 (#1964)
- 修复网格视图加载更多历史记录时反复更新的问题 (#1973)
- 改善 Windows 上应用启动、退出及托盘菜单更新的可靠性 (#1928)
- 修复 Linux 上在 Wayland 环境中切换主题可能导致应用崩溃的问题 (#1989)
