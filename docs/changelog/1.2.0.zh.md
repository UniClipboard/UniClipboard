## 1.2.0 - 2026-10-20

### Features

- 在 macOS 上使用重新设计的剪贴板历史界面，通过侧边栏和详情面板浏览记录 (#1963)
- 在 Windows 上使用全新 Windows 11 风格的剪贴板历史界面 (#1962)
- 在 Linux 上使用统一的系统风格界面，涵盖历史记录、设置、首次设置和解锁页面 (#1989)
- 使用更贴合 macOS 风格的全新设置页面 (#1977)
- 使用更贴合 Windows 11 风格的全新设置页面 (#1987)
- 无需离开历史记录页面即可管理已配对设备和同步偏好 (#2010)
- 一次选择多条历史记录，批量置顶、发送或删除 (#1844)
- 使用自定义彩色标签整理历史记录，并在详情面板中查看、保存图片或用其他应用打开图片 (#1848)
- 通过搜索建议、多个标签以及内容类型和来源设备的快捷筛选查找记录 (#1846)
- 查看搜索筛选条件的匹配数量，并在没有结果时按建议移除筛选条件 (#1842)
- 直接在快捷面板中输入口令解锁剪贴板 (#1975)
- 在 Windows 上使用原生快捷面板 (#1950)

### Fixes

- 修复切换历史记录时详情预览不稳定或无法滚动的问题 (#2035)
- 修复快捷面板短暂显示其他记录文本的问题 (#1991)
- 修复快捷面板与预览窗口出现在不同显示器上的问题 (#1975)
- 修复在普通搜索文字后无法添加筛选条件的问题 (#1974)
- 修复历史记录加载到 200 条后无法继续显示更多记录的问题 (#1964)
- 修复加载更多历史记录时反复刷新的问题 (#1973)
- 修复无法正确录入 Option 与字母键或数字键组合的快捷键的问题 (#1986)
- 修复 macOS 上双击修饰键唤出快捷面板不可靠的问题 (#1988)
- 修复 Windows 上启动、退出和托盘菜单刷新不可靠的问题 (#1928)
- 修复 Linux X11 桌面上调小快捷面板窗口后尺寸不生效的问题 (#1883)
