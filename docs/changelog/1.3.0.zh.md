## 1.3.0 - 2026-10-21

### Features

- 支持选择自动、效果优先或流畅优先的视觉效果模式，并在重启应用后保留选择 (#2050)
- 支持在「通用 → 托盘图标」中切换默认的双卡片图标与经典猫头图标，切换后即时生效 (#2052)

### Fixes

- 保持各窗口的设置一致，让快捷面板快捷键的更改可靠生效，并在快捷键无法启用时明确提示 (#2052)
- 修复 Linux 系统托盘菜单无法显示的问题，并正确显示 UniClipboard 应用名称 (#2051)
- 在侧栏添加带文字的设备管理入口，方便查找 (#2048)
- 改善 Linux 窄窗口下的历史记录浏览，支持收起侧栏并从条目详情返回列表 (#2049)
- 在无法通过口令恢复时提供诊断导出和恢复指引 (#2032)
- 降低 Linux 上复制图片后的内存占用 (#2055)
