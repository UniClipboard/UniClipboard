## 1.3.1 - 2026-10-22

### Features

- Choose between the default icon and the classic cat in the menu bar or system tray (#2052)
- Keep your visual-effects preference across restarts and let Auto reduce effects on the next launch after repeated slow interactions (#2050)
- Include desktop preferences in configuration backups and offer a guided retry when an older pending import cannot complete (#2061)

### Fixes

- Keep settings changes in sync across windows without overwriting unrelated preferences or prompting for unnecessary restarts (#2052)
- Preserve an existing configuration backup if exporting its replacement fails (#2061)
- Make device management accessible from the sidebar even when the device list is collapsed or empty (#2048)
- Keep history browsing, search, and navigation usable in narrow Linux windows (#2049)
- Restore the Linux tray menu and identify its icon as UniClipboard (#2051)
- Show recovery guidance when a passphrase cannot restore access to a space (#2032)
- Stop continuous progress-bar animation on Windows when reduced motion is enabled (#2066)
