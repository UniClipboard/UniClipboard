## 1.4.0-alpha.2 - 2026-10-22

### Features

- Search clipboard history with suggestions and combined filters for content type, source device, tags, date, and file extension (#1846)
- See matching item counts beside search filters and remove suggested filters when a search finds nothing (#1842)
- Edit and color-code tags, preview images at full size, and save or open images from history details (#1848)
- Sync folders between devices while preserving their directory structure (#1323)
- Choose a folder where received files are saved automatically and kept after history deletion (#1271)
- Resend clipboard items to devices that have not received them (#806)
- Pause or resume syncing for all devices or individual devices from the tray menu (#1638)
- Use a keyboard-driven quick panel on Windows to search clipboard history and paste into the previous app (#1950)
- Open the quick panel by double-tapping a chosen modifier key on macOS (#1364)
- Unlock clipboard history directly from the quick panel (#1975)
- Customize colors across the desktop interface and optionally follow the Omarchy desktop theme (#2071)
- Save your visual effects preference and use Smooth Mode to reduce animations and transparency (#2050)

### Fixes

- Restore the main window size and maximized state after restarting the app (#2074)
- Recover from temporary Linux secure-storage startup failures using Retry once the service becomes available (#2081)
- Release window resources when the main window closes while keeping tray controls and background sync available (#2078)
- Prevent the Windows quick panel from crashing when a requested font is unavailable (#2072)
- Show update notes covering changes since the installed version, with a notice when older notes are omitted (#2070)
- Stop continuously animated progress indicators on Windows when reduced motion is enabled (#2066)
- Make the Linux tray menu available on desktops that require it to be published separately (#2051)
- Keep history navigation usable in narrow Linux windows (#2049)
- Keep history detail previews stable and scrollable when switching between entries (#2035)
- Prevent the quick panel from briefly showing text from the previously selected entry (#1991)
- Make the macOS modifier double-tap shortcut work reliably and allow its configuration before Accessibility permission is granted (#1988)
- Correctly record macOS shortcuts that combine Option with letter or number keys (#1986)
- Keep the quick panel and its preview together on the same display (#1975)
- Recognize search filters entered after ordinary search text (#1974)
- Load clipboard history beyond the first 200 results (#1964)
