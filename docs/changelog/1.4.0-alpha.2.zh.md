## 1.4.0-alpha.2 - 2026-10-22

### Features

- 搜索剪贴板历史时可查看输入建议，并组合使用内容类型、来源设备、标签、日期和文件扩展名筛选条件 (#1846)
- 查看各筛选条件的匹配数量，并在没有搜索结果时按建议移除筛选条件 (#1842)
- 编辑标签并设置颜色，在历史详情中查看原尺寸图片、另存图片或用外部应用打开图片 (#1848)
- 跨设备同步文件夹并保留目录结构 (#1323)
- 选择接收文件的自动保存目录，并在删除历史记录后保留这些文件 (#1271)
- 向尚未收到内容的设备重新发送剪贴板条目 (#806)
- 通过托盘菜单暂停或恢复所有设备或单个设备的同步 (#1638)
- 在 Windows 上通过键盘操作快捷面板，搜索剪贴板历史并粘贴到之前使用的应用 (#1950)
- 在 macOS 上双击选定的修饰键打开快捷面板 (#1364)
- 直接在快捷面板中解锁剪贴板历史 (#1975)
- 自定义桌面界面各处的配色，并可选择跟随 Omarchy 桌面主题 (#2071)
- 保存视觉效果偏好，并通过流畅模式减少动画和透明效果 (#2050)

### Fixes

- 重启应用后恢复主窗口大小和最大化状态 (#2074)
- Linux 安全存储服务暂时不可用导致启动失败后，可在服务恢复时点击重试继续启动 (#2081)
- 关闭主窗口后释放窗口资源，同时保持托盘操作和后台同步可用 (#2078)
- 修复 Windows 快捷面板在所需字体不可用时崩溃的问题 (#2072)
- 更新说明展示当前已安装版本之后的变化，并在省略较早版本说明时给出提示 (#2070)
- 在 Windows 启用减少动态效果后，停止进度指示器的持续动画 (#2066)
- 修复部分 Linux 桌面环境无法显示托盘菜单的问题 (#2051)
- 修复 Linux 窗口较窄时历史记录导航难以使用的问题 (#2049)
- 修复切换条目时历史详情预览不稳定或无法滚动的问题 (#2035)
- 修复快捷面板短暂显示上一个所选条目文本的问题 (#1991)
- 修复 macOS 修饰键双击快捷键失效的问题，并允许在授予辅助功能权限前设置该快捷键 (#1988)
- 正确录入 macOS 上由 Option 与字母键或数字键组合的快捷键 (#1986)
- 确保快捷面板及其预览显示在同一块屏幕上 (#1975)
- 正确识别在普通搜索文本后输入的筛选条件 (#1974)
- 修复剪贴板历史只能加载前 200 条结果的问题 (#1964)
