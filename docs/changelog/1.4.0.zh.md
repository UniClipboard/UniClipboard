## 1.4.0 - 2026-10-23

### Features

- 优化连接手机和切换空间的分步操作，将设置、连接信息和重试操作集中在同一面板中 (#2086)
- 统一应用和快捷面板的主题配色，支持各平台默认配色，并可选择跟随 Omarchy 主题 (#2071)
- 配置备份现在包含桌面偏好设置，并为未完成的导入提供更清晰的恢复指引及替换前确认 (#2061)

### Fixes

- 修复重启后主窗口尺寸和最大化状态无法保留的问题 (#2074)
- 关闭主窗口后释放窗口资源并保持后台同步，自动检查更新也不会重新打开已关闭的窗口 (#2078)
- 修复 Linux 上安全存储暂时不可用导致的启动失败，支持自动重试并在安全存储恢复后手动重试启动 (#2081)
- 检查更新时显示自当前已安装版本以来的更新内容 (#2070)
- 修复 Windows 快捷面板在所需字体不可用时崩溃的问题 (#2072)
- 修复 Windows 上启用减少动态效果后进度条仍持续播放动画的问题 (#2066)
