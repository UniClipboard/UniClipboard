## 1.5.0-alpha.1 - 2026-10-23

### Breaking Changes

- Linux packages now require newer systems, including glibc 2.39 or later for AppImage, and the Wayland quick panel now uses a regular window without overlay placement or exclusive keyboard control (#2094)

### Features

- The installer now selects Snap on Ubuntu 22.04, its derivatives, and Debian 11/12 to avoid incompatible native packages (#2094)

### Fixes

- Make fonts in the Windows quick panel and preview window consistent with the main window, including Chinese text (#2098)
