## 1.5.0-alpha.1 - 2026-10-23

### Breaking Changes

- Linux 的 deb、rpm 和 AppImage 安装包现在要求 glibc 2.39 或更新版本，快捷面板改用普通窗口，不再提供原有的覆盖层定位和独占键盘输入行为 (#2094)

### Features

- Linux 快捷面板现在可直接解锁，无需打开主窗口，macOS 和 Windows 的备用面板也支持此操作 (#2102)

### Fixes

- 修复 Linux 快捷面板窗口大小和文字缩放不生效的问题，支持将文字缩小至 100% 以下 (#2102)
- 统一 Windows 快捷面板、预览窗口与主窗口的字体，包括中文字体 (#2098)
