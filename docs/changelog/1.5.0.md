## 1.5.0 - 2026-10-26

### Breaking Changes

- Linux .deb, .rpm, and AppImage downloads now require glibc 2.39 or newer, and the installer selects Snap on Ubuntu 20.04/22.04 and Debian 11/12 (#2094)

### Features

- See individual file receive results in history details and retry failed files without downloading successfully saved files again (#2108)

### Fixes

- Show image previews for individual image files in the native Quick Panel (#2105)
- Keep the native Quick Panel unlocked when closing the main window or entering lightweight mode, and dismiss it when switching to another window on Windows (#2103)
- Unlock directly in the Quick Panel without opening the main window, and correctly shrink the panel window and text below 100% on Linux (#2102)
- Make Windows Quick Panel fonts consistent with the main window, including Chinese text (#2098)
