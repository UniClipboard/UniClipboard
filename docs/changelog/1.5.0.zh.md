## 1.5.0 - 2026-10-26

### Breaking Changes

- Linux 的 .deb、.rpm 和 AppImage 安装包现在要求 glibc 2.39 或更新版本，安装脚本在 Ubuntu 20.04/22.04 和 Debian 11/12 上改用 Snap (#2094)

### Features

- 在历史详情中查看各个文件的接收结果，并仅重试失败的文件，无需重新下载已保存的文件 (#2108)

### Fixes

- 修复原生快捷面板无法预览单个图片文件的问题 (#2105)
- 关闭主窗口或进入轻量模式后，原生快捷面板保持解锁，并在 Windows 上切换到其他窗口时自动收起 (#2103)
- 支持直接在快捷面板内解锁，无需打开主窗口，并修复 Linux 上面板窗口和文字无法缩小到 100% 以下的问题 (#2102)
- 统一 Windows 快捷面板与主窗口的字体显示，包括中文字体 (#2098)
