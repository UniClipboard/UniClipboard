## 1.6.0-alpha.1 - 2026-10-30

### Features

- Show sending progress for each device and ask for confirmation before resending starts a new transfer (#2129)
- Keep settings readable in narrow windows by moving category navigation into a collapsible drawer (#2126)
- Add a separate background startup option so you can choose whether the main window opens at login independently of desktop mode (#2114)

### Fixes

- Keep background sync running when switching desktop modes or closing lightweight windows, show the window when opening the app manually, reduce update memory usage, and direct package-managed installations to their package manager for updates (#2114)
