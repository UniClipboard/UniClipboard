## 1.6.0-alpha.4 - 2026-10-31

### Features

- Show sending progress for each destination device and ask for confirmation before resending starts a new transfer (#2129)
- Keep settings easy to use in narrow windows with a collapsible category drawer (#2126)
- Use smaller image previews to reduce memory use when browsing clipboard history (#2145)

### Fixes

- Allow browsing older and newer history entries with the mouse wheel or Page Up and Page Down even when all currently loaded entries fit in the window (#2150)
- Show upgrade progress while the app is starting instead of leaving the main window hidden (#2149)
- Keep syncing when closing a lightweight window or switching desktop modes, and respect the separate background startup setting (#2114)
