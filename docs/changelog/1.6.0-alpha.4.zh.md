## 1.6.0-alpha.4 - 2026-10-31

### Features

- 显示向各台设备发送内容的进度，并在重新发送需要发起新传输时请求确认 (#2129)
- 窄窗口下将设置分类收起为可展开的抽屉，让设置内容更易查看和操作 (#2126)
- 浏览剪贴板历史时使用更小的图片预览，减少内存占用 (#2145)

### Fixes

- 即使当前加载的历史记录全部显示在窗口内，也能通过鼠标滚轮或 Page Up、Page Down 浏览更早或更新的记录 (#2150)
- 应用启动时显示升级进度，避免主窗口一直隐藏 (#2149)
- 关闭轻量模式窗口或切换桌面模式时保持同步，并遵循独立的后台启动设置 (#2114)
