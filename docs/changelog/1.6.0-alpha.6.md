## 1.6.0-alpha.6 - 2026-11-02

### Features

- Show individual file sending and receiving progress, transfer status, and failure reasons in history details (#2172)
- Add compact transfer indicators beside each device, with file details available on hover or keyboard focus and an option to retry failed sends (#2179)

### Fixes

- Apply Quick Panel enablement and position changes without restarting, and refresh macOS Accessibility permission status when returning from System Settings (#2171)
- Complete Quick Panel permission translations for Japanese, Brazilian Portuguese, Russian, and Traditional Chinese (#2184)
- Match Quick Panel preview backgrounds to the history view (#2182)
- Fix saving encryption keys on Linux systems whose keyring rejected them (#2173)
- Prevent repeated macOS keychain password prompts when switching between the desktop app and command-line tool (#2160)
