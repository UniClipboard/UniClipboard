## 1.6.0-alpha.6 - 2026-11-02

### Features

- 在历史记录详情中显示每个文件的发送与接收进度、传输状态和失败原因 (#2172)
- 在各设备旁显示紧凑的传输状态指示，鼠标悬停或键盘聚焦时可查看文件详情，并可重试失败的发送 (#2179)

### Fixes

- 快捷面板的启用状态和位置设置无需重启即可生效，并在从系统设置返回时刷新 macOS 辅助功能权限状态 (#2171)
- 补全快捷面板权限提示的日语、巴西葡萄牙语、俄语和繁体中文翻译 (#2184)
- 使快捷面板预览背景与历史记录视图保持一致 (#2182)
- 修复部分 Linux 系统因密钥环拒绝写入而无法保存加密密钥的问题 (#2173)
- 修复在桌面应用与命令行工具之间切换时，macOS 反复要求输入钥匙串密码的问题 (#2160)
