## 1.6.0 - 2026-11-02

### Features

- Show image thumbnails in clipboard history while keeping full-size images available to open or copy (#2145)
- Show sending progress for each device and ask for confirmation before resending starts a new transfer (#2129)
- Show individual file transfer progress in history details (#2172)
- Make transfer status more compact and easier to read, with a look that matches your operating system (#2179)
- Keep settings navigation accessible through a drawer in narrow windows (#2126)

### Fixes

- Apply desktop mode changes without interrupting background sync, reduce memory use during updates, and direct system-managed installations to their package manager for updates (#2114)
- Prevent received text, images, and files from being sent back to other devices as newly copied content (#2190)
- Recognize copying the same content again instead of ignoring it (#2196)
- Keep newly copied entries visible at the top of history (#2191)
- Preserve history selection and prevent the scrollbar from jumping when browsing older entries (#2159)
- Allow history browsing to continue when the loaded entries all fit in a large window (#2150)
- Show sending and receiving progress while file transfers are still being prepared (#2161)
- Remove duplicate transfer progress displays from history details (#2192)
- Apply Quick Panel settings immediately and refresh macOS Accessibility permission after returning from System Settings (#2171)
- Keep the Quick Panel action menu visible while navigating between entries (#2194)
- Place Quick Panel shortcut hints at the end of each row (#2195)
- Match the Quick Panel preview background to the history preview (#2182)
- Complete translations for Quick Panel accessibility settings (#2184)
- Show startup upgrade progress instead of leaving the app waiting without feedback (#2149)
- Use the correct UniClipboard application name in the macOS Dock (#2193)
- Display the macOS menu bar icon at the correct size (#2157)
- Keep the Linux tray icon visible against the KDE panel background and update it when the theme changes (#2158)
