## 1.6.0 - 2026-11-02

### Features

- 在剪贴板历史中显示图片缩略图，并保留打开或复制原图的操作 (#2145)
- 显示各设备的发送进度，并在重新发送需要启动新传输时请求确认 (#2129)
- 在历史详情中显示每个文件的传输进度 (#2172)
- 以符合操作系统风格的紧凑界面展示传输状态，让进度更易查看 (#2179)
- 在窄窗口中通过抽屉菜单切换设置页面 (#2126)

### Fixes

- 切换桌面运行模式时保持后台同步，降低更新时的内存占用，并引导由系统管理的安装使用包管理器更新 (#2114)
- 避免将收到的文字、图片和文件当作新复制的内容再次发送给其他设备 (#2190)
- 修复再次复制相同内容时可能被忽略的问题 (#2196)
- 让新复制的条目及时显示在历史列表顶部 (#2191)
- 浏览较早的历史记录时保留选中条目，并避免滚动条跳动 (#2159)
- 修复大窗口能容纳全部已加载条目时无法继续浏览历史的问题 (#2150)
- 在文件传输准备期间正确显示发送和接收进度 (#2161)
- 移除历史详情中重复的传输进度显示 (#2192)
- 即时应用快捷面板设置，并在从系统设置返回后刷新 macOS 辅助功能权限状态 (#2171)
- 在切换条目时保持快捷面板的操作菜单可见 (#2194)
- 将快捷面板的快捷键提示放在每行末尾 (#2195)
- 统一快捷面板与历史详情的预览背景 (#2182)
- 补全快捷面板辅助功能设置的翻译 (#2184)
- 在启动升级期间显示进度，避免等待时没有反馈 (#2149)
- 在 macOS 程序坞中正确显示 UniClipboard 应用名称 (#2193)
- 以正确尺寸显示 macOS 菜单栏图标 (#2157)
- 根据 KDE 面板背景调整 Linux 托盘图标颜色，并在主题变化时更新 (#2158)
