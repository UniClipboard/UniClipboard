## 1.6.1 - 2026-11-03

### Features

- Ask for confirmation before resending starts a new transfer, and show sending progress for each device (#2129)
- Show each file’s receiving progress and save status in history details (#2172)
- Add compact transfer status indicators with expandable details in history (#2179)
- Use image thumbnails for lighter, faster history browsing while keeping original images available (#2145)
- Make settings easier to use in narrow windows with a collapsible category menu (#2126)
- Let you choose Normal or Lightweight desktop mode independently of starting in the background at login (#2114)
- Add a signed package repository for installing and updating UniClipboard with pacman on Arch Linux (#2132)

- Prevent received text, images, and files from repeatedly syncing back to other devices (#2190)
- Keep deliberate copies of the same content from being ignored on macOS (#2196)
- Keep new history entries visible when you are at the top of the list (#2191)
- Preserve the selected history entry and prevent scrollbar jumps when browsing older items (#2159)
- Fix history scrolling and keyboard navigation in large windows (#2150)
- Show sending progress and receiving progress before file details become available (#2161)
- Remove duplicate transfer progress displays from history (#2192)
- Keep the Quick Panel action menu visible while navigating between items (#2194)
- Apply Quick Panel settings without restarting and recheck macOS Accessibility permission when returning from System Settings (#2171)
- Complete translations for Quick Panel screen reader labels (#2184)
- Show upgrade progress while the background service starts (#2149)
- Restore the app’s live connection after the background service restarts (#2162)
- Keep the Linux tray icon visible on KDE panels and update it when the theme changes (#2158)
- Correct the size of macOS menu bar icons (#2157)

- Avoid repeated macOS keychain password prompts when switching between the desktop app and command-line app (#2160)
- Reduce memory use during update downloads and direct package-managed installations to their package manager for updates (#2114)
