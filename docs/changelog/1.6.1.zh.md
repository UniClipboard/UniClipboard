## 1.6.1 - 2026-11-03

### Features

- 重新发送需要启动新传输时先请求确认，并显示各设备的发送进度 (#2129)
- 在历史详情中显示每个文件的接收进度和保存状态 (#2172)
- 在历史记录中提供紧凑的传输状态提示，并可展开查看详情 (#2179)
- 使用图片缩略图提升历史浏览速度、减少资源占用，同时保留原图操作 (#2145)
- 窄窗口中的设置分类菜单可收起，让设置内容更易查看 (#2126)
- 可独立选择普通或轻量桌面模式，以及是否在登录时后台启动 (#2114)
- 新增签名软件包仓库，支持在 Arch Linux 上通过 pacman 安装和更新 UniClipboard (#2132)

### Fixes

- 防止收到的文本、图片和文件在设备间反复回传 (#2190)
- 修复 macOS 上主动再次复制相同内容时可能被忽略的问题 (#2196)
- 浏览历史列表顶部时，保持新记录可见 (#2191)
- 浏览较早的历史记录时保留选中项，并防止滚动条跳动 (#2159)
- 修复大窗口中的历史滚动和键盘导航问题 (#2150)
- 正确显示发送进度，以及文件详情尚未就绪时的接收进度 (#2161)
- 移除历史记录中重复的传输进度显示 (#2192)
- 在快捷面板中切换条目时保持操作菜单可见 (#2194)
- 快捷面板设置无需重启即可生效，并在从系统设置返回时重新检查 macOS 辅助功能权限 (#2171)
- 补全快捷面板屏幕阅读器标签的翻译 (#2184)
- 在后台服务启动期间显示升级进度 (#2149)
- 后台服务重启后恢复应用的实时连接 (#2162)
- 修复 KDE 面板上托盘图标不清晰的问题，并在主题变化时更新图标 (#2158)
- 修正 macOS 菜单栏图标的大小 (#2157)
- 在 macOS 程序坞中正确显示 UniClipboard 应用名称 (#2193)
- 避免在桌面应用与命令行应用之间切换时反复提示输入 macOS 钥匙串密码 (#2160)
- 减少下载更新时的内存占用，并引导通过软件包管理器安装的用户使用对应的管理器更新 (#2114)
