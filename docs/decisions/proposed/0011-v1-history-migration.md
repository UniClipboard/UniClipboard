- 状态：已采纳，互操作与本机验收进度见[执行计划](../../exec/0011-v1-history-migration.md)。
- 日期：2026-11-08。
- 依据：[0003](0003-engine-sdk.md)、[0005](0005-monorepo-layout.md)、[历史契约](../../contracts/history-contract.md)。

## 范围与边界

交付 macOS、Windows、Linux 各 arm64/amd64 的 `unic-migrate`。读取本机旧数据目录，迁移可恢复的文本、HTML、图片、文件、标签定义和关联；支持新目录与已有历史目录。旧身份、设备信任、网络设置不导入。

工具不依赖旧 Rust Engine。旧 crate 的依赖与启动副作用超出只读迁移需求；在 `internal/v1migration` 实现固定旧格式的只读适配，以旧 Rust 同款算法与序列化库生成的固定样本检验互操作。目标写入通过当前 `engine` 的公开导入接口，CLI 不直接写目标 SQL。

当前主要验收对象为旧产品 V3 profile。早期 KeySlot/JSON inline/UCBL V1/UCFS 读取分支不代表所有历史发布版本均已验收。未知 manifest 或未具备内容密钥目录的格式明确失败，不扫描备份目录拼凑活动状态。

## 解锁与只读保证

只读系统凭据，保留二进制秘密的原始字节；macOS 使用 generic password，Windows 按旧 keyring-rs 的 `account.service` target 读取，Linux 按 Secret Service 的旧属性查询。读取失败允许用户在终端无回显输入旧口令，或由宿主经标准输入传递；不接受口令命令行参数，不写回旧凭据。

旧数据库以 `mode=ro`、`query_only` 和读事务打开。读事务固定数据库快照，不修改源数据。建议退出旧程序；若旧程序仍运行并回收文件，缺失内容报部分迁移，不能声称文件系统和数据库共同原子快照。

## 离线导入与恢复

宿主运行相邻的 `unic-migrate`，由 CLI 独占目标 `unic.lock`。用户需先停止使用该目录的 daemon。迁移界面可存活，但 daemon 不与 CLI 并发写入。`Options.MigrationMode` 禁止 Start，导入不触发捕获、处理器、同步或系统剪贴板。

按条提交，内容落盘并同步后，在一个 SQLite 事务发布条目、标签关联和持久映射。源标识由旧 profile scope 和 MasterKey 的域分离摘要产生，移动或复制源目录不改变标识。幂等键为源标识与旧 entry id，不以正文 hash 合并记录。源删除项不导入；同内容多记录保留。

已提交条目在中断后保留，重跑跳过成功项、重试失败项、补充新增项。首次导入后源标签变化不覆盖目标编辑；目标主动删除的记录仍保留映射，重跑不复活它。校验时会报告这类已映射但不可读取或内容不同的条目。

全新目录由当前 Engine 初始化；已有目录追加历史，不替换其身份、配置或既有条目。迁移容量不触发淘汰，并持久保存容量下限：历史条数至少为导入提交时总条数加 1000，历史字节至少为总逻辑字节加 1 GiB，总内容至少为总逻辑字节加 8 GiB。下次普通启动仍取显式配置与下限的较大值，避免启动后立即因原默认值淘汰；后续正常捕获仍遵循容量策略。

## 内容、标签与顺序

- 纯文本/HTML 保留支持的表示；JPEG/TIFF/WebP 在像素预算内转为 PNG。其他宿主专用表示不导入；存在可用的标准表示时不因此整条失败。
- 文件内容复制为目标自有 blob。普通用户文件引用在读取时检查已知大小、修改时间及已知 BLAKE3；旧 NULL 大小按未知处理。旧后台转换图片后可能留下过期的 representation 大小，以已认证且通过自身大小/摘要检查的 blob 为准；文件夹以 ZIP 文件保留目录结构，目标仍通过现有文件能力使用它。丢失内容明确计入报告。
- 保留旧创建时间，旧活动时间记为更新时间。新增私有 `order_ms`：普通提交取创建时间与已有最大排序时间的较大值，迁移取旧创建时间；按 `(order_ms, seq)` 降序。序号继续作为唯一提交顺序和分页上界，新提交不会进入旧分页。
- 标签上限调整为每条 1000 个、每名称 64 个 Unicode 字符，按原名称字符串去重。无关联标签存独立定义表，`ListHistoryTags` 返回定义与现有条目标签的并集，不改既有历史的关联。
- 目标沿用当前版本的存储方式；导入不会为目标增加静态加密。

## 资源与终态

串行处理，一页 128 个 entry id；单记录所持明文数据最多 500 MiB，图片最多 3200 万像素，文件清单最多 10000 行，外部文件流式复制。AEAD 解密与转换过程中还会持有密文、解压或图像工作内存，500 MiB 不是进程 RSS 上限；峰值尚需实测。ZIP 归档在有界内存中生成，不落完整明文中间归档。

关闭并重开目标后通过公开内容接口校验字节摘要。终态区分 `ready`（预检）、`complete`、`partial`、`cancelled` 和 `failed`；部分迁移退出码 3，失败/取消退出码 1，完整成功退出码 0。进度和报告只携带数量、阶段与错误类别，不输出正文、路径、文件名或秘密。
