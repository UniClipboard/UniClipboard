# 0008 · 统一设备身份、信任与同步插件关联

- 状态：已采纳，待实现；身份握手、配对票据及 RPC/SDK 的具体编码仍须补齐后验收。
- 日期：2026-11-08。
- 依据：[0001 配对码](0001-pairing-code.md)、[0007 多后端](0007-multiple-sync-backends.md)、[设备与后端关联契约](../device-contract.md)。
- 产品尚未上线：直接调整接口、存储与设备协议，不实现旧 tailcat 密钥、地址、配对记录、票据或 wire 对端的兼容迁移。本决策不授权删除开发者本地数据。

## 背景

设备管理需要按设备展示，并能查看每台设备通过哪些同步插件接入、各路径的状态和同步开关。tailcat 是默认同步插件，但设备身份、信任和配对不能成为它的专属能力。其他 P2P 或对象存储插件也必须能接入统一设备目录。

## 决策

### 1. Engine 管理设备，插件管理接入路径

Engine 持有本机设备身份密钥、远端设备身份、待批准请求、信任、后端关联授权与统一设备列表。插件提供自身的发现、连接或仓库访问、身份验证材料传送和传输状态，不维护第二套批准/拒绝数据库，不获取 Engine 身份私钥。

区分三个动作：发现候选、验证设备身份、用户授予信任。发现成功、共享仓库、同名设备、相同的自报 DeviceID，均不能直接授信或合并设备。每个后端只取得自身已授权关联所需的状态与短期能力。

### 2. 设备与后端关联分层

设备是全局实体，一台经过认证的设备在列表中显示一次；同一设备可有多个后端关联，每个关联独立授权、启停和报告状态。关联以稳定的配置实例标识区分；插件实现标识与实例标识在目标模型中分离，同一实现可以配置多个实例，例如两个 WebDAV 仓库。

具体类型以设备契约为准。现有 PluginID 同时充当实现与实例 ID 的约束需要调整；不保留旧签名兼容层。配置实例 ID、持久设备关联 ID 与 RPC 的临时 binding_id 是不同概念，不能混用。

### 3. 身份跨插件，授权按关联

Engine 使用独立于 tailcat 网络密钥的设备身份。各后端承载统一身份协议要求的证明，由 Engine 验证。新增路径必须证明远端持有已登记身份密钥，并绑定本次连接或仓库上下文；不能只比较 DeviceID 或采用插件返回的任意“已验证”布尔值。

设备级信任与关联授权同时满足才可同步。新增关联默认需要用户确认；本地明确选择某设备及路径并确认添加，可作为本地授权，远端仍须独立决定。首版不提供自动关联策略。配对码入站请求始终需要出码方用户批准，不因设备已知而绕过。

### 4. 统一配对流程，不强迫统一传输机制

配对码、地址、二维码、局域网发现或仓库发现都是入口。Engine 统一管理候选、配对操作、身份核对、审批和结果；插件负责具体接入。默认交付 tailcat，不要求其他插件依赖 tailcat 完成配对。

P2P 使用连接与会话语义；对象存储使用仓库成员、来源证明和内容授权语义。后者不实现虚假的拨号或在线会话。共享目录不构成设备信任，仓库可访问不表示另一设备在线。

### 5. 设备管理与撤销

列表展开每个设备的后端实例、关联授权、同步开关、可达性、最近活动与脱敏错误。发现来源与当前已关联路径分开表示；未验证候选不能伪装成已信任设备。

暂停某关联只停止该路径内容同步；移除关联撤销该路径授权；解除设备配对撤销全部关联。撤销的本地提交点立即拒绝新授权，完成返回前须使旧会话/任务失效并通过后端屏障；外部后端可终止不响应进程，builtin 后端须关闭端点并确认任务退出，不能确认则停止同步服务并报告失败。已经发送的字节或写入远端的对象不能宣称撤回。

禁用/卸载插件保留设备和关联记录，显示不可用；恢复同一实例须重新验证身份与当前授权。不能以相同实例 ID 悄悄替换仓库/账号并继承授权。

## 对既有设计的调整

- 0001 保留短码只负责发现、到期和强制审批原则；票据、指纹和设备握手改为统一身份协议，不沿用 ID 哈希作为身份认证。
- 0007 保留多后端策略、结果隔离、去重和撤销；目标与策略按配置实例区分。
- 原后端迁移方案改为全新身份初始化与外部插件装配，不读取或导入旧 tc.* 数据，不要求保留原地址或与旧 wire v2 互通。
- 现有 RPC Schema、向量和公开 Go 类型尚未表达本决策；完成相应定义及互操作验证前，不得宣称统一身份或多实例设备管理已可用。

## 验收

- 两个假后端发现同一已验证设备，列表仅一台设备且有两条独立关联；同名不同身份不合并，伪造 DeviceID 不继承信任。
- 已信任设备的新路径未经确认不得同步；确认、取消、过期及撤销竞争不产生迟到授权。
- 不装 tailcat 时，其他具备相应能力的后端可独立完成设备添加；零后端仍可本机使用。
- 同实现的两个实例状态、目录、凭据、授权和撤销相互隔离；实例重定向到其他仓库/账号不能继承原关联。
- 解除设备配对在所有关联后端生效；单路径停用不影响其他路径；插件卸载不删除设备。
- 身份冒充、重放、跨连接/仓库证明复用、密钥不符、坏身份文件及未知协议版本拒绝；秘密不进入列表、事件、日志或错误。
