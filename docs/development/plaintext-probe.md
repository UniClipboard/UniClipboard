# 明文探针验收

明文探针用于验证除文件内容本体外的业务内容没有以原文写入数据库、内容仓、传输缓存、搜索索引、临时目录或日志。探针必须是本次验收专用的随机内容，不能使用真实用户数据。

## 准备探针

为每次实验生成一条全新的单行探针，并保存到扫描目录之外。使用同一探针构造以下测试内容：

- 文本正文与预览；
- 图片字节；
- 文件名；
- 标签名。

文件内容允许按原始字节落盘，不得复用这条敏感内容探针。应另用一条不同标记确认文件传输内容正确，但该标记不参与明文泄漏判定。

探针文件只能包含一行非空文本。不要把探针正文写入测试报告、命令参数或日志。

## 执行实验

在待验收平台上启动完整 P2P 核心，创建或加入空间，双向发送上述内容，然后完整关闭核心。导出或复制以下目录到验收机器：

- 应用私有数据目录；
- 应用缓存目录；
- 应用临时目录；
- 应用日志目录。

不得只挑选已知数据库文件。扫描必须覆盖目录中的数据库、预写日志、内容仓、搜索数据、传输缓存、临时文件和日志。文件内容本体可含单独的传输校验标记，但不得含敏感内容探针。

## 扫描

从仓库根目录运行：

```bash
scripts/security/scan-plaintext-probe.sh \
  /path/outside/export/probe.txt \
  /path/to/private-data \
  /path/to/cache \
  /path/to/temporary \
  /path/to/logs
```

扫描器只报告扫描目录、文件数量、文件类型和命中文件路径。路径中如果含有探针，会自动遮蔽；报告不会输出探针正文。

退出码含义：

| 退出码 | 含义 |
| --- | --- |
| `0` | 所有目录均已扫描，未发现探针原文 |
| `1` | 至少一个文件包含探针原文 |
| `2` | 输入无效、目录缺失或文件无法扫描，验收无效 |

任何非零结果都不能标记通过。退出码 `2` 也不能当作“未发现泄漏”。

## 当前自动门禁

`cargo test -p uc-engine --locked` 当前会：

- 验证干净目录通过、泄漏目录失败、缺失目录失败；
- 验证报告不会泄露探针正文；
- 在真实核心中发送文本和图片，确认文本探针进入预览，关闭后扫描私有数据、缓存、临时目录和正式日志目录。

文件名、文件路径、标签以及 iOS、Android、HarmonyOS 的真实设备目录仍必须按上述流程完成。只有这些证据全部齐全，四平台明文探针门禁才算完成。
