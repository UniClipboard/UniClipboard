## Regression found and fixed

The [pre-fix receipt](0004-2026-11-10-cli-twohost/regression-before.json) records the failure at the first zero-byte file.
The sender committed it and reached `sent`, but the receiver produced no history.
A minimized two-host CLI comparison reproduced `0 B: not received`, `1 B: received` before the fix.
The same comparison passed for both sizes after the fix.

`Engine.admitReceive` had treated a zero total byte count as absent content.
It now checks for absent parts, negative sizes and empty representations, while allowing zero-byte file parts.
The Engine contract and pipeline architecture state this boundary.
The final matrix verifies zero-byte files three times in each direction.
No unit tests were added.
