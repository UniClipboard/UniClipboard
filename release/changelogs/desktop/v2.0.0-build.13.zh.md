## v2.0.0-build.13 (desktop) - 2026-11-26

### Features

- 桌面端窗口、系统集成和安装程序现在统一使用 Unic 品牌名称。 (#2404)
- 配对页面现在会显示配对码和完整配对票据的二维码，连接新设备更方便。 (#2403)
- 同步传输现在会在历史记录中显示进度和送达状态；接收文件时也会显示进度，并可直接从通知中放弃接收。 (#2402)
- 搜索支持标签、类型、设备、日期和文件扩展名的自动补全，快捷面板还新增了“仅看已收藏”筛选和更完善的键盘操作。 (#2412)
- Windows 用户可以选择快捷面板打开在屏幕中央、鼠标指针附近，或文本光标旁边。 (#2413)

### Fixes

- 重新打开快捷面板时，现在会选中第一条结果，不再恢复上次的选中项。 (#2411)
- 修改同步策略或设置时，不再导致整个页面闪烁。 (#2406)
