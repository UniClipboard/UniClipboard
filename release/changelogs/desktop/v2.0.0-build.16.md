## v2.0.0-build.16 (desktop) - 2026-11-28

### Features

- Sign in to your UniClipboard Cloud account from Desktop and enable official hybrid relay service for devices that are temporarily offline. (#2445)
- Hybrid relay now provides encrypted temporary delivery when a paired device is offline, while keeping direct peer-to-peer delivery as the first choice.
- Desktop adds Sensitive Content Guard to identify and block likely secrets, password-manager content, and sensitive files before they enter history or sync; plugin settings also make processing stages and their order clearer. (#2440)
- Delivery status is easier to scan with a collapsible per-device summary that shows progress, relay storage, failures, and retry actions. (#2443)
- The bundled CLI now offers a clear first-run choice to import existing v1 history or start with a fresh profile. (#2446)

### Fixes

- Quick Panel satellite windows now stay aligned with the panel instead of drifting away from it. (#2437)
- Desktop diagnostics export now creates a ZIP bundle containing sanitized logs, status details, and a verification manifest, without configuration, credentials, or clipboard history. (#2441)
