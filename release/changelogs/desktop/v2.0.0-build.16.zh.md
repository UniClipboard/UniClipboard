## v2.0.0-build.16 (desktop) - 2026-11-28

### Features

- 现在可以直接在桌面端登录 UniClipboard Cloud，并启用官方混合中转服务，让暂时离线的设备也能接收内容。 (#2445)
- 混合中转现支持在配对设备离线时加密暂存内容；设备在线时仍优先使用点对点传输。
- 桌面端新增敏感内容防护，可识别并拦截疑似密钥、密码管理器内容和敏感文件，避免其进入历史记录或同步；插件设置也更清晰地展示了各处理阶段及执行顺序。 (#2440)
- 传送状态卡片更易查看：可展开按设备查看进度、中转暂存、失败原因，并执行重试。 (#2443)
- 随附 CLI 首次初始化时会清楚询问是导入现有 v1 历史记录，还是创建全新的配置。 (#2446)

### Fixes

- 修复 Quick Panel 卫星窗口逐渐偏离面板位置的问题。 (#2437)
- 桌面端诊断信息现在导出为 ZIP 文件，包含脱敏日志、状态摘要和校验清单，不包含配置、凭据或剪贴板历史。 (#2441)
