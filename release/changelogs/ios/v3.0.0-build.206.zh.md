## v3.0.0-build.206 (ios) - 2026-11-27

### Features

- 全新的 iOS 应用体验，支持更方便地浏览、搜索、复制和发送同步剪贴板历史，涵盖文本和图片。 (#2343)
- 全新引导流程会帮助你完成设备配对、系统权限设置，以及 iOS 分享和键盘功能的配置。 (#2426)
- 配对更简单：支持二维码扫描，设备审批提示更清晰，并采用更符合 iOS 使用习惯的原生界面。 (#2384) (#2386) (#2430)
- 首次设置时可自动导入已有的 UniClipboard 移动端历史记录，并保留收藏内容。 (#2410) (#2432)
- 可通过 iOS 分享扩展向已配对设备发送内容，也可以从历史记录使用相同的发送流程。 (#2385) (#2391)
- iOS 键盘扩展现在可以显示同步剪贴内容并将选中的内容发送到设备；打开键盘时还可按需实时同步系统剪贴板。 (#2389) (#2436)
- 当应用需要读取剪贴板以刷新本地历史时，会显示原生 iOS 提示。 (#2392)

### Fixes

- 优化 iOS 页面、底部面板、设备设置和历史记录操作，使其更符合 Apple 的使用习惯。 (#2377) (#2382)
