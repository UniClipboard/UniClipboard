## v3.0.0-build.207 (mobile) - 2026-11-28

### Features

- A new first-run setup guides you through pairing, device capabilities, and migrating legacy history, with a refreshed migration experience. (#2426)
- Pairing and device management are easier to follow, with clearer approval flows and incoming pairing requests surfaced automatically. (#2430)
- The iOS keyboard extension can keep clipboard content synced while it is active, with a setting to control automatic sync. (#2436)
- Sync can continue when devices cannot connect directly through an encrypted relay fallback, including improved recovery for interrupted transfers. (#2408)
- Mobile users can sign in to UniClipboard Cloud and configure relay access from the app. (#2445)
- You can export a diagnostic bundle from mobile settings when troubleshooting. (#2441)
- Android now shows a theme-aware launch screen that matches light and dark mode. (#2431)

### Fixes

- Legacy history is preserved correctly when migration completes on first launch. (#2432)
- Android onboarding transitions are smoother and no longer jump during navigation. (#2428)
