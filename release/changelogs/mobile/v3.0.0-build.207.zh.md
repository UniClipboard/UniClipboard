## v3.0.0-build.207 (mobile) - 2026-11-28

### Features

- 全新的首次使用引导帮助你完成设备配对、了解设备能力并迁移旧版历史记录，迁移流程也经过重新设计。 (#2426)
- 配对和设备管理更加清晰，新的配对请求会自动弹出，审批流程也更易操作。 (#2430)
- iOS 键盘扩展在使用期间可以持续同步剪贴板内容，并支持控制是否自动同步。 (#2436)
- 设备无法直接连接时，同步可以通过加密中继继续进行；中断传输后的恢复也更加稳定。 (#2408)
- 移动端支持登录 UniClipboard Cloud，并可直接在应用中配置中继访问权限。 (#2445)
- 遇到问题时，可以从移动端设置导出诊断信息包。 (#2441)
- Android 启动画面现在会随系统浅色或深色模式自动匹配。 (#2431)

### Fixes

- 首次启动完成迁移后，旧版历史记录可以正确保留。 (#2432)
- Android 首次使用引导的页面切换更加顺畅，不再出现布局跳动。 (#2428)
