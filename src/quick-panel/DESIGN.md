# 快捷面板设计规范

本规范约束 `src/quick-panel/` 的布局、字号、间距与交互。新增或修改样式时先遵循本规范；调整规范值时，同步修改代码与本文档。

## 设计目标与作用范围

- 紧凑、便于连续浏览，搜索与列表融入同一面板。
- 对齐以控件可见边缘和内容起点为准，不只比较容器宽度。
- 所有平台共享字号、控件密度和菜单规格；Linux 默认双栏，macOS 与 Windows 保留按需展开预览。
- 复用共享搜索、预览和菜单组件；快捷面板的专属覆盖放在 `src/quick-panel/quick-panel.css`，由该窗口入口单独加载，包含挂载到 `document.body` 的浮层。不修改主窗口的默认密度。
- 颜色使用 `bg-card`、`foreground`、`muted-foreground`、`border`、`primary` 等语义变量，兼容浅色、深色和系统主题。

## 单位与权威来源

下面的像素值按 `1rem = 16px`、界面缩放 100% 说明。实现优先使用 Tailwind 间距刻度或 `rem`，随应用缩放，不重复乘系统缩放。

| 内容 | 代码位置 |
| --- | --- |
| 外侧留白、页脚高度、平台布局 | `src/quick-panel/constants.ts` |
| 搜索、预览内容留白、菜单密度、滚动条 | `src/quick-panel/quick-panel.css` |
| 历史区纵向布局 | `src/quick-panel/components/HistoryPane.tsx` |
| 历史条目 | `src/quick-panel/components/PanelItem.tsx` |
| 类型与标签按钮 | `src/quick-panel/components/QuickPanelTypeFilterBar.tsx`、`src/quick-panel/components/QuickPanelTagFilterBar.tsx` |

共享外侧留白必须使用 `QUICK_PANEL_GUTTER_CLASS_NAME`，页脚使用 `QUICK_PANEL_FOOTER_CLASS_NAME`，不要另设近似值。

## 布局与对齐

| 项目 | 规格 |
| --- | --- |
| Linux 默认面板 | 800 × 560 逻辑像素，受可用输出区域约束 |
| Linux 两栏比例 | 历史 42%，预览 58% |
| 两栏分隔线 | 1px，覆盖绘制，不额外占用一栏宽度 |
| 搜索、类型、历史列表、标签的外侧水平留白 | `px-2`，两侧各 8px |
| 历史条目内部水平留白 | `px-2`，两侧各 8px；图标起点距栏边约 16px |
| 预览内容水平留白 | `--clipboard-preview-inset: 1rem`，两侧各 16px；不调整代码行号等内容自身占位 |
| 普通页脚 | `h-10`，40px，禁止收缩，两栏分隔线等高 |

Linux 面板高度受限时，历史与预览分别在内部滚动。不要通过扩大窗口或改变列宽来容纳条目、标签或预览内容。浮动平台的外侧留白用于阴影和窗口布局，不与栏内留白混用。

## 字号、行高与间距

| 元素 | 字号 | 行高／高度 | 留白与间距 |
| --- | --- | --- | --- |
| 搜索输入 | 14px | 输入区域最小 32px | 内部左右 8px；展开时右侧保留清除按钮空间 |
| 搜索区域 | — | 随内容布局 | 顶部 8px；分割线上下各 6px |
| 类型按钮 | 11px | 高 24px | 左右各 6px；按钮间 2px；区域底部 6px |
| 历史条目正文 | 13px | `leading-tight`，约 16.25px | 上下各 6px；图标与文字间 6px |
| 历史列表容器 | — | 占据剩余高度 | 上下各 2px；普通列表与图片列表使用相同外侧水平留白 |
| 条目时间 | 11px | 跟随条目行高 | 靠右，禁止收缩 |
| 条目快捷键 | 10px | `leading-none` | 左右各 4px，上下各 2px |
| 标签按钮 | 11px | 高 24px | 左右各 6px；图标与文字间 4px；按钮间 2px |
| 页脚提示 | 11px | 跟随页脚居中 | 水平留白 8px |

历史条目高度由行高与上下内边距决定，不重复添加固定高度。类型按钮保持单行、不压缩文字；极窄宽度允许横向滚动。

## 搜索外观

- 普通状态与输入 `#` 后的展开状态都不使用胶囊边框或输入框阴影。
- 使用透明底色；展开的筛选条件可能覆盖下方内容时，使用面板自身的 `card` 底色。
- 分割线属于整个搜索区域：左右与列表外边缘对齐，使用 `border-border/30`，聚焦不加深。
- 聚焦通过光标与搜索图标颜色表达；不要再增加短线、渐变线或输入框底边线。
- 自动补全列表保留独立浮层、键盘导航与清晰选中态。

## 标签区域

- 不显示额外的“标签”文字。
- 默认一行；溢出时才显示展开按钮。尺寸或语言变化后重新测量。
- 展开区域高 72px，标签列表最大高 52px，供两行浏览；更多标签在区域内滚动。
- 展开按钮为 24px，箭头为 16px，固定距底部 8px；展开与折叠时按钮位置不变，仅方向变化。
- 支持多选，标签之间为“或”关系；再次点击取消该标签，收起保留选择。

## 右键菜单

继续复用 `HistoryCardContextMenu` 和 `src/components/motion/context-menu/`，不创建另一套菜单交互实现。主菜单、发送到设备等子菜单使用相同密度。

| 项目 | 规格 |
| --- | --- |
| 菜单宽度 | 200px，仍受视口最大宽度限制 |
| 面板内边距 | 4px |
| 菜单项字号／行高 | 12px／16px |
| 菜单项最小高度 | 28px；长文案允许增高，不强行截断操作名称 |
| 菜单项内边距 | 上下各 6px，左右各 8px |
| 图标／图标文字间距 | 14px／8px |
| 快捷键字号／行高 | 10px／14px，左侧间距 8px |
| 分隔线上下间距 | 各 4px；不向面板外扩展 |
| 圆角 | 延用共享菜单：面板 12px，菜单项 8px |

缩小菜单时不得改变点击行为、方向键导航、Esc 关闭或子菜单定位；保留禁用态、危险操作颜色和共享动效。

## 预览与滚动交互

- 默认预览当前选中条目；真实鼠标移动到其他条目时切换预览。
- 光标离开历史列表进入预览区后，继续显示最后悬停条目；下一次悬停或键盘切换选择时才更新。
- 所有滚动条隐藏，包括原生滚动条和共享滚动组件；保留滚轮、触控板和键盘滚动。
- 不通过 `overflow: hidden` 禁用本应可滚动的内容来隐藏滚动条。

## 验证要求

样式调整检查浅色与深色、默认与缩小后的窗口、较长翻译文案。菜单额外检查主菜单和子菜单，标签检查溢出、多选、展开与折叠，预览检查长文本、图片和文件。

布局截图使用合成条目，避免把真实剪贴板内容写入仓库。检查应记录实际覆盖范围；组件测试不能替代 GTK 桌面交互验证。
