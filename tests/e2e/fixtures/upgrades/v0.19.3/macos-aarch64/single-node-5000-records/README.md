# v0.19.3 五千条历史样本

该样本用于验证大量历史记录下的升级前备份和资料升级。来源是 v0.19.3 提交 `d2d19c8934aa966a9e01bd4885de68de810e0030` 的 macOS ARM 开发构建，程序摘要见 `tests/e2e/fixtures/upgrades/v0.19.3/macos-aarch64/single-node-5000-records/manifest.json`。

样本先恢复同版本的多类型历史资料，再通过旧版的加密写入链路增加 4,994 条不同的文字记录，总数为 5,000。没有直接插入或复制数据库记录。原有 6 条记录包括普通文字、多行文字、链接、长文字、图片和文件。

测试口令为 `v0-19-3-baseline-passphrase`，只用于这个合成样本。测试会在新的独立档案中恢复资料，等待当前版本完成备份和升级，随后解锁并分批读回全部历史，确认总数、记录编号和批量文字记录均未丢失。

归档不包含日志、运行锁、共享内存文件、使用统计标识或升级备份目录。旧版程序完全停止后才生成归档。
