## 文件记录的边界

`inputs/baseline-note.txt` 是被复制的合成源文件，随样本一起保存。旧版文件记录保留采集时的源路径，读取该记录仍依赖源文件可访问；仅恢复压缩包不会重写记录中的源路径。换一台机器或换仓库位置时，不能据此宣称文件记录可独立搬迁。已验证移开源文件时，记录仍在，但当前版本无法导出它。
