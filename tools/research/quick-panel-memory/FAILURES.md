# Quick-panel memory failure inventory

Specify before product changes. Reuse canonical Desktop E2E and its synthetic directory clipboard. Never add a second business implementation.

- Misidentify launcher, GUI, tray, panel or service; group shared pages twice; compare MB with MiB or resident memory with commit.
- Compare different source/build/architecture/DPI/data/time windows; mistake x64-on-ARM64 emulation for a proven root cause.
- Materialize unused full originals or invisible thumbnails; retain hidden details, decoded rasters, reconstruction bytes or satellite GPU resources.
- Reuse stale selected detail after search/reopen; lose full-resolution/EXIF preview, original bytes, actual-size or cancellation.
- Hide panel while content completion is pending; queue completion retains images forever or repopulates a retired generation.
- Reopen blocked by old lifetime; duplicate windows, event streams, clipboard adapter or global shortcut.
- GUI close changes panel behavior; keep-open paste loses original target; cancel/blur retries input or steals focus.
- Force GC/workset trim produces artificial savings; optimize residency while commit or CPU grows.
- Cold start or repeated selection becomes slow; teardown loses pending clipboard application.
- Native capture occurs before paint; software-view result misreported as physical input/paste; automation or capture failures silently pass.
- Access personal history/clipboard; interrupt another VM task; terminate foreign process or leave task resources.

Before implementation, run a native role-aware baseline and add an E2E assertion that fails for a demonstrated unnecessary allocation. Preserve the first failing artifacts. Retry at most twice before investigating a recurrent failure. Keep baseline and candidate source/binary hashes. Measure non-race performance and race correctness separately. Windows ARM64 cannot run the Go race detector.

The rejected satellite control required the hidden history window and role PID
to survive. Final native acceptance retains both window lifetimes, requires the
satellite to render, and preserves search across Copy/hide/reopen. A full-window-retirement exploration was rejected after measuring unstable
cycle savings and higher original readiness latency. It is not the shipped change.

Selected-original input control: a size-known real service image must not allocate
geometrically growing whole-input copies before DecodeBitmap. Measure TotalAlloc
with other view workers cancelled, without forced GC. Keep original dimensions,
encoded bytes and the existing overflow/cancellation rules. Unknown or inaccurate
size hints must retain bounded fallback behavior.

A known-length original must not turn its reserved capacity into a multi-megabyte
body read request. The real-service probe counts the largest requested read and
requires at most64KiB before any product I/O refinement. Keep the existing byte,
raster, admission, original-byte and cancellation contracts unchanged.

## Root-cause follow-up boundary

The follow-up diagnostic plan was recorded before the private probes in the
ignored task plan. No production fix follows these probes in this change.

- Weak owner/renderer instrumentation accidentally extends lifetimes.
- A missing renderer yields a false zero-orphan verdict.
- A frame counter is mistaken for elapsed time or an actual resource lifetime.
- Texture payload bytes are mistaken for driver allocation or private commit.
- Diagnostic GC/release is counted as a normal performance saving.
- An extra guest console changes foreground focus during a native run.
- Output directory names override observed flags; a claimed no-capture run
  actually captures or retains reconstructed pixels.
- A copied read-only module directory prevents an isolated probe build.
- A private dependency override or diagnostic listener leaks into production.

Observed first failures and the misnamed capture trace remain in the root-cause
receipt. The runner now verifies requested/observed flags. The resource assertion
requires both panel renderers and remains RED before diagnostic orphan release.
